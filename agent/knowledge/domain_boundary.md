# 领域与证据边界

OPL Med Cast持有医学科普叙事、媒体质量与资产复用语义；OPL持有通用执行、候选字节、评测、资格及激活。机器检查身份、路径、区间、Schema与状态引用，AI和领域负责人评判解释、叙事与医疗准确性。

静态入库、源视频可用、连续动态、成片技术、完整听感、医学复核、上传各有独立状态与证据。任何缺项记pending；输入不能通过修改状态字符串伪造审查。包预检只检查已声明证据的一致性，不认证审查者身份或判断医学质量。

工作区拥有原始与生成媒体、配音、配置、发布包和资产库；Agent源码不携带媒体或凭据。后台复核不自动播放发声，只有明确需要听审且用户允许时进入听审路径。发布须有当前授权，且最终读回平台结果。
