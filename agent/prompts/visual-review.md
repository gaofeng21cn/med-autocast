# 视听与医学复核

文字先区分纸上排版与独立题注，检查自己的显式区域及真实遮挡。`text_region_overflow` 来自实际字体 metrics 与明确区域；`unbound_text_subject_partial_overlap` 只是旧文字包围盒相交的疑点，不猜 owner，也不靠大背景包含就批准。原尺寸检查标题、单位、日历前后页、笔杆、纸夹、人物和封面在整个动作路径中的关系；正常翻页/收纳与未读文字被遮住分别判断。布局诊断必须保留到顶层质量债，不以脚本归零阻断其他可消费工作。方法见随包工作台 docs/37_纸片文字对齐SOP.md。

排版审查消费 `primary_view: final` 的正式预览及编码对应帧；去文字 `clean` 画面不能批准标签和字幕。`audit_label_contract` 的低层文字调用统计只是源码导航，不是缺陷数；不要用候选数量归零代替逐镜判断。

背景方式检查完整源区间及成片切点，临界细节看原尺寸逐帧；按需求完成连续动态与完整听感复核，另行记录医学复核。

先读取当前工作区与目标选集的精确制作单。不要根据旧对话、文件前缀或mtime推断最新版。

提交可消费的逐项复核决定、可用区间、待审状态与精确返修目标，说明实际证据、欠项、下一阶段或返修点。判断标准：人物头部与手部、医学细节、运动连续性、字幕和旁白是否一致；静态筛选是否被误记成动态或医学通过。

每集先隐藏标题、标签和字幕，不读导演解释，反向描述实际对象、关系、变化或稳定状态；再恢复同期旁白核对条件、否定、先后和结果，不能靠标签改变物件身份。按本镜意图看精确首帧、切点、邻镜和完整连续窗口；操作镜头检查准备/接触/反应/落定，静态关系、揭示和生活情境不强套动作链、前景视差或动作数量。联系表、strip、1 fps 帧、代码分数、ASR、响度和布局只定位各自问题，不能代替正常速度的连续观看、完整听感或医学判断。

执行入口及质量边界见 `agent/professional_skills/medical-video-visual-qa/SKILL.md`、`agent/knowledge/domain_boundary.md`。
