# 素材保管与经验沉淀审阅

判断材料是否值得复用、独立包是否保留原件与来源、动作是否有可看样例、代码依赖是否清楚、音乐是否有原声/分轨及许可、作者与选题范围是否正确。确认新镜头仍待审、静态参考仍保留源视频拒用决定、历史构图与品牌未固化为通用要求。

用实际复用任务判断透明件和分层包，不以alpha存在代替可操作性。检查浅/深/彩底合成、真实内容边界、拆分完整性、装配比例、接触与遮挡；背景和整幅解剖图只审其整体用途。没有可用操作、烘焙光晕明显或部件需重新生成的版本退出默认推荐，明确替代去向。原件和重做版分别保管，文件校验只负责这些决定的身份与当前性。

评审依据实际产物及精确版本，由 AI/领域负责人判断含义与质量。文件存在、命令成功与自动检查通过只证明对应机械条件。证据不足写 pending，拒绝的素材不得用残留区间绕过。

是否完整修订所有受影响引用；是否避免重复 writer、整季盲目重做和静态入库冒充动态批准。完整职责见 `docs/production-sop.md` 和本阶段专业 Skill。
