# 媒体制作与剪辑验收

输入是否为已审首帧和完整提示；任务预算是否累计；拒用源是否排除；旁白未变是否复用；媒体是否实际解码。

JS 动画的每个医学主体是否有已查看的素材、医学参考、来源和用途限制；是否通过素材准入入口；是否仍存在错误器官占位。全篇旁白是否共用同一声线、情绪与参数；听取场景接缝是否出现突然兴奋、音高或距离感变化。响度检查只定位音量问题，完整语气审核不可被声学指标替代。

评审依据实际产物及精确版本，由 AI/领域负责人判断含义与质量。文件存在、命令成功与自动检查通过只证明对应机械条件。证据不足写 pending，拒绝的素材不得用残留区间绕过。

实际提交是否保留官方提示、首帧和参数；字幕、品牌、BGM、尺寸与作者档案是否一致；既有素材是否避免重复生成。完整职责见 `docs/production-sop.md` 和本阶段专业 Skill。

同一时间线应能生成带 BGM 和无 BGM（保留必要拟音）两种候选；旁白始终是主声道，音乐来源和侧链参数可追溯。预览与编码使用相同 score/seek，固定 seed 只证明可复现，不证明视觉语义成立。

按本镜意图核对实际对象、关系、变化或稳定状态是否绘制出来，路径、接触、材质与声音是否在该出现的时点发生。动作库调用、固定 seed、前景视差或动作数量不能证明基本表意。可运行研究样例不能自动批准医学镜头，代码复杂度不代表艺术质量。

复核语境注音是否真正转成模型支持的输入、拒用旧 take 是否排除、未变声段是否复用；新时长是否保留字幕断句且同步到镜头和混音。新修订可编辑文件不能与历史工程共享硬链接。逐段沿源 take、拼接轨、归一化轨、mix 和最终 MP4 核对首词、尾词、接缝与实际时码；真实采样率、解码样本和下游引用应一致，不以静音/能量阈值裁掉低能辅音，不为旧时长截声。实际读音、无 BGM 接缝和最终听感仍须听辨；未覆盖范围保持待审，链路与 ASR 通过不替代听辨。

混音前后重新计算当前旁白整轨与 `score.json` 的 SHA-256，并与 `mix-receipt.json` 的 `voice_sha256`/`score_sha256` 比对；任一失配都标为 `mix_lineage_mismatch`，必须重混并按新时长 retime、build、render。源轨边界扫描或 `source_timeline_bound` 通过不能替代最终 MP4 的段首听辨；每段首词、接缝和结尾都要从实际交付 MP4 音轨听辨，无听辨则保持 `final_mp4_headword`/`full_listening=pending`。

透明请求不能代替实际alpha和多底色复核；环境与运动层分别判断。源码/素材/Score变更后的build、当前preview实际帧、精确current母版及编码回执是否一致；退出码不能批准缺失输出或旧bundle。发现工程漂移修最小原因并继续独立工作，不补填动态或听辨通过。代码统计和哈希仅定位，不按分数决定合格；代表集和批量重渲染不能替代逐集复核。每集已知表意/声音缺陷不得标 passed/ready 或混入用户最新版。方法见 `runtime/workbench/docs/39_逐集表意与段首完整性验收.md`。
