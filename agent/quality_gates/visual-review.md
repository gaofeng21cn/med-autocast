# 视听与医学复核验收

人物头部与手部、医学细节、运动连续性、字幕和旁白是否一致；静态筛选是否被误记成动态或医学通过。

评审依据实际产物及精确版本，由 AI/领域负责人判断含义与质量。文件存在、命令成功与自动检查通过只证明对应机械条件。证据不足写 pending，拒绝的素材不得用残留区间绕过。

方法、范围、审核角色及版本是否有据；静态图、源片和成片的通过不能相互替代。完整职责见 `docs/production-sop.md` 和本阶段专业 Skill。

## 纸剧场动画门

对本地 JavaScript 手绘拼贴候选，视觉审片必须先做去文字审片，再做完整版审片。隐藏字幕、标签和装饰后，每镜仍要能说出一个主焦点及其关系变化；如果只剩居中物件、漂浮线段或依次滑入的卡片，退回故事卡/粗动态分镜。

每镜默认一个主焦点、一个主动作、零到两个短标签、零条装饰线。线段必须指向对象、标记边界或来自真实固定件；大色块必须是纸片、胶带、信封、印章或医学对象，并在镜头中进入、揭开、遮挡、折叠或固定。无法回答“它是什么、为何在这里、接下来如何变化”的元素删除。

资产门与动画门分开：运动层必须是透明单件，浅色、深色和彩色底都不能出现图集残片、背景棋盘、光晕或相邻物件侵入；手、人物和医学主体还要有动作锚点与接触点。技术检查通过、联系表好看或静帧无报错，都不能替代连续运动、声音稳定和医学复核。

预览至少包含精确第 0 帧、每镜切入帧、准备/极值/落点帧、每镜 12 姿态 strip 和整片联系表。首帧不得出现彩色占位或未加载素材；字幕默认透明，除非字幕纸片本身是已经登记的故事物件。返修按“医学与素材 -> 主动作 -> 构图承接 -> 字幕 -> 材质微动”的顺序执行。

按 `shot_recipe` 逐镜确认 `prepare -> action -> reaction -> settle -> hold/rest` 是否真正可见；动作弧只是导演检查语言，不是自动放行条件。每镜需能说出一个主焦点及其关系变化；若去掉文字后只剩卡片、色带、悬空线段或依次滑入的标签，退回导演稿或粗动态分镜。
