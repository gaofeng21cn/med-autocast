# 医学视频阶段

manifest.json是阶段与专业Skill路由权威，阶段细则说明目标、输入、产物及质量边界。

当前主路线为 `evidence-plan -> story-directing -> media-production -> visual-review -> meta-review -> review-handoff`。`asset-curation` 在交付后按需执行，负责资产与经验沉淀。Manifest 的 `requires`、`ensures`、能力包引用和下一阶段引用均是可读的交接建议；Progress First 允许从已有结果跳转、回溯、跳过或继续，只有权限、身份、当前性、执行器和不可逆授权边界才构成硬停止。
