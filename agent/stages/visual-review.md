# 视听与医学复核

背景方式检查完整源区间及成片切点，临界细节看原尺寸逐帧；按需求完成连续动态与完整听感复核，另行记录医学复核。

输入为当前请求、工作区配置和上一阶段可用结果。输出：逐项复核决定、可用区间、待审状态与精确返修目标。已有结果可直接进入本阶段，资料缺项记录为待处理问题；身份、权限与当前版本不一致时停止依赖该条件的动作。按任务语义决定前进或返修，不启动第二 writer。

专业入口：`agent/professional_skills/medical-video-visual-qa/SKILL.md`。

整季请求先用 `scripts/build_episode_review_queue.py` 逐集建立复核任务，再按队列实际证据消费；队列不批准质量，也不因一集缺项阻断其他集的独立审片。

收到质量债清单后，本阶段负责继续完成判断与返修，不能只把整份清单改名为“待人工审核”后结束。先排除未绘制的库存候选，再看当前原件、正式画面与对应实现；可确认的身份、比例、接触、文字和基础医学对应关系直接判断。长停留、阶段名称缺项或重复事件不自动构成缺陷；结合本镜实际职责说明保留或返修的理由。返修候选一旦形成，就消费新候选重新检查受影响定位，不永久沿用“返修中所以待审”。剩余项须具体说明缺什么证据、能否由当前工具继续获得，以及真正需要谁决定；医生终审不替代模型应完成的基础审查。

纸面舞台检查完整构图和跨镜状态：丰富环境是否衬托主焦点、主体是否被重复文字抢走、已收纳物件是否在后镜保留、固定件和门洞是否真正接触。检查音乐是否服务剧情、急诊是否减薄、旁白是否清楚且语气一致；音乐压低与响度仅属技术证据。先审去文字版和带字幕版，再核对当前编码；未覆盖的完整连续动态、听感和医学终审分别保留待审。

比例 Review 检查实际可见主体、辅助物件的色彩重量、动中极值和邻镜承接。包围盒只定位留白与碰撞，不能替代画面平衡判断；不自然的尺寸关系回到具体镜头返修，不增加固定比例硬门。

每集先隐藏标题、标签和字幕，只根据实际画面反向描述对象、关系、变化或稳定状态，再恢复同期旁白核对事实、否定、先后和结果。错误物件不能靠标签改身份。操作镜头检查准备、接触、反应和落定；静态关系、揭示和生活情境按本镜意图判断，不以固定动作链、动作数量或前景视差判合格。精确首帧、切点、动作极值和邻镜按需逐帧查看，正常速度覆盖本集连续时间线；strip、联系表和 1 fps 帧只作定位，未看范围保留待审。声音按旁白、BGM、拟音各自职责复核，技术指标不能代替完整听感。

preview 的去文字帧、`richness` 与 `richness_debt` 帮助定位未登记主体或低占比画面，不代表语义或艺术评分，也不自动决定发布资格。Visual Review 根据实际镜头判断核心含义是否成立；需要名称、数值或限制条件的内容可由必要标签和旁白补足。缺陷与未覆盖范围随集流转，可消费候选和独立工作继续；已知表意或声音缺陷不得标通过或混入用户最新版。
