# 审看交付 SOP

publish是正式审看入口。技术、完整动态、完整听感、医学复核、上传分别有真实状态；不能因publish目录存在而宣称可公开发布。

交付前独立读取当前制作单，与拟交付manifest核对series_id、revision、精确选集和逐集master_ref。母版、字幕、配音与QA必须来自本次确认的当前版本，不能按前缀或mtime选“最新”。medcast.py preflight只做确定性预检，不替代实际媒体解码与审查证据内容。

旧包器可能仍指向v1。先读调用参数与源路径，确认当前修订支持，再打包；准备覆盖时先保留上一审看包恢复路径。交付后回读实际文件与制作单，核对数量、版本及待审项。未变配音和字幕复用，不为交付重新生成。

review模式允许明确记录pending/failed并交付返修或审看。publication_candidate需要所有必要复核声明及当前母版证据，但机器仍不能据此授权上传。对外上传取决于用户当前授权，平台结果另外回读。
