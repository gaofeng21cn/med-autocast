# OPL Med Cast 0.1.0 · 首个公开预览版

面向医学科普视频的首个可下载版本，提供系列规划、故事与镜头设计、视听制作组织、质量复核、审看交付和关键帧资产整理方法。

- 三个动作、六个阶段、六个专业技能，沿用 OPL 标准声明式结构。
- 将既有制作经验落实到 SOP：优先复用素材和已审音轨，排除拒用源片，检查叙事连续性与人物构图，按具体缺陷返修。
- 提供工作区检查、关键帧检索和交付预检三个只读辅助命令。
- 提供中英文 README、统一风格的标志与流程示意图。

下载文件包括源码归档、Codex 插件包和 SHA256SUMS。市场与插件名称均为 opl-medcast，安装选择器为 opl-medcast@opl-medcast。安装与环境准备见仓库 docs/installation.md。

14 个行为测试、OPL 结构检查、接口生成、源码目录检查、辅助程序定位和插件清单校验已通过；现有制作工作区已完成只读接入验证。

本版本以 GitHub 预览版及 Codex 插件形式分发，未进入 OPL GHCR 稳定软件包渠道。OPL Meta Agent 工程调用在启动前因安装身份不一致受阻，尚无设计蓝图、独立资格结果或 OPL 托管激活；该问题及恢复条件见 docs/status.md。具体视频仍需分别完成视听与医学复核。
