# 版本状态

OPL Med Cast 采用标准 OPL 软件包与 OCI 发布流程。当前源码已补齐工作台能力迁移：六个专业 Skill、原十阶段完整方法、跨阶段职责绑定、18 个可调用工具、后端部署源码和模板，以及原制作单/交付合同预检。现有工作区工具优先，通用工具随包提供。

已完成原工作台行为回归、原合同兼容性与错误版本拦截检查；隔离环境实际调用原合成器生成了 4.458333 秒测试片，核对 608×352、H.264/AAC、完整解码、字幕、品牌、BGM、双平台文案、复制字节与旧包恢复。该测试不调用模型，不修改真实作品，也不代表医学视频内容合格。

真实工作区只读验证使用当前血脂单集的原修订制作单与母版，检查 13 段镜头及双平台文案；作者和后端仍从工作区解析，保留原 RTX 4090 视频与音频默认选择。原听感、连续动态与医学待审状态保持不变。源码和载体检查的最新结果见 [能力迁移验收](workbench-parity.md)。

当前源码版本为 0.1.3。正式发布状态以 OCI 版本标签和 latest-stable 的回读为准，本机安装状态以 OPL Package 和原生插件载体回读为准。独立 OMA 资格、托管生产运行、新后端真实推理、医学复核和上传均不由工程验证替代。
