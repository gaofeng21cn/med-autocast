# 版本状态

Med Auto Cast 采用标准 OPL 软件包与 OCI 发布流程。当前源码已补齐工作台能力迁移：八个专业 Skill、原十阶段完整方法、跨阶段职责绑定、随包可调用工具、后端部署源码和模板，以及原制作单/交付合同预检。纸剧场和配音固定使用随包通用入口，旧制作单的专用工具保留工作区覆盖。

已完成原工作台行为回归、原合同兼容性与错误版本拦截检查；隔离环境实际调用原合成器生成了 4.458333 秒测试片，核对 608×352、H.264/AAC、完整解码、字幕、品牌、BGM、双平台文案、复制字节与旧包恢复。该测试不调用模型，不修改真实作品，也不代表医学视频内容合格。

历史迁移验证曾只读使用血脂单集的原修订制作单与母版，检查 13 段镜头及双平台文案；作者和后端仍从工作区解析，保留原 RTX 4090 视频与音频默认选择。原听感、连续动态与医学待审状态保持不变。源码和载体检查的最新结果见 [能力迁移验收](workbench-parity.md)。

当前源码版本为 0.2.6；本版本的 OCI 发布与本机安装以 immutable ref、latest-stable 和 OPL Package 回读为准。独立 OMA 资格、托管生产运行、新后端真实推理、医学复核和上传均不由工程验证替代。

## 0.2.4 发布范围与 App 接入

本版集中交付本地 JavaScript 纸剧场的导演方法、模块化 Canvas 镜头、可选动画风格和渲染器定位、Progress First 阶段交接、视觉与声音联合设计，以及可复用素材的独立保管、看图库和精确版本复用。七个专业 Skill、完整 SOP、工具、模板及资源通过同一软件包分发；私人素材和作者声线不进入公开包。

Med Auto Cast 以 `publisher: one-person-lab` 和 `standard_agent` 角色加入 OPL App 的动态智能体目录，安装与更新由原生载体负责；首页提供“开展医学科普视频工作”。App 读取已安装包的名称、能力说明和入口，不另存固定智能体名单或制作状态。安装入口及工作区初始化见[安装说明](installation.md)。

素材库是可再次创作的起点，不固定下一集的构图、故事或品牌。准备阶段先看实际纸件和动作，制作中保留原件与来源，交付后精选入库，清理前保全；通用代码和作者范围资产分开，原素材审核与新镜头审核分开，一般欠项保留已完成材料继续推进。
