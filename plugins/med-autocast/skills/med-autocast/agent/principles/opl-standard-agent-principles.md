# OPL Standard Agent Principles

This domain adopts the OPL Standard Agent AI-first Principle Pack from `contracts/opl-framework/standard-agent-principles.json`.

- AI performs open-ended understanding, comparison, creation, review, diagnosis, and revision inside bounded stage attempts.
- Contracts, schemas, tests, and readbacks guard identity, authority, inputs, outputs, evidence, and recovery.
- Domain truth, quality verdicts, artifact bodies, memory bodies, owner receipts, and typed blockers stay domain-owned.
- Stage prompts define goals and accepted answer shapes; professional skills carry domain methods; tool catalogs describe affordances and limits without prescribing executor strategy.
- `evidence-plan` maps domain intake into medical evidence and series planning; it is a Stage, not an independent runtime.
