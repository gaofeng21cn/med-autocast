# 医学代码动画制作

拼贴表演按[纸剧场制作方法适配](../../../runtime/workbench/docs/42_paper-collage-mv制作方法适配.md)制作：先检查核心道具各状态与中间姿态，再实现重心/视线先行、手到后物件随动、局部反应和结果停顿。用不同动作时长与保持关键帧避免全程慢慢变形；无人物的科学关系可以稳定呈现。镜头/转场接真实事件，不用随机微动刷动作量。可运行原创小戏：animation_lab create --study followup_bag --project <新目录> --complete；不是跨集导演模板。

新增纸上标题、标签和正文用 `Stage.label` 或 `textBox` 绑定真实局部安全区；`Stage.text` 是底层绘字，不承担自动排版。`audit_label_contract` 定位旧项目仍绕过区域的调用，实际越框、笔杆/夹子遮字及字幕冲突仍在正式预览中确认；不凭统计批量改位置。

动画新标准的单一入口是 [纸剧场动画新标准总纲](../../../runtime/workbench/docs/38_纸剧场动画新标准总纲.md)：工程事实（资源、构建、版本和引用）由工具核对；基本表意、连续动态、声音和医学含义必须由逐集 Review 确认；故事、分镜、构图、纵深和情绪仍由本集独立导演决定。总纲管统一口径与流程骨架，本 Skill 管实现技法。机器结果不能代替语义或听感批准。

先消费当前导演稿、可用素材、实际声段与本集 score；故事、医学事实与作者基线由原职责持有。实现支持导演意图，不让模块库存决定故事。默认是 Canvas 手绘拼贴纸剧场，renderer 与风格分别选择；视频模型仍只在用户显式选择时使用。

读 [代码动画技法与风格工作流](../../../runtime/workbench/docs/26_代码动画技法与风格工作流.md)，按本次选定风格加载 [风格目录](../../../runtime/workbench/templates/animation/styles/index.json) 中的 STYLE.md。它说明材质、动作、镜头、声音与失败模式；样例故事只用于看技法。新风格允许自由设计，现有七种研究不代表穷尽风格或医学生产资格。

先把一个最有解释力的镜头做成真实风格帧与短动作，现场看原尺寸，再逐镜扩展。路径绘制用 `kit/paths.ts` 的 measurePath/trace/pointAt，镜头/物件轨道用 `kit/tracks.ts`；接触后的 settle 衰减到静止。纸材、透明叠色、网点和固定件用 `kit/materials.ts`，或直接自定义 Canvas。对象可以 on-twos，镜头和声音保留主时钟；不为风格感持续抖动所有层。

每集扩展完整镜头前，确认 Score 登记了 `signature_shot` 或 `representative_shot`，并先看该镜头的真实风格帧与短动作。制作或预览时调用 `scripts/audit_motion.py`；它只报告动作阶段缺口、事件死区、配方/事件重复、方向多样性和跨镜承接质量债，所有发现均保持 `blocks_stage_progress=false`。正式预览和渲染还应回读 `medical_animation_runtime_receipt/v1`，确认本次实际读取的 Score、bundle、素材、声音和工具版本。

构图由实际物件内容、认知主次与空间关系控制。PNG 透明外框和 bounds 帮助排除留白，不能自动决定物件大小。图层遮挡由容器/舞台局部层控制，接触点由素材登记或审定路径给出；医学生物结构不可由通用植物样例或自动生成路径代替。

症状标记、探头与器官焦点绑定原件实际结构的局部锚点，再随原件裁切、缩放和旋转共同变换。高幅全身图的颈部不能按显示宽度估算；同一标记 helper 用于咽喉、皮肤、手脚时分别核对真实部位。修了实现后同步本集导演稿与 Score 的旧动作描述，避免下一轮重新引入已否决的动作。检查该标记的出现、中间移动与最后落点，不靠文字声明纠正落错的图形。

文字先区分纸上排版与独立题注。纸件、标题条与文字共享局部变换；`kit/labels.ts` 的 `textBox` 明确宽高，`cardTitle` 只使用以当前原点为中心的真实纸件尺寸。按实际字形量宽高、在可读下限内缩字/换行，仍放不下则保留完整字与 `fits:false` 交导演重排，不截字、不许诺“永不溢出”。纸夹留边、铅笔按笔尖定位、封面与插页保持正确层级；检查整个进入路径是否扫过旧标题。先看原尺寸帧确认归属再改具体 helper，源码相邻与包围盒不猜 owner，不批量居中。全季定位用 `audit_text_layout`，疑点是可消费质量债。见[纸片文字与遮挡SOP](../../../runtime/workbench/docs/37_纸片文字对齐SOP.md)。

画面与声音共用 `score.json`：重要接触、揭示和落点用命名事件驱动。声音调色板供导演选材，注册声音资产优先于程序合成音；合成音只是可运行的试作下限。允许静默与有目的的 J/L cut，不要求所有动作响。旁白沿用授权本地声线，动画工具不改 VoxCPM2/Edge 策略。

通过 [工作台入口](../../../runtime/workbench/docs/20_纸剧场单集工具与局部返修.md) 的 `animation_lab list` 查风格；`animation_lab create --project <新目录> --complete` 生成独立原创样片、源码、无旁白音效轨、帧、strip 和 MP4。用于学习与验证，不能覆盖真实单集或作者配置。实际单集沿用 `paper_project` 做局部预览/正式渲染，随机 seek、预览和编码必须同源。

审片顺序按问题选择：首帧与关键接触、完整动作、邻镜、正常速度整片与去文字。preview 的 text_observations 和 layout_findings 是定位线索；字体、背景对比、画面含义、阅读节奏与完整听感仍由 Review 判断。字段缺失或风格不理想记质量债并继续可消费工作，不让脚本替艺术审判。

有价值的模块连同冻结源码、依赖版本、score 事件、可看样例、适用与失败条件交素材策展保存；样例通过不能自动批准另一集。实际素材、个人声线和成片保留在工作区。外部方法 provenance 在风格目录 SOURCE.md；复制第三方代码/素材时另保留逐件许可。

纸件容器用 paperFolder 等模块控制自身遮挡，尺寸依实际内容设计；完整打开后检查是否仍遮住资料。翻页与收纳动作结束必须留下正确状态。医学路径从真实来源与当前解剖关系审定，不能用自动曲线补缺；可先通过同源纸件分层揭示继续制作。短闪点、按压和记录共用 score 命名事件，不维护第二份时码。具体返修边界见代码动画工作流。

源码、素材、Score 或品牌变化后，通过 paper_project 重新 build，再 preview 当前受影响窗口/邻镜，最后 render；不绕过已存在的构建输入绑定。退出码为0可能只有诊断，回读本次 preview.json、实际帧与 out/current.json 指向的 MP4，不沿用旧帧或旧审核。可运动素材先查真实 alpha 和多底色合成；静态环境可不透明。具体前置交接与返修见[初版质量流程](../../../runtime/workbench/docs/28_初版质量与高效返修流程.md)。

完整纸景不能掩盖空洞事件；真实构图先排查桌边色带、抽象占位物、无来源遮挡与资料相互覆盖。重复排时保留相同音轨已采用的字幕时码；既有漂移用明确编辑参考修复，不重配未变声轨。具体方法见初版质量流程。

真实纸景中的字幕按实际背景对比与纹理检查，默认优先字色/细描边，不用大色带补救。道具按实物身份设计，不能把烟草、补充食品、药物和不同样本都画成同一瓶形再换标签。有限抽帧发现问题时局部返修；新母版须重新构建、预览、编码并回读当前登记，范围与待审见初版质量流程。

每一集必须拥有自己的故事、导演稿、分镜和镜头实现；跨集只共享动画原语（kit）和纸件资产，不允许共享导演。系列级镜头工厂（six_shots/hypertension_shots/story_shots 之类）不是可选项，而是架构错误：它让同一系列每集用同样的空间与节奏，把 89 集压成 11 集。写新集时新建本集 `episodeshots.ts` 与 `scene_directions.json`，可以 import 词汇层（organ/page/paperFolder/nightSpace）与 kit 原语（arc/place/contactShadow），禁止 import 其他集的镜头文件。`scripts/check_episode_independence.py` 只定位逐字复制与共享镜头实现，再核对真实 import 和职责；哈希不同不证明故事独立，通用原语相同也不构成导演不合格。跨集共享整篇导演实现仍须拆回本集。详见 [逐集独立导演与系列资产分层SOP](../../../runtime/workbench/docs/34_逐集独立导演与系列资产分层SOP.md)。

相机运动不能代替物件关系和真实变化。`Stage.camera()` 对整幅画面施加同一变换，不能据此宣称存在景深；前景视差、纸纹罩染和持续运动都是按本镜语义选择的技法，不是每镜必有的门。`kit/staging.ts` 的 `foreground()`、`paperWorld()` 及 `Shot.depth` 只在确实帮助空间、媒介或注意力时启用。操作、交接、翻页等有物理接触的镜头检查准备、接触、反应与落定；静态科学关系、持续观察、生活情境或局部变化选择适合本集的动作和停留，不硬套同一弧线。动作时点读 `beat.events` 而非猜 `t`。详见[纵深与媒介统一](../../../runtime/workbench/docs/35_纸剧场纵深与媒介统一SOP.md)与[逐集表意与段首完整性验收](../../../runtime/workbench/docs/39_逐集表意与段首完整性验收.md)。

逐集返修先读本集导演稿、实际候选和上一轮 Review，明确“观众应看懂什么、当前画面实际表达了什么、最早缺口在哪里”，再决定局部修复、重写镜头或保留候选。`scripts/evaluate_episodes.py` 只用于导航源码、汇总诊断和发现可疑集，不能用分数阈值决定“需重写/合格”，也不能代替逐集观看。批次只用于排期与验收，不用于共享导演实现：每集独立读 beats 与 directing、写镜头并查看当前渲染的精确首帧、动作关键姿态、结果、邻镜及正常速度。发现表意含糊时优先回到导演稿和素材身份，不能靠再加标签、线段或色带补救。源码统计与观感冲突时保留诊断，以逐集语义审片决定返修。详见[逐集评估与独立改写](../../../runtime/workbench/docs/36_逐集评估与独立改写SOP.md)与[逐集表意与段首完整性验收](../../../runtime/workbench/docs/39_逐集表意与段首完整性验收.md)。


独立 MAC 资产库默认先查原件：`python3 scripts/media_asset_library.py query --query <视觉锚点>` 返回真实原件、动作和独立 Skill 路径；查看后决定复用、适配、另找合法素材或新创。不设复用率，也不让库里的构图和故事锁住新片。`ensure` 在安装时自动获取或复用，访问失败继续新创；`use --project <单集路径> --id <精确外库ID>` 接到本地版本包与 uses，当前镜头重新审核。方法见工作台 docs/31_MAC独立资产库接入.md。


## 2026-10-18 全季返修经验：文字安全区与离屏标签

源码复查确认 `cardTitle` 曾把水平 `inset` 同时作为垂直内边距，短纸签因此只剩极小字形区域；现已分开水平/垂直安全区并将区域限制在纸件内。另一个待收口方案曾把离屏文字单独移回视口，但这样会让字脱离纸件，已撤去：`Stage.text` 保持导演的局部坐标，纸与字共用变换、遮挡与退场。近边缘需要可读时，调整整个纸件、镜头或同层排版，不偷偷移动字。新增或返修使用 `cardTitle`/`textBox`；这些源码修复不证明 89 集当前成片都已复核。

按实际依赖更新受影响的集：旁白或时码变更需 retime，动画源码/素材变更需 build/preview，声音变更需 mix，最终媒体变更需 render/package；只改方法文档不重渲染全季。布局与声音报告绑定当前产物；`audit_text_layout` 缺少 Pillow 时仍保留结构化报告。审计只提供定位，不替代逐集连续动态、完整听感和医学 Review。

## 2026-10-18 动作审计发现的逐镜处理

动作审计中的 `motion_phase_evidence_incomplete`、`long_motion_dead_zone`、重复事件、方向单一、代表镜头、承接物和转场告警先按定位材料消费。它们不是同数量的画面故障，也不能通过简单改事件名清零。对现有工程可运行：

```bash
python3 scripts/resolve_motion_audit.py --workspace <workspace>
```

该工具只汇集当前 Score 声明与实际引用，生成 work/review/ 下的待审材料；不写 Score，不读取源码/帧后假称动作已发生，不自动认证停留或跨镜连续性。历史 motion_director_evidence/v1 自动补写按未核实声明处理；不要为改变审计数量重渲染全季。真实画面改动后再重跑受影响构建/预览/混音/编码。

声明只帮助导航。是否已经发生、是否清楚和生动，必须查看真实动作及邻镜；没有发展与结果就改本集导演稿/实现，不能用 motion_quality_review 字段掩盖空洞。
