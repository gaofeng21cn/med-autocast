# 医学动画素材策展

先以明确的 `workspace_root` 和当前单集登记定位材料。方法见[素材保管与策展](../../../runtime/workbench/docs/23_可复用素材保管与策展.md)，实际调用见[工作台工具接入](../../../docs/workspace-adapter.md)。素材文件属于制作工作区，不复制进智能体源码或随包示例。

准备新故事时先查 `paper_project library --query`，再实际看候选图像和动作。区分环境板、透明主体、纸材固定件、静态参考与可运行组件；查到原工程材料不等于独立保管，也不等于适合当前故事。库只提供稳定起点，导演仍可以新创和替换，不因已有素材锁住故事。

选取值得再次使用的材料，登记能承担的动作、适用情境、来源/许可、限制、连接点、审看范围和质量债。按通用、选题、系列、作者标范围。具体品牌、个人形象和参考声线从作者/系列档案读取，不写死进通用 Skill，也不把原样例中的身份带给新作者。

入库前先判断它能怎样复用，不能把“已有PNG、有alpha、曾经上过片”当入选理由。需要独立运动的部件从生成前就分别准备：例如血糖仪与试纸、药瓶与瓶盖、袖带与主机。每件保留真实内容边界、接触点与朝向；分层包保存 `asset_bundle` 和装配说明，`media_asset_library use` 一次复制并登记全部部件。先在浅/深/彩底及实际装配关系中看过，才进入可复用候选；小样未覆盖的动态与医学范围仍待审。

完整纸景可作为后景，完整解剖图可作为结构总览，必须准确标明整体用途；它们没有分层时不能声称门窗、仪器或内部结构能独立运动。多物件合图如果承担的是多个独立动作，先拆出干净部件；缺少被遮挡内容、外围光晕严重或医学生成关系不可靠时重新生成/换源，不靠颜色阈值抹边或底板遮盖。无法提供明确复用操作的原件退出默认推荐；参考和被替代版本只留恢复来源，缺材时继续新创，不阻断 Stage。

图像用 `library --ingest-project --notes JSON` 独立保存原图及已有来源证据。组件、动作与声音用 `library --register JSON` 保存实际文件包：组件带冻结源码和依赖；动作带简短使用条件及可看样例；音乐保留原声/分轨/可编辑工程和许可，不把含旁白混音当 BGM。大音源或授权参考声线可保留唯一稳定位置，包里明确外部依赖。

归档复制后回读实际文件和来源，确认不依赖将被清理的原工程。`catalog.json` 及版本包是持久库；`index.json`、`index.html` 是重建投影。普通查询只读，用 `--refresh` 刷新完整看图库。保留旧 revision，新字节不能覆盖旧包；样例和文件存在不能补填艺术、听感或医学通过。

新集用 `library --use ID --revision REVISION` 显式复制，图像可给 `--asset-id` 指定本集 ID。保留来源审核，重置当前镜头审核；查看实际内容和透明边界后按画面平衡、认知关系、动作及邻镜调整尺寸，不统一图片外框。代码复制后由开发者显式接入，依赖缺项记清并继续其他可消费工作。

`uses.json` 和项目内素材引用帮助追踪复用影响；库升级不自动改旧片。拒用素材保留拒用理由，不推荐回用；一般材料欠项保留成功包并记录债务，不增加 Stage 启动门。交付后 `asset-curation` 汇总精选与经验，制作中也随时使用本能力。

交接给出实际库条目及精确版本、可看入口、已复制范围和未完成审查。经验抽取可迁移的方法，疾病细节和品牌参数留对应档案；清理前保全唯一素材与证据，避免把整片、依赖目录和帧缓存复制成素材库。

风格方法与具体故事分开保管。代码动作保存源码、kit 版本、依赖、命名事件、可看动作窗口及适用/失败条件；材质音保存原音或可编辑合成参数，不把含旁白成片当素材。`animation_lab` 的原创样例可学习技法，不能把通用植物符号、示例时码或技术通过当医学准入。具体方法见 [代码动画工作流](../../../runtime/workbench/docs/26_代码动画技法与风格工作流.md)。

透明图先检查实际RGBA和舞台合成，再判断外围光晕；原件保留，内容裁切可在代码里显式登记。保存内容bounds、裁切用途、动作样例和拒用修订原因，源图审核与当前镜头审核分别保管。被替换的几何占位件不再推荐为默认人物或医学结构。

“请求透明”与“真实透明”分别记录：查原件 alpha 分布与浅/深/彩底合成，区分不透明背景、假棋盘、内部破洞及外围光晕。登记实际内容 bounds、接触点、遮挡职责、医学用途/边界、来源/许可或生成回执与拒用原因；bounds 不自动决定认知比例。环境板可以不透明，运动层要可操作。问题单件重新生成或换合法来源，不用底板遮盖。方法见[初版质量流程](../../../runtime/workbench/docs/28_初版质量与高效返修流程.md)。

## 外挂库接入

跨工作区资产通过工作台 `workbench.yaml.asset_library.root` 指向外挂仓库。准备新集时先查询并实际查看载荷，交付后同步有复用价值的纸件、动作源码、BGM 分轨和失败原因；精确版本写入本集 manifest/uses。查询或同步不是启动门，外部库不可用时继续 Progress First。初稿前置动作见 `runtime/workbench/docs/29_医学视频资产库与初稿前置质量SOP.md`。


独立 `mac-media-assets` 是默认发现入口。先用 `media_asset_library query --query <视觉锚点>` 或 native `assets --library external` 检索，再实际查看 `resolved_payloads` 的原图/动作与本库 Skill。按本集故事决定复用、适配、另找合法素材或 ImageGen 新创，不设复用率，不让已有素材决定故事、构图、风格或镜头数。库缺失、无匹配或旧素材不合适时继续新创与其他工作，质量债随交接保留。实际取用用 `media_asset_library use --project <单集路径> --id <精确外库ID>`，沿用工作台版本包与 uses，复制后当前镜头重新审查；作者范围仍按作者档案约束。安装/发现方法见 `docs/media-assets-integration.md`。
