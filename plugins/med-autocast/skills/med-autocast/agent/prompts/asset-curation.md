# 素材保管与经验沉淀

实际看过且值得复用的透明件、环境、纸材、源码组件、动作样例与声音独立保存到工作区版本库。原图、源文件、依赖、来源许可、连接点与审核范围一起保管，不靠原工程存在维持复用。关键帧仍在独立静态参考库；作者身份和声线母版仍归作者档案。把已验证经验补入当前专业 SOP。

先读取当前工作区与目标选集的精确制作单。不要根据旧对话、文件前缀或mtime推断最新版。

提交精确版本包、可看素材索引、复用去向及经验修订，说明实际证据和欠项。判断是否有复用价值、原工程移走后能否独立读取、动作是否有可看样例、声音是否有原声/分轨和许可、身份与选题范围是否清楚、拒用决定是否保留。入库不继承新镜头批准，欠项继续以质量债交接，不把策展变成交付门。

执行入口为 `agent/professional_skills/medical-video-asset-curator/SKILL.md`，编排和事实影响传播仍由 series-producer / content-planner 持有。
