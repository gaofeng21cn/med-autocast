# 故事与联合时间轴

按当前观看任务明确主焦点、支持组与背景：复杂核心给足阅读面积或拆解，小图只保留单一轮廓或已解释归档内容。人物、椅面、投影与道具成组试装，查看原尺寸和手机宽预览，并核对动作极值与邻镜。统一观看判断，各集保留独立导演；方法见 `runtime/workbench/docs/44_人物素材与画面尺度契约.md`。

人物先读取目标系列作者档案，再用 `media_asset_library character-coverage`、`query --character-role <角色> --pose <姿态>` 查原件与真实缺口。作者档案启用 `default_for_clinician` 时，所有医生身份、`generic`、精确外库 ID 和自定义医生别名都使用当前作者私有完整形象；本机当前作者为 Dr.咩 时直接用 Dr.咩。同一场景确需第二位独立医生时，设计明确不同的专属角色，不复制作者人物制造分身。完整姿态按同一母版准备，先试人物、椅面和道具的接触及当前尺寸，再冻结分镜。

分镜阶段为必要文字说明它属于哪件纸、何时需要读完、物件/人物/笔杆从哪里经过；可直接在风格帧上标注，不新增强制表单。标题、数值和单位与真实纸件共享局部变换，固定件和动作路径避开阅读区。没有承载动作的文字底板优先删掉；独立题注可直接留在画面里。布局审查必须看含标签和字幕的正式视图，去文字图仅检查视觉表意，不能反过来批准排版。方法见随包工作台 docs/37_纸片文字对齐SOP.md。

先用 `media_asset_library query` 发现跨工作区候选并实际看原图/动作，结合当前旁白，按整篇观看任务共同设计讲述与画面。先确定本集患者能理解什么、能做什么，再为核心事实写可见对象、关系、变化或稳定状态、解释作用、入出镜承接与准确区间。规划时暂去文字反向推演实际会看见什么，再与同期旁白核对条件、否定、先后与可能性；样本、器械、药物和结构身份不能靠标签改写。

人物覆盖在分镜前完成：按角色、年龄/身体状态、姿态、朝向和动作建立清单，查询并查看完整素材。主要人物不能用圆头、梯形身体和独立四肢临时拼成；儿童、老人、孕妇不能由成人素材缩放或改色冒充。缺人物先准备素材包，再按最佳素材重写镜头。复杂对象按叙事重量决定景别，读不清就改近景、拆分或换简化结构，不用标签补偿。

进入制作前运行 `scripts/first_draft_preflight.py --project <单集工程> --pretty`，把程序拼片、姿态尺度、复杂对象阅读面积和动画参考接线作为初稿质量债；它只定位，不代替实际看帧。

先读取当前工作区与目标选集的精确制作单。不要根据旧对话、文件前缀或mtime推断最新版。

提交可消费的故事包、分镜、旁白、镜头与复用/生成缺口清单，说明实际证据、欠项、下一阶段或返修点。判断标准：画面能否解释同期旁白；镜头承接是否清楚；跨集是否仅换名裁切；短片段是否造成碎镜。

从系列故事圣经写单集纸剧场分镜，注明物件含义变化、动作因果、景别、透明分层、读图停留和字幕空间。粗动态分镜及每镜 JS seek 预览可在最终编码前返修，首帧和切入帧须精确检查。

素材设计由故事动作决定：生成前写明哪些部件分别运动、在哪接触/遮挡、哪些只是后景或完整结构图。库中完整背景和复合纸件不冒充可拆层；需要试纸插入、瓶盖打开、人物操作仪器时使用独立部件或重新准备。默认检索仅推荐可复用候选，历史静帧与待重做原件只供明确的参考用途；无匹配时继续新创。

每镜附可读的 `shot_recipe`：患者先看什么、可见对象与核心关系是什么、需要怎样变化或保持、哪个物件接到下一镜、旁白/BGM/拟音各在何处服务。操作/接触镜头交代准备、操作、反应和结果；静态科学关系、持续观察、局部揭示和生活情境允许不同语法，不强制前景视差、动作数量或统一动作链。配方卡是导演交接和返修定位，不是必须满足的结构化启动条件；缺字段时保留故事包并记录质量债。

优先沿用用户在 workflow input 的 `style_selection`；没有显式选择时才读取系列作者档案和 `animation_style_registry.json` 默认值。把 `style_id`（艺术语言）和 `renderer`（实现后端）分开。未知风格先保留原请求、设计视觉处理并记录能力债务，不因目录不认识该值而退回默认风格或停止导演工作。

执行入口及质量边界见 `agent/professional_skills/medical-video-director/SKILL.md`、`agent/knowledge/domain_boundary.md`。

## 原工作台职责与专业交接

覆盖 S05—S06：内容与导演在正式配音前共同收敛整篇故事板和版本绑定的故事包；准备真实基础素材及替代。

- `agent/professional_skills/medical-video-content-planner/SKILL.md`
- `agent/professional_skills/medical-video-director/SKILL.md`
- `agent/professional_skills/medical-video-visual-qa/SKILL.md`

先读 `docs/production-sop.md` 的阶段映射；按 `docs/workspace-adapter.md` 选择实际工具和原输入合同。后续补充或返修从受影响职责继续，不为六阶段顺序重复制作。

按所选 STYLE.md 的媒介方法写本集 Treatment，比较有实质区别的故事讲法后确定观看事件、开头/结尾、signature shot、镜头理由与声音弧线。先做真实风格帧与短动作；`animation_lab` 供学习原件。不要照搬示例故事/时码或强制运镜数，未完成项交接质量债。方法见 `runtime/workbench/docs/26_代码动画技法与风格工作流.md`。

先用自然语言讲清每段的可见事情、认识变化与同期医学含义，规划核心道具真实状态图；有角色才设计性格、重心/视线与有来由的表情。动作时长与停顿来自读图负担，不设动作数/转场数配额。先把一个代表动作做深，再审整集 animatic。方法见 runtime/workbench/docs/42_paper-collage-mv制作方法适配.md。Score 的动作说明只是声明，resolve_motion_audit 只汇集、不改输入，不凭字段清零批准画面。

交接旁白时已按全文语境确定多音字、医学术语、数字单位和缩写的读音，给出可消费的配音专用输入及停顿意图（如 VoxCPM2 tts_text 与正文分离）。优先做首句/高风险整段和代表镜头小样，不把注音责任留到最终听审。方法见 runtime/workbench/docs/28_初版质量与高效返修流程.md。

先设计本集完整纸面空间，再拆可表演层；按事实交接可见关系、需要的变化/稳定状态、结果停留和邻镜承接。主次按实际内容和画面重量决定，不统一 PNG 外框；去文字能辨认核心对象关系，必要名称、数值和限制可由旁白及简短标签补足，不用无职责底板/线段填空。长旁白应有持续成立的画面承接，不用慢推或随机微动代替解释。先做真实风格帧与代表镜头，再用整集 animatic 看邻镜、字幕和声音；代表镜头/代表集仅验证方法，不豁免其他各集。批量复用技法不复制故事和整套镜头；欠项继续交候选与质量债。方法见 `runtime/workbench/docs/28_初版质量与高效返修流程.md` 与 `runtime/workbench/docs/39_逐集表意与段首完整性验收.md`。


独立 `mac-media-assets` 是默认发现入口。动画制作先用 native `assets --library external --animation-reference --query <动作或视觉锚点>` 得到按可运行动作、代码组件、分层部件和环境排序的候选，再实际查看 `resolved_payloads` 的原图/动作与本库 Skill。它只提供可复用下限，`creative_ceiling=open`；按本集故事决定复用、适配、另找合法素材或 ImageGen 新创，不设复用率，也不让已有素材决定故事、构图、风格、镜头数或新效果。库缺失、无匹配或旧素材不合适时继续新创与其他工作，质量债随交接保留。实际取用用 `media_asset_library use --project <单集路径> --id <精确外库ID>`；取用动作/代码包后检查项目 `animation_references[]`，再沿用工作台版本包与 uses，复制后当前镜头重新审查；作者范围仍按作者档案约束。安装/发现方法见 `docs/media-assets-integration.md`。

按中文对象、动作和叙事用途检索外库，使用 `collections` 查看装配与事件关系，查看真实小样后决定是否 `use-collection`。集合不固定故事与构图，欠项保留债务继续新创。部件bounds分别使用，不把单层总览当可配准分层。完整方法由资产策展Skill与随包 docs/32_资产发现与可重组事件SOP.md 提供。
