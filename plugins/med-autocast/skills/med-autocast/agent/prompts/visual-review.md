# 视听与医学复核

新动画实际审看角色表演与灵动性：注意力落点、表情、视线、朝向、重心、手势与停顿是否服务本镜任务。固定微笑摊手或只平移倾斜不能证明阅读、转头、解释或递接；有意义的停手倾听和稳定注视可以成立。正常速度看完整动作与邻镜，核对同一身份、身体体量和接触连续性；缺口回最早导演、素材或实现，不以姿态数量/登记状态替代判断。方法见 `runtime/workbench/docs/44_人物素材与画面尺度契约.md` 的“角色表演与灵动性”。

先在原尺寸与手机宽预览中判断主焦点、支持组、背景和小图职责，再看动作极值、落定与邻镜的人物、椅面、投影、手持物关系。复杂核心读不清就扩大、近景或拆解；小图只承载单一轮廓或已解释归档内容。将小而复杂、裁切遮挡、接触承托、身份及层级分开记录，等距状态帧不能批准所有接触或连续动态。方法见 `runtime/workbench/docs/44_人物素材与画面尺度契约.md`。

核对真实锚点、身体承托、可见手与道具、跨姿态身份连续性，不能因registration字段齐全或复制回读通过而放行。PNG透明区RGB显示的光晕须看真实alpha合成；当前镜头逐项审查，不把登记候选当动作批准。

纸剧场按 runtime/workbench/docs/42_paper-collage-mv制作方法适配.md 查看道具状态、中间姿态、动作因果、停顿、表情来由、明暗和转场。换一句旁白仍通用的画面检查解释职责；接触、医学关系、同期条件优先。Score 声明与自动审计不证明画面发生过，不以动作量或告警归零批准质量。

人物模式与尺寸是独立检查：主要人物是否为完整素材、是否为程序拼片，儿童/老人/孕妇的年龄和身体状态是否真实，完整素材的头脸手脚关节是否仍在；再按主对象、复杂结构、辅助物、环境和小细节判断尺度，使用实际内容 bounds 和画面重量。复杂主体太小应返修镜头或素材，不能靠标签补救。`audit_character_and_scale_contract.py` 只定位，结论绑定当前帧。

人物同场比例是独立审片项：回读当前 `scale_contract` 的 `pixels_per_cm` 与每个实际载荷 SHA，逐镜看头肩、躯干、姿态高度、桌椅承托、脚底、可见手和前后景关系。Dr.咩 半身、患者全身、家属站姿等真实人物不能按像素外框相等放行；确认失衡回到导演/素材/实现 owner 返修。示意层按 `scale_mode` 分类，结构示意、放大切片、数据图表和符号隐喻可以使用解释职责需要的不同图解比例；`document_flat`/`screen_content` 的纸张和屏幕容器仍按物理关系排景。不得让任一图解层被误读为人物尺度依据，详见 `runtime/workbench/docs/49_示意图分类与跨层排景逻辑.md`。

文字先区分纸上排版与独立题注，检查自己的显式区域及真实遮挡。`text_region_overflow` 来自实际字体 metrics 与明确区域；`unbound_text_subject_partial_overlap` 只是旧文字包围盒相交的疑点，不猜 owner，也不靠大背景包含就批准。原尺寸检查标题、单位、日历前后页、笔杆、纸夹、人物和封面在整个动作路径中的关系；正常翻页/收纳与未读文字被遮住分别判断。布局诊断必须保留到顶层质量债，不以脚本归零阻断其他可消费工作。方法见随包工作台 docs/37_纸片文字对齐SOP.md。

自然性是单独的审片维度。结合事件前、接触时、落定后三个状态判断：人物是否完整连续，视线、身体、手和物件是否属于同一关系组，动作是否符合先注意—接触—移动—反应—落定的日常认知；中央断臂、来源不明的悬浮局部、文字压在药盒或药单上、物件无手无支撑漂移，均回到导演或素材 owner 修复。明确视角、画边进入/退出、人体连接点和材质连续的操作特写可以只露出一只手臂，但须实际看原尺寸、手机宽度、动作中间和结果。去掉标题、标签和字幕后，观众仍应能说出谁在看什么、谁移动了什么、结果是什么。每集在 `qa/naturalness-review.json` 记录文字归属、人物连续性、动作因果、接触落点、去文字反向读图和移动端证据；这份记录只绑定实际版本、镜头范围和证据路径，不能以根 `passed` 或字段存在升级为自然性通过，也不能升级连续动态、听感、医学或发布状态。

首次试装及成片都用原尺寸和手机宽复看人物朝向、座面承托与遮挡最大处。看关键部位及身体连接是否可读，区分有意的桌沿遮挡与反向坐椅、悬空、断肢错觉或握持点被挡。将具体时码与复看结果记入 `qa/naturalness-review.json`。

用真实成片验证落座、步行、持握、入袋和正文显露的先后。查坐向和椅背、实际接触点、最快或遮挡最大处、结果和切点。复看每次修订的实际编码版本。

在正式编码的原尺寸与手机宽核对急症镜头的精确切入帧，确认触发条件和对应行动同屏可读，行动数字、单位和动词完整。对纸签入场、报告分叠和折页翻面加查中间状态，只在所属纸面完整可辨时显示文字。各自落桌的道具边缘若相切，判断是否让人误读为倚靠或夹持，必要时留出间隔。

排版审查消费 `primary_view: final` 的正式预览及编码对应帧；去文字 `clean` 画面不能批准标签和字幕。`audit_label_contract` 的低层文字调用统计只是源码导航，不是缺陷数；不要用候选数量归零代替逐镜判断。

背景方式检查完整源区间及成片切点，临界细节看原尺寸逐帧；按需求完成连续动态与完整听感复核，另行记录医学复核。

先读取当前工作区与目标选集的精确制作单。不要根据旧对话、文件前缀或mtime推断最新版。

若当前工程存在 `qa/miniapp-notes/`，读取与本集相关的审看意见及绑定媒体/镜头。
意见是待处理输入，不能当成批准；先核对所指候选，版本变化时结合新候选说明是否仍适用。
把已处理意见引用和返修结果写入本阶段原有复核产物，不另建任务队列或第二份质量状态。

提交可消费的逐项复核决定、可用区间、待审状态与精确返修目标，说明实际证据、欠项、下一阶段或返修点。判断标准：人物头部与手部、医学细节、运动连续性、字幕和旁白是否一致；静态筛选是否被误记成动态或医学通过。

每集先隐藏标题、标签和字幕，不读导演解释，反向描述实际对象、关系、变化或稳定状态；再恢复同期旁白核对条件、否定、先后和结果，不能靠标签改变物件身份。按本镜意图看精确首帧、切点、邻镜和完整连续窗口；操作镜头检查准备/接触/反应/落定，静态关系、揭示和生活情境不强套动作链、前景视差或动作数量。联系表、strip、1 fps 帧、代码分数、ASR、响度和布局只定位各自问题，不能代替正常速度的连续观看、完整听感或医学判断。
