# 视听与医学复核验收

评审方法见 `runtime/workbench/docs/38_纸剧场动画新标准总纲.md` 与 `runtime/workbench/docs/39_逐集表意与段首完整性验收.md`。工程事实、基本表意与声音、表现力分开判断；本门用于依据当前实际候选作语义判断，不用形式数量或分数替代质量。

人物头部与手部、医学细节、运动连续性、字幕和旁白是否一致；静态筛选是否被误记成动态或医学通过。

评审依据实际产物及精确版本，由 AI/领域负责人判断含义与质量。文件存在、命令成功与自动检查通过只证明对应机械条件。证据不足写 pending，拒绝的素材不得用残留区间绕过。

方法、范围、审核角色及版本是否有据；静态图、源片和成片的通过不能相互替代。完整职责见 `docs/production-sop.md` 和本阶段专业 Skill。

## 纸剧场动画门

逐集先隐藏字幕、标题和解释标签，不读导演注释，反向描述实际对象、关系、变化或稳定状态；恢复同期旁白后检查事实、条件、否定、先后和结果是否同向。必要名称、数值和限制可以由标签/旁白补足，但不能用文字改变错误物件身份。表意含糊或误导时回最早导演、素材或实现环节，不以增加标签补救。

根据本镜解释任务判断注意力是否清楚、标签是否必要、关系是否可读，不固定动作或标签数量。线段应有指向、边界、固定件或所选风格的明确职责；大色块有可辨身份、层次或叙事用途，不为了装饰填空。静态科学关系和生活场景可以成立，不要求所有物件都进入、折叠或操作；无法说明用途、抢走焦点或造成误读的元素返修。

资产复核与动画复核分开：需要分别运动的部件应可独立控制，透明边缘在多底色下不能带图集残片、假棋盘或相邻物件侵入；整体使用的环境与复合纸件按实际用途判断，不冒充拆层。需要操作的手、人物和主体核对锚点及真实接触。技术检查通过、联系表好看或静帧无报错，都不能替代连续运动、声音稳定和医学复核。

检查精确第 0 帧、切入切出、核心事实区间、邻镜与结尾；有动作时查看实际极值、接触和结果，strip 的采样密度按疑点选择，不用固定姿态数量替代完整动态。首帧不得出现占位或未加载素材；字幕背景按必要可读性和场景职责决定。返修回最早缺口，先纠正表意与声音，再打磨构图、字幕和材质，正常速度动态未覆盖的范围保持待审。

独立文字可以直接存在；确有纸卡或条带时，核对文字与承载物是否匹配、是否被裁切、遮挡或压住其他内容。`scripts/audit_label_alignment.py` 的包络和偏移用于定位，不以固定居中值决定艺术质量；预期居中排版偏离、文字溢出或运动中失配时返修实际布局。对齐通过不证明文字必要或场景表意成立。

按本镜 `shot_recipe` 判断表意和因果。操作/接触镜头可检查 `prepare -> action -> reaction -> settle -> hold/rest`；静态关系、揭示、持续观察和生活情境不强套该链，也不强制前景视差。逐集核对所有语段首词、尾词与切换，声音来源到最终 MP4 的实际链路和实际听辨分别留证。代表集、分数、哈希、联系表或代码模式不能外推为其他集通过；已知表意或声音缺陷不得标 passed/ready 或混入用户最新版，候选与独立进度可继续。

每集必须保存自己的去文字视觉表意记录，至少包含实际对象、关系、动作或稳定状态、同期旁白、误读风险、修复改变和当前 MP4 复核范围；代表集、联系表、代码统计或系列摘要不能外推其他集。若 `mix-receipt` 输入哈希失配，先回媒体制作重混；最终 MP4 首词与接缝听辨另列，不能由源轨扫描、ASR 或波形指纹代替。

全季或批量复核先用 `scripts/build_episode_review_queue.py` 从当前工程与媒体指针生成逐集任务；随后逐集消费实际候选并记录覆盖范围。队列的缺项是导航任务，不是质量分或硬阻断，一集材料缺失时其余可独立审片继续。
