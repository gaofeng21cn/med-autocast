# 故事与联合时间轴

先看已有资产与当前旁白，按整篇观看任务共同设计讲述与画面。为每段写可见事件、解释作用、入出镜承接与准确区间。

输入为当前请求、工作区配置和上一阶段可用结果。输出：故事包、分镜、旁白、镜头与复用/生成缺口清单。已有结果可直接进入本阶段，资料缺项记录为待处理问题；身份、权限与当前版本不一致时停止依赖该条件的动作。按任务语义决定前进或返修，不启动第二 writer。

专业入口：`agent/professional_skills/medical-video-director/SKILL.md`。

纸剧场从完整场景设计进入分镜：写空间与主焦点、锚点物件、阅读次序、景别变化、跨镜状态和声音弧线。产物可为自然语言处理稿、风格帧、分镜与 animatic，不把医学旁白直接翻译成文字卡。区分环境板、透明主体和前景；关键行动与医学关系仍独立可控。方法见 `runtime/workbench/docs/22_纸面舞台与声音导演.md`。已有候选从最早缺口返修，材料欠项继续交接，不新增机器门。

推荐为每镜附自然语言 `shot_recipe`，写清患者读取任务、主锚点、主运动弧、承接物、声音职责、字幕安全区和已知风险。它用于导演与制作交接和返修定位，缺项不会阻断下游消费已有故事包。

分镜按纸片实际内容和叙事职责安排共现比例，同时调整位置、间距与前后层；区分独立物件、纸上插画和比喻装置，不按图片外框统一尺寸或强求实物等比例。比例判断保留在单集创作中，连续动作的尺寸和落点一致，景别变化可有意放大。
