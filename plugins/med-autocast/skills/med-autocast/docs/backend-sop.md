# 媒体后端 SOP

能力协议由后端目录持有，实例、模型、默认选择和密钥来源由制作工作区的部署profile持有；Agent不硬编码某台GPU或云服务。现有工作区的生产默认值不因安装Agent而改写。

在 workspace_root 下检查 scripts/media_backend.py 的帮助和 resolve 入口，再读登记SOP；只有需要当前服务诊断时才doctor。对未知入口先读实现及副作用，不能从配置任意执行命令。真实生成前核对已审首帧、完整提示、参考资产在服务端的真实引用、帧数、分辨率和模型限制。

按同一观看任务累计生成预算，默认一次；明确输入或调用缺陷最多一次定向修正。更换seed、提示或首帧不重置累计预算。未知能力实验单独立项，不挤占整季交付；模型漂移交导演更换已审方案，不随机重抽。

异步提交保存原任务ID和精确产物引用，断流先查queue/history。错误返回先分清已生成但解码失败、未生成、服务不可达，避免重复计费。不将完整base64、image_url、凭据或生成响应写入对话/回执。

媒体实际下载后用ffprobe验证解码、时长、尺寸和流，再审实际内容。视频自带音轨被后期丢弃不等于已禁用模型音频采样。记录去密参数、供应商/模型、运行ID、耗时和精确产物；不新建日常剪辑哈希机制。
