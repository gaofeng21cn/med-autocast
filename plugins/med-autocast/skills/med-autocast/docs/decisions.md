正式名称为 Med Auto Cast，技术标识为 `med-autocast`，领域为 `medical_video`。与 Med Auto Science、Med Auto Grant、Med Auto Practice 共用 Med Auto 系列命名；OPL 负责标准与发布。采用 Framework 标准声明式骨架，以 OPL Book Forge 为结构参考。将工作台十阶段归并为六个语义阶段、保留六个专业 Skill，不建立新的媒体调度器。关键帧留制作工作区，通过 catalog 检索。独立资格与本地开发验证分开报告，不伪造工程完成或资格。

正式发布复用 OPL Flow 的软件包工具与 Framework 的 publish-package.yml，以 OCI 不可变版本和 latest-stable 为准。不创建独立 ZIP 发布器；不创建或保留独立 GitHub Release 页面及附件。
