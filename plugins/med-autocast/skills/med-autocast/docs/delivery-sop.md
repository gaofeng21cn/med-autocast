# 成片与双平台交付

专业实现见[成片与发布 Skill](../agent/professional_skills/medical-video-release-packager/SKILL.md)及[系列 SOP 第 7 节](../runtime/workbench/docs/04_医学科普视频系列SOP.md#7-标准化发布交付)。先确定当前制作单和母版，确认包器匹配当前修订，不能默认根制作单或 final 比 review 更新。

S08 使用原通用合成器，按作者档案落实画布、字幕、固定品牌、头像策略、BGM 音量与淡入淡出；导演负责同期含义、镜头区间和相邻承接。S09 分别回读技术、构图、语义、连续动态、完整听感和医学审核。当前母版的构图复核不得直接继承被替换版本。

S10 文案只在登记 release_catalog 维护，含义变化交内容策划回溯事实和故事包；包器只物化。每集至少交付 video.mp4、小红书文案.txt、微信视频号文案.txt、发布交付包.md；根据原合同附字幕、审看/技术记录及系列 manifest。复制后回读视频字节、字幕、文案全文和版本，不重渲染已审母版。只改画面时按原要求比较整段解码音轨，不以 WAV 路径未变代替。

默认用 [preflight-workbench](workspace-adapter.md) 读取原合同；检查通过只证明对应引用和字节一致。审看包保留欠项，可按授权进入登记的 publish_root；不能另建平行交付入口。旧交付先保留恢复路径，单集更新不得覆盖其他集。公开上传需当前授权和平台回执，技术通过或进入 publish 不等于医学、听感或上传完成。
