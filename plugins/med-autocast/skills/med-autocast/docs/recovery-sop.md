# 中断恢复 SOP

卡顿或413时只恢复精简checkpoint、当前任务/队列ID、实际产物路径和剩余目标，不导入整段旧对话、base64或批量图片。

先核对原runner是否仍在执行、原queue/history和精确输出；存在writer就沿用，不重起第二个。以本次期望处理清单判断结束，旧ready汇总不代表新增任务已完成。已有有效产物不重跑smoke或重新生成。

恢复记录包括当前选集与修订、唯一执行者/任务ID、每集已完成和剩余项、下一条可执行动作、证据路径。令牌或会话恢复不能改变审查状态、重置生成预算或默认授权发布。

OMA工程请求也是一次请求：保存request_id及真实FoundryRun（如果有）。启动前失败只记录失败，不编造run或蓝图；修复入口身份后使用同request_id，先查持久状态避免重复执行。
