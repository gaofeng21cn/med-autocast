# Workbench 能力迁移验收

修复目标：Med Auto Cast 在 OPL 标准结构内保留来源 Workbench 的完整医学视频能力。六个执行阶段不取代原十阶段的专业交接；原数据、档案、作者授权和后端选择仍由制作工作区持有。

## 已补齐的能力

| 原职责 | Med Auto Cast 实现及验证 |
| --- | --- |
| 作者基线、受众、事实库、系列设计 | 总编排与内容 Skill；随包 01、04、09 号方法和作者/系列模板；按系列覆盖作者 |
| 单集叙事与配音前联合设计 | 内容、导演和视觉 QA 跨阶段参与；保留事实引用、完整故事板、版本冻结与代表样片要求 |
| 后端、配音、字幕和 H3 | 原工作台通用工具、后端定义及部署源码；官方提示直通、采样设置、回执先保存和断流恢复测试 |
| 后期合成 | 原 build_episode_video；字幕偏移、作者品牌、头像策略、BGM、混音、画布与构建记录；真实隔离合成验证 |
| 质量检查 | 原 animation_gate、技术 QA、联合时间轴；构图、语义、完整动态、听感、医学分别记录 |
| 交付与反馈 | 原 release_catalog 与双平台格式；正式 final 包器和原合同单集审看包器；字节回读、其他集保留、旧包恢复 |
| 资产与中断恢复 | 原关键帧库投影工具、72 张现有资产只读查询；拒用源处理、单一执行者与精简恢复规则 |
| 安装与迁移 | 随包通用核心及模板，配置根显式传入；不携带私人档案、媒体、权重或凭据 |

## 实际证据与边界

- 行为回归覆盖原字幕、H3 提示/采样、重复提交防护、动画合同、联合时间轴、原制作单兼容性、旧母版/错误文案/拒用源拦截和交付恢复。
- 真实工作区血脂单集使用原 v3 制作单、当前 review 母版、原 review_package/v1 清单：13 段镜头、视频复制字节和双平台文案全文核对通过。原源片审查缺少精确文件映射时保留证据缺口，不猜测批准。
- 隔离的原合成器运行产出 4.458333 秒、608×352、H.264/AAC 测试片，完整解码成功；字幕、品牌、BGM 和构建记录核对通过。单集审看包视频与母版字节一致，双平台 TXT 与原格式全文一致，重复交付保留旧包和清单恢复路径。
- 随包配置工具实读当前作者档案和后端选择，仍为工作台原 RTX 4090 视频与配音默认。没有调用 GPU、云模型或播放器，没有修改现有作品。

以上证明迁移实现、原工具复用和已验证路径；不把结构或测试结果当作医学内容验收。来源 Workbench 本来未验证的新后端模式仍保留原候选状态，Med Auto Cast 不宣称新增实测。独立 OMA 资格和新版本 OCI 发布/本机安装是另行回读的状态，见 [版本状态](status.md)。

## 后续维护规则

完整方法按需加载，不能为了缩短入口删除职责。修改专业 Skill 时回看原阶段输入、输出、方法和真实工具调用；增加工具要登记定位、依赖与副作用。改动制作单接口优先兼容原合同，不建立平行制作状态。验证按具体风险覆盖真实行为；单纯技能数量、文件长度、关键词匹配或安装成功均不证明能力等价。
