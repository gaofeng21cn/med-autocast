# 角色锁定与系列视觉差异化 SOP

状态：2026-09-09 补充全季与跨季差异化、短可用区间的成片复核

## 1. 唯一角色母版

当前作者档案的 `visual_identity.character_reference` 是唯一人物母版入口。启用人物身份的作者，只要镜头出现品牌人物，就要使用该母版或审定场景关键帧作为身份参考；文字描述不能替代参考资产。未启用人物身份时跳过人物锁定，不虚构人物要求。

必须保持作者档案 `visual_identity.traits` 与参考图中的稳定身份特征；明显改变发型、年龄比例、关键配饰或混入另一位品牌人物时，重新审核或淘汰。具体外貌只属于作者档案，不复制到通用 SOP。

场景关键帧可以由母版派生，但不得反过来成为新的角色母版。片头头像、场景人物、后期品牌头像必须能回溯到作者档案。现存后端目录中的旧图片只作历史快照保留。

## 2. 生成顺序

1. 先锁定旁白和镜头职责，核对已有可复用素材；缺口才生成。
2. 对含品牌人物的镜头，先制作单独审定关键帧，再按所选后端支持的方式输入。多主体场景不能用孤立人物母版替代完整场景设计。
3. 按后端已验收能力控制动作复杂度；当前生成经验优先每镜一个主要动作，不同时要求口型、复杂医学图和跨场景连续性。
4. 按作者档案在后期叠加字幕与品牌文字，生成画面不得自行排字、加角标头像或小窗。

## 3. 每集差异化预算

差异化服从 [解释对应与叙事连续性 SOP](11_解释对应与叙事连续性SOP.md)。同概念保留固定符号与布局，同事件保留顺序与病例；不同示例的转换应能被观众识别。不能为达成下面的变化项更换空间、人物或隐喻，导致解释线索中断。

有前篇可比较时，判断本篇的问题、主要观看对象和行动是否具有独立职责，并在 `production_plan.yaml` 说明实际差异。下列是可选手段，不再要求至少两项变化；不得为换场景而增加未验证生成：

- 不同的开场动作或患者生活情境；
- 不同的主空间（家庭、走廊、检查室、诊室、病房等）；
- 不同的镜头语法（俯视整理、侧向跟拍、双人并行、设备观察、物件路径、局部手部特写等）。

禁止把第一篇的“患者坐姿—解剖插图—桌面资料—医生对谈”顺序当作系列默认模板。相邻篇可因同一操作复用准确姿势和设备镜头；应检查它是否承担本篇必要解释，不能让通用对谈和资料镜头包办各篇内容，也不能把复用本身当作必须重生成的错误。

功能素材可以跨篇复用：前三篇共享已核对的鞍区关系图、信号、视野检查或到院动作，但分别服务报告评估、急诊行动和症状路径。审核看主叙事是否不同，不为了差异化重新生成一个已经合格的机制图。

首篇无上一集，只记录系列角色与视觉基线。当前第一篇用 `director_contract.series_visual_role`，manifest 如实记 `first_episode_baseline_no_predecessor`；不写会触发“已对照上一集”要求的 `director_contract.episode_visual_delta`。后续篇对照实际前篇已审版本并注明路径，未发布不能称为上一已发布篇。

同一事件中的患者及家属保持身份与场景连续。第二篇曾出现老人儿童、女性患者和母婴场景，本轮换回中年夫妻及对应行动；第一篇借用其急诊画面时明确为另一段情境例子，不伪装成同一患者连续剧情。

### 3.1 全季复核经验

同一段医生对谈、递资料、药盒或整理本子，即使裁切、变焦、改名、换标签，也仍是同一素材。不能以文件名不同或逐帧哈希不同证明新镜头；必须从实际人物动作、空间、观看职责及生成来源判断。第10篇曾出现同源对谈裁成多个 close 版本，这类处理不计入去重复成果。

先按全季镜头表找出被泛用场景占据的解释区间，再为真实缺口设计本篇场景：如急症到院、核对外源激素、异常化验复核、共同选择治疗、病房即时沟通、居家长期档案。机制、MRI 和视野等功能素材可以保留，但不能用同一套通用对谈包办每篇的开场、解释和结尾。

本轮人物关键帧曾出现年龄、发型和衣袖身份差异，先在图片阶段修正再做 H3；同一事件需要连续身份，不同检查示例可为不同患者，必须在导演意图中明确是示例而非同一人的连续病程。普通临床人物不登记为品牌角色。

去重复的验收对象是最终时间轴：新素材必须真的替换生产单、manifest 与母版，并同步发布包。回执和候选目录已有新文件不能证明患者将看到新版本。

### 3.2 全季与跨季时间轴复核

生成前按真实源片、动作及实际使用区间，比较各集开场、核心解释与收束；多个系列共享素材库且纳入本次任务时一并比较。逐集相关不代表整季有独立观看信息。机器统计源片覆盖集数和使用秒数用于定位高复用段，导演判断通用场景是否包办不同问题；不能用文件改名、裁切或新生成数量证明差异化。

源片准入后按实际合格时长重新编排整篇。短区间反复插入、同一动作多次从头开始，可能使去重复变成碎镜；不要为了增加新素材秒数或占比而保留。优先合并意义连续的段落、减少插入，或接入已审且与同期解释相关的对象与结果。源片自然、单个切点合格仍不能代替整篇节奏判断。

交付前重新核对最终时间轴及实际母版：新画面承担什么独立信息，重复是否转移到另一通用场景，动作是否反复重启。保留前后源片使用统计和语义结论，按系列SOP第7—8节同步当前publish；没有新生成也可能完成合理修订，新生成再多也不自动通过。实际案例与规则走查见[两季修订复盘](production-lessons.md)。

## 4. 验收

按实际对象记录：

- `brand_identity_match`：含品牌人物的镜头必须与作者档案的母版一致；
- `episode_visual_delta`：有前篇时记录所比较版本和可见变化；首篇按上节记录基线，不虚构比较。

不满足时回到导演重设，不用字幕、裁切或后期贴图掩盖角色漂移和同质化。

片尾已有品牌医生时不再重复叠大头像。当前合成器中 `brand_character_segments` 非空会关闭所有额外头像叠加；应按真实人物镜头填写，无人物镜头时需要关闭头像则用 `--no-avatar`。准确生效规则见 [配置文档第 7 节](09_工作台配置与档案.md#7-作者设置怎样生效)。

## 5. 关键帧沉淀与复用

生成前先查[关键帧资产库](../../../docs/keyframe-library.md)及看图目录，按观看任务、场景和人物关系选参考，再决定复用、派生或生成真实缺口。原图以独立副本保存在assets/keyframes，catalog维护分类、来源、实际看图范围和使用边界；品牌人物仍从作者档案读取。入库不能把关键帧审核、关联视频审核和当前成片批准合并。

有参考价值且来源明确的图在实际查看后入库；截头、无头躯干或关键医学关系错误的候选先记录原因。修正版保留原来源，用新ID关联旧资产，不覆盖原图。新场景生成或返修收尾时判断哪些关键帧值得归档，不机械保存全部候选。使用时把资产ID与实际路径写入现有制作单并登记引用；全季重复仍按第3.2节核对。详细字段及目录更新命令只在资产库README维护。
