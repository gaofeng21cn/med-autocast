# 解释对应与叙事连续性 SOP

版本：2.4，2026-09-09。适用于新系列及明确授权的旧片优化。详细规则由本文件维护，[十阶段总SOP](04_医学科普视频系列SOP.md#0-十阶段流程与交接)和相关专业Skill引用；不反向把旧片标记为通过本SOP。H3官方、社区与医学教育证据，以及调用验证顺序见[调研与制作策略](12_H3调研与制作策略.md)。人物构图最低质量与交付复核案例见[构图复盘](production-lessons.md)。

## 0. 视觉视频的首要原则

用人物行动、具体物体和可见关系推进理解；旁白解释原因与医学边界，字幕保障可读，短标签帮助定位。画面与解说对应不等于把每句话改成文字框。医学准确、视觉叙事和稳定实现必须同时成立，不能用任意一项替代其余两项。

2026-09-07 高血压候选被用户否决：大量纯色背景、逐条文字框、固定标题与少量人物片段形成课件。第6集力量练习只显示提示，第7集以“药物A/B的途径”替代实际关系。文字显隐被归入确定性动画，技术检查没有拦住视觉形式错误。旧 `work/hypertension-s01/render_*explanation*.py`、`render_remaining.py` 只作失败复盘，不是新系列模板。

本节统一解释下文和旧制作文档：复杂画面生成失败不能自动退回泛对谈，也不能自动改成文字列表；应保留观看任务、换成更容易拍清的具体对象或动作。精确关系优先后期控制，指在审定对象上表现位置、方向、变化和对比，不等于整屏文本框。生成时长比例与像素变化只核查来源和媒体，不能批准观看形式。

### 0.1 最短可靠生产路线

1. 内容和视觉共同设计：先确定一个患者问题、可见事件链及最后行动，再形成可朗读旁白。列出必须看清的对象、必须说清的条件、无需重复上屏的解释。视觉无法成立时在配音前简化内容或重新表达。
2. 整篇故事板同时放入场景全景、必要近景、精确信息出现位置和旁白。判断观众的注意力怎样从一个对象转向下一个，不按段落套固定六镜模板。
3. 先让基础版本有可执行的画面：逐段绑定已有可用源区间或已做出的审定对象及后期表现。新H3镜头可能失败，必须预先有能接回同期解释的替代素材；只有替代构想、没有资产和实现时，该段仍未准备好。先解决基础表达缺口，不把攻克最难镜头作为开工条件。具体规则见0.4节。
4. 样片必须是一篇完整视频，包含本季常见场景、实际动作、精确信息和收束。按0.3节实际复核后再扩展同类制作；没有用户反馈时由制作方负责基于证据判断，不把流程变成重复索要批准。用户已否决的形式必须重新设计。
5. 画质验证按当前制作阶段安排：用户要求快速迭代时，先固定已有尺寸完成内容和形式，不能把高清试验放在前面。当前高血压明确使用608×352。以后确需提升清晰度时才比较配套采样与画布，回读实际成片尺寸、动作、字幕和品牌。复用已验证参数、角色参考、字幕与合成工具，不复制整篇镜头排列；每篇独立检查主要事件和切点。
6. 已有旁白准确、节奏能容纳新画面时复用声音；如需修改论述或修复读音，只重做命中部分及其时码。不能为保留音轨强行塞进文字课件。

“一步到位”的实际目标是新生成未被采用时，整篇仍能沿预定方案完成，不临时重写全片或改成文字课件。基础版本仍须符合医学含义、观看形式和真实素材合同；未备齐不能宣称下限已保证。记录全部尝试和可用源区间，不承诺未经实测的首次成功率。

### 0.2 画面与工具分工

| 观看任务 | 稳定实现 | 不可接受的替代 |
| --- | --- | --- |
| 看见生活行动 | 优先使用已核对的动作区间；新生成一次简单动作，按预定替代处理失败 | 用无关点头、走路填满核心段落 |
| 看懂操作 | 审定全景建立姿势，固定近景展示关键位置；确需演示安装过程时先取得准确示范素材 | 让H3自行完成袖带安装，或只显示“正确操作” |
| 看懂数量、标签 | 血压计、记录本、食品包装等具体对象承载后期数值与局部高亮 | 全屏标题、长句与圆角框列表 |
| 看懂机制和比较 | 审定具体结构/对象及其状态，用确定性局部变化控制关系 | 给“机制A/B”文字框加箭头冒充解释 |
| 理解决策条件 | 清楚区分的患者情境与行动，必要短标签明确分支，旁白保留条件 | 让不同病例像同一人连续发生所有后果 |

镜头先呈现对象，再加入必要标签。主画面不预留固定文字半屏，不持续挂段落标题。字幕与医学条件不能为了“少字”删除；长解释留在声音，精确信息在需要观察的时点进入相应对象。静态结构短暂保留便于辨认，但不能用推拉、标签显隐或装饰粒子改报动画。

提示词按实际模式使用[官方格式的本机适配](../../../agent/professional_skills/medical-video-director/references/h3-prompt-design.md)，描述`已审首帧 -> 一次可见变化 -> 剪辑可用落点`。首帧提供外观与布局依据，不能保证后续帧正确；精确对象不交给H3重新绘制。运镜只有在失败也不丢失必要信息时才作为增强，不能靠locked-camera等文字承担可见性保证。新生成与失败处理统一按0.4节，不逐镜发明重试规则。

本版吸收图词邻近、解释同步和减少无关信息的多媒体学习原则：物体/关系在对应旁白出现时可见，短标签贴近对象，同一时刻有明确注意中心。保留无声观看与听力需求所需字幕，去掉重复整段讲义；不把一般学习实验机械套成删字幕或“动画越多越好”的规定。

### 0.3 形式验收在技术验收之前

- 去掉解释性文字层，主要人物行动、物体变化或关系是否仍可辨认？纯数字阅读段不强求无字成立，但应依附真实观看对象。
- 保留旁白和字幕，观众是在观察事件，还是被要求连续读几页文字？人物是否只是给文字当背景？
- 每次切镜是否承接前镜对象、动作或明确的新情境？连续性不等于不切镜、同一姿势或同一人物重复出现。
- 讲操作时是否实际展示关键动作，讲关系时是否实际呈现关系？不要求逐词图解，不容许核心信息只靠话题标题。
- 将新样片与用户偏好的垂体瘤第1集实际抽帧对照，看具体对象、景别变化和信息职责，不照抄其场景或未经验证的医学示意。

上述是基于画面和同期旁白的语义判断，不以字数、固定比例或关键词自动评分。记录当前视频路径、对应制作单、镜头和检查方法；未做连续动态/听感的部分单列pending，不把技术通过或旧approved继承成形式通过。样片未通过不扩展同类渲染。

### 0.4 先保证下限，再增加效果

2026-09-08补充：人物构图属于最低可接受质量。人物中景/全景保留完整头部与构图余量，首帧建议头顶留约画高8%，并兼顾双手和关键物体。不是仅在提示里写“完整头部”就算完成：首帧、源片全选用区间、成片字幕叠加后分别检查，推近和站起区间加密。所有人物都检查，不能只看主角。半头、切掉头顶或只剩躯干不能以“手部近景”放行；真正物体特写采用纯俯拍对象与自然伸入的手臂，不留下大块无头身体。

修复按源片成因处理：选取构图完整的区间，或换用已经审过且同期含义相符的素材；源片本就缺头时不能靠缩小加边冒充补全。共享合成默认contain/pad，禁止默认fill/center-crop；确需裁切须生成显式资产并复核人物与信息。此次高血压源片与画布均为608×352，直接成因是关键帧/提示的躯干构图、H3推近和视觉漏判，不是合成器额外裁切。未来不同宽高比由保留全幅默认值防止新增问题。

修复前归档旧成片和审核，修复后重新生成后台QA与有序帧序列，逐镜绑定当前成片及制作单记录构图结论和实际检查范围。共享素材变更核对全部引用集，统一更新publish；未改音轨和医学内容则保留原WAV/SRT与文案。机器核对文件、尺寸、实际源区间与审核绑定；同路径文件被替换后旧结论失效，复制交付时逐字节回读，视觉语义由实际看图判断，不能用关键词或检测器分数代替。此流程降低漏检风险，不作永不出错的保证。

**基础版本和增强版本是同一时间轴的素材选择。** 基础版本也要有与解释相关的真实动作、具体对象和连续关系，符合现行交付合同。增强可以更换一个动作镜头或景别，但不能引入新的医学事实，不能靠其成功补齐原本缺失的核心解释。无需另建生产系统，选择及依据记在现有镜头卡、制作单和检查记录中。

先分清三种证据：已审的某段文件可直接复用；若干同类任务成功只支持有限尝试新镜头；官方支持或单张正确首帧仅证明可试，不能算稳定生产能力。某个已生成长片段可用，也不能推出下一个长片段会持续正确。

生成前，每个新镜头说明当前原句、必须看清的内容、基础素材及可用区间、增强希望增加什么、失败后接回哪一素材。关键数值与条件由审定文字控制；需要精确的位置、设备和结构由审定画面控制。移动屏幕、旋转包装、手遮住标签后再后期追踪，会新增不确定性，基础版优先固定物体近景及现有合成能力。

当前H3生活动作可从约4-6秒的预期使用区间起步，具体请求按模型帧网格和动作长度决定。这是限制暴露时间的起点，不是成功率结论；不强求截取开头，不机械把10-14秒旁白分配给一个新片段。动作说清后即可切到相关对象或结果。长旁白若只有相关点头撑时长，须重新设计表达；旧音轨仅在仍适配时复用，必要修改保留医学条件并重新对齐命中部分。

**重试预算按同一个观看任务累计。** 默认新视频一次；模型自行添物、变形、伪字或漂移时，采用已有合格区间或预定替代。同类已有反复失败证据时不再试。只有错误首帧、错误字段等明确输入/调用缺陷，允许一次针对性修正；换关键帧、提示词、seed、模式或镜头名称不重置预算。图片资产同样不能反复抽到“碰巧正确”：已知难点优先已有准确资产、范围明确的编辑或审定图示制作。确有新能力值得探索时单独选一个问题作有界实验，不作为本季交付依赖。

替代方案不能写成“再生成一张”“后期解决”或“换成图解”。它必须有具体资产及可运行实现，并能表达同一句的对象与关系；否则先完成这个基础素材。审定插图不必被强行做成会动的图，静态如实登记，但整篇不能由静态保持、文字显隐或装饰运动组成。不能降低生成/静态阈值、重复素材或伪报类别来掩盖基础版缺口。

基础版本形成后先排一篇完整样片，查形式、同步与切点；成功的简单生活片不替测量、机制、急症分支背书。按出现的新表达问题补最小范围的核对，已有证据不重做。QA负责识别实际残留问题；复杂度、备选、时长及字幕容纳应在生成前处理。

2026-09-07整季扩展补充：字幕预排不能只取一句的中点。一条字幕跨镜时，须同时查看它覆盖的两幅构图，尤其是姿势段为避脚上移的字幕进入记录近景后，可能压住脚注；确定性图示要预留所有字幕行实际覆盖的区域。高血压第3、4集已发生并修正这两类问题。先检查跨镜字幕和图示文字的组合，能把这类返工留在生成前；固定对象插入如实登记，不能为追求运动而重新生成精确医学结构。

## 1. 已观察到的差别

依据：2026-09-06 对当前垂体瘤第1、2、3、9、10集及糖尿病第7集的生产单、旁白/SRT、分镜中点成片抽帧与合成脚本的比较。这是解释结构和画面对应核对，不是完整音画试听，也不是医学终审。

- 垂体瘤第1集以“激素、视路、大小与变化”总览、分解、回收，约36–49秒的信号、49–64秒的位置及视野、64–78秒的影像对比有具体解释职责。其优势主要是观众能追踪问题，不是绝对同一人物、全部生成动画或不复用素材。
- 第2集40–49秒已在病床接受评估，49–56秒才到院，局部相关的镜头组合成了倒序事件。
- 第3集的三路径先后换用轨道、管道、玻璃柱、网络、纸带，增加重新理解符号的成本。
- 第10集65–73秒用视野检查承接解除压迫、控制功能性肿瘤、持续生长等手术目标，评估动作未解释治疗目标。
- 糖尿病第7集10–22秒的四药盒只表示“药不同”，未解释旁白中的肝脏、胰岛素、尿糖、肠道机制。

这些观察不能外推为其他集均差或既有技术检查无效。技术合格、单镜稳定、没有明显矛盾和整篇帮助理解是不同结论。

## 2. 先确定整篇如何理解

每篇先写清观众的问题、最后应形成的判断、主要行动，以及一条可追踪的解释路线。按题材选用：

- 解释或比较：具体总览 -> 逐项展开 -> 回到同一总览 -> 下一步。不是所有主题都强制三项。
- 行动事件：起因 -> 识别 -> 行动 -> 结果/后续，保留真实时间顺序。
- 操作示范：准备 -> 操作 -> 记录/判断，精确设备姿势优先使用审定画面。

每篇选择一个主要病例、空间或图示作为锚点。解释插入后回到已建立的对象；不同患者或情境确有必要时，在观众能看到的表达中说明“另一种情况”“检查示例”，只写在内部导演意图里不足以消除身份误解。示例转换不强求一个患者接受所有治疗。

同一个概念保持同一图标、方向、配色、布局和名称。跨篇可复用视觉语言及准确功能图，不照搬整篇镜头顺序。差异化服从解释任务，不为换房间、衣服或机位打断故事。

## 3. 按关系与行动分镜

先保留原句中真正需要理解的关系：谁作用于谁、什么增加或减少、何种条件下选择何种行动。不得在分镜时把这些关系压缩成“综合评估”“药物不同”等话题标签后用通用对谈填满。

每个镜头卡除了原有时码、原句、源区间及动作，还说明：

| 内容 | 需要解决的问题 |
| --- | --- |
| 观看所得 | 患者从图中能看出什么关系或行动？只看药盒不能推断药理机制 |
| 解释职责 | 直接解释、操作示范、情境承接或总结；情境承接不能包办核心解释 |
| 前后承接 | 上一镜的哪个对象引入本镜？结束时哪个对象留给下一镜？ |
| 连续对象 | 同一人还是不同示例？固定场景、道具和图示语义是什么？ |
| 实现方式 | 哪个已有素材或已验证实现承担基础表达？新生成只是增强还是仍是未解决的依赖？失败接回哪里？ |

这些是导演的语义判断，不能用字段齐全、关键词、固定镜头数或比例代替。可放入故事包的 `continuity_design` 与逐镜 `explanation/connection`，无需为了新字段改写历史回执或所有旧Schema。

一个旁白节拍可以有多镜，也可以与相邻节拍共用一个动作；边界跟随理解对象变化，不按段落数量自动一一配镜。一句话列出四种机制时，逐项显现或有序高亮；若时间不足以理解，回到旁白精简，不用快速闪切塞入。

## 4. 分工与提示词

H3负责其当前已验证的自然动作、情境和简单可见变化；精确解剖、阈值、曲线和文字优先由审定图示及确定性后期负责，并按0.2节进入具体对象。比较与决策先选可见对象和患者行动，只有必要关系才补图示。图形变化必须表达信息变化，不能靠平移、缩放、文字显隐或无意义粒子运动伪装解释动画。素材类别和时长按真实来源声明；不为通过生成占比而削弱医学解释，也不为易于编码牺牲视频形式。

场景关键帧必须实际查看。优先从同一已审场景派生近景或局部，避免所有镜头各自文生造成身份和布局漂移。图片编辑与尾帧能力按实际后端合同及验证结果使用，不声称输入参考图就必然锁定身份。

动作提示围绕“已审开场 -> 可见发展 -> 剪辑可用落点”，明确主体和空间关系。例如已有资料交接动作接固定记录近景，后期在近景加入准确内容；无需模型把资料正好转到指定角度。FL2VA、Ref2VA、AddGuide/latent context留作解决明确问题的独立试验，不能以“可验证”代替本次可执行的基础镜头。

不要把“one continuous scene”当整篇连续性保证。相邻镜头的连接由导演设计、关键帧和剪辑完成，不依赖模型自行跨家庭、诊室、病房生成长剧情。失败按0.4节接回预定表达，不用新的提示或模式开启下一轮相同探索。

## 5. 先审整篇再投入生成

先用已有素材及必要对象状态排整篇故事板，不先为整季生成全新的关键帧。顺序检查患者能否追踪问题、符号是否一致、事件是否倒退、解释是否被泛动作替代。必要图示先做出并检查，不能把“确定性后期”作为未实现的承诺。需要判断节奏时做带最终旁白的animatic；它只验证设计，不当成正式成片。

先完成一个具有本季代表性、包含自然动作和精确解释的样片，核对整篇之后再扩展同类制作。已验证单一动作只证明该动作，不证明整季解释效果。批量可处理独立技术步骤，但共享GPU及同一集权威文件保持单一写入者。

故事板发现错位先改设计，再生成；候选自然但解释不成立时调整素材/时码或重设，不用标题补救。不得为了照表执行重新生成已有合格声音或素材。

## 6. 验收与证据

成片结合旁白逐镜判断：画面实际增加了什么理解？每次切换为何在此发生？同一图示、病例、动作是否承接？观看是否可能把检查当治疗、不同例子当同一病程、示意变化当疗效保证？

分别记录单镜动作、逐秒图文对应、相邻切点、整篇解释连续性、完整听感和医学终审。实际只做抽帧或SRT对照就写清范围，完整音画未做仍pending。解释不足可记为需优化，明确错位或误导必须返修；旧技术QA或manifest的approved不能继承为新语义通过。

机器核查源文件、时码、缺口、Schema与媒体可解码；AI/实际审核负责解释力度、连续性和医学含义。定时图示可确定控制，H3的动作和形变需验收；新SOP的成片效果与一次成功率须以新制作实测，不提前承诺。


## 7. 本机后台复核方式（2026-09-06）

用户明确要求不直接操作播放器播放视频，避免影响电脑使用。本工作台后续不自动打开或控制QuickTime、浏览器视频播放器，不发出声音。先在后台完成全片解码，导出覆盖全时长的有序帧序列，关键动作和切点前后提高采样密度，按原旁白/词级时码核对解释出现顺序，再检查字幕、品牌、音量和ASR差异。不得把离线抽帧、播放到结尾或音轨解码写成完整听感通过；工具不能覆盖的听辨和连续动态检查如实单列。

### 7.1 从缩略联系表到清晰切点

全时长联系表用于发现整体走势、重复和疑点，缩小图不能批准微小伪字、数字、手部或头顶边界。源片所选区间首尾、全部新增或改变的切点，另用足以辨认源画细节的尺寸检查，并对照实际成片、字幕和制作单；放大低清缩略图不能恢复已丢失细节。切点两侧少数帧只能证明边界；动作重启、空间跳变等疑点应扩到前后有序窗口。

发现边界接近污染、推近截头或动作变形时，在临界区间加密至逐帧，定位最后合格帧与污染起点，并按实际剪辑帧率、变速和源时码核对最后使用帧。不能机械用“首次看见坏帧减一个采样步长”确定安全区间。缺陷影响整个任务含义，或无法确认干净区间时停用该源，接回已审相关素材；不因已有可用秒数而保留。所有人物均检查，不能只看主角。

源片准入以最新审核结论及允许区间共同决定；accepted为false时，即使历史usable_range尚在也不得使用。收窄区间或停用源片后，核对所有引用它的实际时间轴，交导演按合格时长重新编排。重建受影响成片及其联系表、清晰切点证据并实际复看，旧图和旧批准不能继承；短片反复插入的整篇节奏按[差异化SOP第3.2节](07_角色与视觉差异化SOP.md#32-全季与跨季时间轴复核)判断。

记录源片与成片各自路径、源区间/成片时码、实际尺寸与采样密度、所看范围及结论。日常剪辑不新增哈希；正式工具已有的校验字段按其适用合同保留，见[系列SOP第7.1节](04_医学科普视频系列SOP.md#71-单集更新与回读)。这些后台检查支持所看范围内的结论，未完成的连续动态、完整听感与医学终审仍为pending。

首集解释版实测还显示，人物小窗与长段旁置文字虽然加强字面对应，仍容易呈现课件感。日常承接与交接镜头保留全画幅人物场景；只有阈值、比较、步骤等直接解释才使用局部图示。最终构图下核对标记坐标，不能按原图坐标猜。多日示例用省略明确持续记录，避免被误读为固定天数。候选文件与实际检查范围见高血压首集review目录，不能据此宣称全季或新提示词已一次通过。
