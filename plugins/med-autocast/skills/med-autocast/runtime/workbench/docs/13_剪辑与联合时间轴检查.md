# 剪辑与联合时间轴检查

日常剪辑优先复用现有素材、PIL/FFmpeg与主合成器。把对象出现时机对齐实际旁白，用同一张图核对画面、波形、字幕和切点，减少来回定位。此方法用于S08剪辑与S09成片检查，由现有导演和视觉QA承担，无需新增独立剪辑Skill。

## 一条命令检查单集切点

在工作台根目录运行，使用现有Python环境、FFmpeg及配置字体：

```bash
.venv/bin/python scripts/build_timeline_review.py \
  --series hypertension_s01 --episode 04_no_symptoms \
  --all-cuts --output-dir work/hypertension04-cut-review
```

工具从系列登记找到`publish`中的视频，从本集`审看记录.json`读取`srt_source`及`segments`切点；不根据可能过时的根目录制作单猜测当前成片。当前自动入口适用于这种记录结构，其他素材使用下方显式路径模式。每次使用新的输出目录，避免覆盖原素材或已看过的检查图。

默认每个切点取前后各1.5秒、8张有序帧，可用`--radius`和`--frames`调整。输出PNG、同名JSON及纯静态`index.html`，没有播放器、脚本或自动发声。JSON保存输入路径、取帧请求时刻、字幕、可选词时码和实际检查范围。

日常剪辑检查不计算或强制校验文件哈希。这里只检查来源路径、集数、时间范围及切点是否超出视频；旧记录作为时码输入，不继承其审核结论。相同时长不能证明内容相同，改剪辑后应使用对应版本的切点与字幕，并直接看当前成片。不要用文件校验代替画面与解说的判断。

## 检查候选或局部解释段

```bash
.venv/bin/python scripts/build_timeline_review.py \
  --video work/editing-pilot-20260908/episode04-trial.mp4 \
  --srt productions/hypertension_s01/04_no_symptoms/audio/local_voice/narration.srt \
  --start 20 --end 26 \
  --output work/hypertension04-explanation.png
```

需要切点线时加`--cuts 22.5`，使用真实全局时码。需要词级辅助定位时，同时加入：

```bash
--alignment productions/hypertension_s01/04_no_symptoms/audio/local_voice/whisper-alignment.json \
--beats productions/hypertension_s01/04_no_symptoms/audio/local_voice/narration_beats.json
```

Whisper文件是节拍局部时码，工具加上对应节拍起点。例如本集“脑”从局部1.12秒换算为全局22.05161秒。仅在候选沿用相同音轨和排时时复用这组数据；音轨重排后使用新时码。ASR用于定位，错字不能替换审定字幕。长字幕自动换行，密集词标签分三轨显示，放不下的注明省略数量，JSON保留完整词表。

## 如何据此剪辑

- 看上一句话何时结束、下一画面出现时正在解释什么，再决定切点；器官标记和关系变化按实际旁白出现，避免机械等间隔播放。
- 只调整画面时保留整条旁白音轨；不要为了视觉切点切断语句或无意义增加淡入淡出。
- 抽帧仍要判断人物头顶、脸、下巴和画面边界；波形只帮助定位静音、节奏与声音变化，不证明听感。
- 按问题范围复查改动段及相邻切点。检查图状态始终从`pending`开始，交给现有单集审核记录写实际结论，不另建一套审批流程。

本工具帮助定位，不能单独证明全片连续动态、完整听感或医学终审通过。用户要求后台检查时持续使用离线图与音轨分析，不打开或操控播放器。

## HyperFrames的适用范围

简单标签、箭头与关系图继续使用PIL/FFmpeg。只有复杂可控动画确实需要统一时间轴、浏览器布局或对象运动编排时，才考虑HyperFrames局部插入，再接回现有合成器；不因此更换H3、配音或全片制作方式，也不把视频变成文字PPT。

实测版本为`hyperframes@0.8.31`、`gsap@3.14.2`，隔离安装。第04集简单图示试验中，HyperFrames渲染全程17.158秒，原PIL实现4.433秒，没有提速收益；标记与旁白的对应改善来自时序设计，现有工具同样可以实现。上游来源、版本、素材与范围见[试验报告](production-lessons.md)。
