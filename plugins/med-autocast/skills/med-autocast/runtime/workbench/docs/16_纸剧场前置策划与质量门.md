# 纸剧场前置策划与质量门

更新：2026-09-28。本文把成熟动画工具包的创作方法落到本地医学科普工作台。主线是导演处理、分镜、风格帧、粗动态分镜、逐镜剪辑和审片；JavaScript 是实现媒介，技术检查只辅助发现故障。医学事实仍由事实库与医生复核持有。

2026-09-29 修订：本流程现在以[纸剧场导演流程与质量框架](18_纸剧场导演流程与质量框架.md)为总纲。所有新集先通过“去文字视觉成立”门，再进入精细素材和代码；线段、色带、字幕底纸和轻微抖动不再作为默认补位手段。当前 v13 审计显示，第一幕手部素材有图集残片/非透明背景，机制幕和急诊幕仍有缺少物理来源的线段，因此该版本只能作为返修样片，不能成为风格母版。

## 2. 创作顺序：先导演，后编码

1. **创作简报**：一句患者问题、一处常见误读、一个看完能做的行动；列出不可暗示的医学结论。
2. **视觉处理稿**：选贯穿的实物母题、纸张世界、材质对比、功能色、光线、镜头视点和声音情绪。至少给两张风格帧，说明为何它们属于同一片。
3. **分镜与 beat grid**：每镜先写观看任务、主体、景别、走位、动作起点/发展/落点、下镜承接和声音事件。不能把旁白逐句翻成标题卡。
4. **粗动态分镜**：用简单纸片加临时旁白搭一条完整时间线。先看节奏、景别变化、字幕位置和故事是否独立成立，再投入精细素材。
5. **分层资产**：按动作拆透明医学主体、情境物件、前后遮挡、阴影、纸纹和可见接缝。用 ImageGen 或有许可的网络素材补真实缺口，不用一张大场景图冒充分层素材。
6. **逐镜实现与审片**：每完成一个镜头就看起点、连续动作、落点和切点。可用 HyperFrames storyboard/Studio 或本地 HTML 预览作为审片面；导演意见指向具体镜头和元素。
7. **整片联审**：画面静音看故事，再配旁白听节奏，最后看字幕、音乐、音效和医学画面。问题若在故事层就回分镜，不靠更多脚本、线段或标签修饰。
8. **编码与交付**：技术检查只确认可运行、无丢素材、时码与画幅正确；完整观看、听感和医学复核仍分别记录。

这八步是推荐的交接顺序，不是阻止 Stage 继续的硬闸。缺少故事卡时可以继续粗动态、备选方案和可消费诊断；关键姿态或单件素材未通过时，可以继续不依赖它的镜头，并用 pending 素材生成明确标记的审看候选。被拒绝的素材必须排除；医学表达没有安全替代时省略该镜头并记录欠项，不得臆造解剖。质量债随结果交给下一 Stage，不能宣称已通过、ready 或进入发布；只有相应证据齐备后，才将候选提升为正式成片。

## 3. 质量下限：先让初稿成立

初稿在准备精致材质前必须过五个低成本门：

1. **问题门**：一句话写清患者想弄明白什么、原来的误读是什么、看完能做哪一步；不能用疾病名或章节名代替。
2. **事件门**：每镜至少有一个起点、一个可见关系变化和一个落点；画面静音且暂时隐藏标签时，仍能说出发生了什么。
3. **读取门**：每镜列出观众的读取顺序；重要读取不能重叠，移动后必须有停留，长句不能靠缩小字号塞进卡片。
4. **资产门**：医学主体、生活物件、前后遮挡、阴影和文字层职责分开；大场景图只能作背景或风格稿，不能冒充可操作透明层。
5. **技术门**：首帧和切入帧不是空舞台；本地项目能预览、定位镜头和稳定重现画面。静帧、联系表、浏览器错误报告只帮助定位问题。

任何一门失败都先退回故事卡或素材计划，不能用更多线段、标签、粒子、随机抖动或淡入淡出掩盖。

## 4. 从选题到一季故事

### 3.1 先做患者问题地图

从事实库和来源提取四种对象：患者正在经历的处境、最危险的误读、需要改变的判断、可执行的安全行动。为每个问题写 `question_id`、受众情境、核心事实 ID、条件/禁区、最小前置信息和独立观看边界。视觉参考另记来源、许可、医学用途和不可暗示项。

### 3.2 用认知任务拆集

两个问题只有在“判断、证据和行动”都相同，且可由同一个物件变化讲清时才合并。不同急迫性、不同鉴别路径、不同检查职责或不同治疗决策必须拆开。每集可以独立观看；前集悬念不能成为本集安全边界的前置条件。低频亚型是独立支线，不强迫所有患者按教材顺序经历。

### 3.3 建系列故事圣经

系列圣经至少冻结：系列承诺、患者旅程、分集顺序和依赖、共同纸张世界、跨集锚点物件、材质和功能色、固定品牌露出、可复用资产职责、不能整套复用的镜头组合。品牌只读取作者/系列档案；Dr.咩 的纸章、下划线和盖章属于本系列档案，不进入通用 Skill。

每集故事卡采用以下句式：

```text
患者想弄明白 ___，但把 ___ 误认为 ___；
一件物件先 ___，随后因为 ___ 发生变化，
最后变成 ___，患者下一步是 ___。
```

### 视觉锚点优先

分镜先回答“哪个物件或动作改变了意义”，再决定是否需要文字。每集先列出 3—5 个可操作的视觉锚点，并为每个锚点写明进入位置、承载面、动作和落点；主要节拍应由物件、手势、视线或物件之间的关系承担，字幕和短标签只做确认。把字幕、标签和装饰全部隐藏后，观众仍应能说出本镜发生了什么。

大面积色块、色带和文字承托必须有可见的物理来源与叙事动作，例如一张被掀开的纸、一段胶带或一枚印章；如果不能回答“它是什么、为什么在这里、接下来如何变化”，就删除。文字默认独立排版，不能先画一个背景区域再把文字塞进去。每个锚点使用稳定的命名坐标和尺寸，禁止依赖临时居中、自动挤压或随文字长度漂移的布局。

### 视觉负担预算

在粗动态分镜阶段为每镜记录 `focal_count`、`active_motion_count`、`label_count` 和 `line_count`。默认目标是一个主焦点、一个主动作、零到两个短标签、零条装饰线；超过目标必须在导演稿中说明物理来源和读取顺序。若镜头只能靠增加色块、线段或标签才能“看起来有内容”，退回故事卡或素材层。

## 5. 每集纸剧场故事卡

每集进入旁白和素材制作前，先用 `episode_blueprint` 形成创意交接；它是导演与内容沟通的故事卡，不是要机器校验的表单：

| 字段 | 必须回答 |
|---|---|
| `patient_task` | 患者此刻想解决的具体问题 |
| `misread` | 开场最常见的错误判断 |
| `anchor_object` | 贯穿本集、意义会改变的纸上物件 |
| `beat_form` | steps、steady、escalation 或 return；选择节奏形状，不默认每镜同速 |
| `reads` | 每镜观众先找什么、再理解什么、最后记住什么 |
| `causal_events` | 事件 A 如何导致 B；每个事件的起点/发展/落点 |
| `staging` | 景别、视线、屏幕方向、前后层和下镜接续物 |
| `asset_layers` | 背景纸、透明主体、遮挡片、阴影、确定性文字、医学参考 |
| `sound_events` | 可见动作对应的纸张/夹子/环境声，以及旁白停顿 |
| `ending_action` | 观众能执行的下一步和物件如何回收 |
| `guardrails` | 不得暗示的诊断、比例、治疗顺序、个体处方或急症边界 |

每镜默认 3—6 秒解释动作、5—10 秒纸剧场停留；长镜头必须有持续事件或景别/视线变化。预备、动作和落点不可共用一帧，末尾给关键含义至少一小段 hold。

## 6. 粗动态分镜和资产交接

先用几何纸片和旁白节拍做 animatic。先做一次“去文字审片”，只保留必要字幕，确认锚点和动作已经表达因果，再恢复短标签。导演连续观看整条粗剪，再看每镜首帧、关键动作帧、落点帧和切点两侧；联系表只帮助发现构图重复。检查物件是否落在桌面、运动方向是否跨镜连续、上一镜的物件是否承担下一镜入口、文字是否有独立阅读时间。切入帧必须已有可辨识的物件或问题，不能先给空纸再逐项上卡片。

素材制作只补粗分镜证明的真实缺口：医学结构优先使用经核对的透明素材；生活物件可用 ImageGen 或有许可的网络素材；纸张、折页、印章、夹子和短线条优先由 JS 确定性绘制。PNG alpha 要在浅、深、饱和底检查内洞、光晕和边缘。素材审查状态、来源许可和医学边界写入 `asset_manifest.json`，不能凭文件存在批准。

新增单件准入门：图集或多物件合成图不得直接作为运动层；主体边界必须有真实 alpha，四角和边缘不得保留生成器背景、棋盘格、渐变底或相邻物件残片；手、人物和医学主体必须登记动作锚点与接触点。不能通过这三项检查的素材只能作为风格参考，必须重新生成或改用有许可的来源。

## 7. JS 实现约束

- `SHOTS` 保存全局区间，场景函数只读取局部时间；`EVENTS` 同时服务动画、音效和预览。
- 所有插值 clamp，动作使用 ease/spring 或等价参数；手绘 boil 每 3—4 帧更新一次，静态医学结构和字幕不抖动。
- 素材预加载并等待 `decode()`/字体就绪；禁止首帧彩色占位、未加载图片或随机布局。
- 纸片的运动要有方向、重量、预备和收尾；不同层错峰，不能所有元素同时飞入。
- 每镜只保留一个主要观看任务；短标签按文字包络定卡片大小，线段只有在表达指向、边界或结构时出现。
- 不用无叙事来源的大型色块、色带或文字背景；颜色只能来自有身份的纸片、胶带、印章、标记或医学对象。文字与这些物件分层排版，锚点坐标、尺寸和安全区在分镜中先冻结。
- 画内文字只承担必要短标签，医学正文由 SRT；品牌由作者档案后期确定性叠加。
- 每镜必须声明 `motion_route`：`staged_reveal`、`camera_with_intent`、`object_sequence`、`cursor_led` 或 `stillness_then_payoff`。没有路线的镜头不得用 wobble、粒子或循环漂移填时。
- 每个跨镜切点必须声明 `carrier`、方向和速度意图。默认沿同一方向切在运动中；没有自然 carrier 时使用明确的纸页/遮挡切，不用无原因淡入淡出。

## 8. 持续打磨循环

每次修改针对一个可观察问题，先看实际运动和整片观看体验，再用静帧、联系表和技术回执定位：

1. 静帧看构图、层级、文字包络、医学关系和品牌位置。
2. strip 看预备、动作、落点、重量、遮挡和切点承接。
3. 联系表看节奏、景别变化、空白帧、构图重复和整季差异。
4. 旁白静音一次，再完整对照旁白/SRT；线段、标签和音乐不能替代核心事件。
5. 技术检查回读帧数、画幅、时长、解码、seek 一致性和字幕安全区；完整听感、素材准入和医学复核分别保留状态。

本地预览器同时输出联系表和逐镜动作 strip：每镜固定 12 个有序姿态，覆盖准备、发展、落点和停留。strip 是导演审片证据，不是把 12 张静帧当成动画通过；重点看层间错峰、遮挡关系、重量、停留和下镜接点。若连续动作只表现为物件依次滑入、主体始终不变，退回分镜或素材层。预览器等待 `window.__ready`、字体和图片解码，避免首帧占位误判。

本次垂体样片复盘新增两条下限：图册裁切得到的透明 PNG 必须在浅色、深色和彩色底各看一次，发现相邻物件残片就重新生成单件素材；医学解剖镜必须保留从头部定位点到放大结构的可见路径，不能让放大图凭空漂浮。无叙事作用的承托白卡、均匀连接线和大块底板一律删除。

若同一问题连续两轮仍存在，回退到故事卡或资产层，不继续堆提示词。每轮保留旧候选、修订原因和新证据，当前制作单只指向最新候选。

返修优先级固定为：医学关系与素材正确性 -> 主动作和读取顺序 -> 构图/景别/承接 -> 字幕安全区 -> 材质和纹理 -> 微动与音效。低层次修饰不能掩盖高层次未解决的问题。

## 9. 交付前质量门

动画门要求：精确第 0 帧和每镜切入帧有真实构图；无大空白或无意义卡片；无字幕/主体重叠；无未加载素材、随机漂移或错误品牌；每个镜头与旁白同向且有明确动作。通过动画门仍不能替代完整听感、医学复核和公开发布授权。
