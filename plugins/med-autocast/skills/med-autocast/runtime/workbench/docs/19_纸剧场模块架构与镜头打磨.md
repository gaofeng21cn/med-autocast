# 纸剧场模块架构与镜头打磨

2026-09-29：从单片 Canvas 脚本升级到逐镜制作。底座降低接触错位、字幕遮挡、时间漂移等技术故障，导演继续负责故事、构图、隐喻与节奏。默认本地 JavaScript 手绘拼贴，视频模型仅显式选择时使用。

## 五个职责

1. 播放输出：装配与时钟，预览/编码共用 seek。
2. 纸件材质：透明单件、纹理、连接点、前后遮挡、局部变换。
3. 动作：准备、发展、接触、跟随、停顿和结果，允许自定义。
4. 镜头：自己的物件、构图、相机、事件和阅读次序，可独立审看。
5. 单集：故事顺序、声音、字幕和系列档案；品牌不写入通用 Skill。

实现入口：[纸剧场模块](../templates/animation/paper_theatre/README.md)。TypeScript 源码打包成离线 JS；不引入 React 重写，不另外造渲染平台。Remotion 的独立镜头预览与 HyperFrames 的薄装配层在现有 Canvas 上落地。只有真实瓶颈需要时才引入它们作为宿主，避免两个主时间轴。GSAP、p5.brush 为专项能力候选，当前不是必需依赖。

## 制作顺序与分工

内容策划输出患者任务、事实边界和故事变化；导演给出视觉锚点、关键构图、逐镜阅读顺序、转场和声音事件；素材制作者把对象拆成可表演的纸件，登记 pivots/anchors/前后层；动画作者先实现关键姿态，再实现动作和相机；剪辑视听审核在真实旁白下调整留白和邻镜衔接。职责是交接边界，不等于必须多代理并发。

完整 animatic 仍在精细代码之前。先用稳定组件保证基础表现，再允许特殊镜头突破。新动作先在本集验证，通过观看比较后才提炼为通用模块；不要先搭一个庞大引擎再找作品验证。

素材清单持有来源、医学边界、真实路径和连接点。`score.json` 是时间事实，持有真实音轨秒数、镜头边界、句级字幕和命名事件；画面与声音共同引用。镜头自有相机和局部构图，不能让总装配根据镜头编号写分支。单集品牌快照追溯系列档案。

## 审片方法

每镜可以独立选择、循环、逐帧、半速和去文字观看；同一代码放回整片。先看关键姿态读图，再看动作准备与落点，最后看前后镜头及声音衔接。版本对照使用同一秒数的两版成片，不强行把不同长度动作拉成一致。输出成片后再抽取实际编码帧。

结构与类型检查只负责接口和资源；几何包络只定位遮挡。技术制作、有限有序帧审看、完整连续动态、完整听感、医学终审各自记录。后台抽帧不能冒充完整视听，当前用户要求不自动打开或播放桌面媒体。

## 已落地的代表动作

垂体瘤首集 v17 的信封收纳按图像真实前袋轮廓遮挡；三张资料沿局部坐标逐次入袋。盖章按印章底部 contact 对齐信封 seal，印迹与纸音共享接触事件。报告末尾血样管落点与下一镜一致。新旧资料比较使用报告材质，夹子实际落在纸上。门轴和门框分别管理开门与资料进入，不靠突然淡出补救。

稳定模块允许调节幅度、路径、重量与停顿。它们不提供固定疾病故事、固定镜头数、固定卡片布局，也不以始终运动为标准。医学信息需要停留，静止不是自动失败；画面没有信息变化时应返回导演调整。

## 外部方法来源与取舍

以下资料于 2026-09-29 实读；案例的模型归属为作者声明，未独立复现生成过程。

- [PDoomVideo](https://github.com/JohnHeibel/PDoomVideo)：阅读 `src/timeline.js`、`src/core.js`、`src/ch/c01_lab.js`；学习章节/角色/道具/时钟分工和乱序帧求值。没有照抄其角色、音乐、品牌或完整镜头。
- [ClaudeAnimationBase](https://github.com/JohnHeibel/ClaudeAnimationBase/blob/main/ANIMATION_GUIDE.md)：学习关键姿态、观众阅读时间、预备动作、重量、跟随和样本库。其禁止文字、要求永远运动等风格偏好不转为医学纸剧场硬规则。
- [Remotion connected compositions](https://github.com/remotion-dev/skills/blob/main/skills/remotion-markup/connected-compositions.md)：同一镜头可独立预览和整片装配，借鉴到本地播放器；[帧驱动](https://github.com/remotion-dev/skills/blob/main/skills/remotion-markup/SKILL.md)用于统一时间。
- [HyperFrames composition patterns](https://github.com/heygen-com/hyperframes/blob/main/skills/hyperframes-core/references/composition-patterns.md)：薄主片与自有镜头时钟；[motion doctrine](https://github.com/heygen-com/hyperframes/blob/main/.agents/skills/motion-doctrine/SKILL.md)启发因果动作与物件接棒，不照搬无交叉淡化或强制全时运动。
- [近期 Opus 5.5 案例索引](https://github.com/yihui-dev/awesome-opus5-5-videos)：区分原作者提示和复刻技术标注；合集热度不能证明本片质量，也不能代替可读源码。

## 版本与经验归档

通用实现归工作台模板，并同步 Med Auto Cast 的 runtime/workbench 和随包投影；单集锁定源码快照，保留旧版 MP4。方法和角色职责归 SOP/专业 Skill，具体医生形象、声音和品牌归作者档案，病种与本集导演决策归 productions/content。模块更新后重建受影响镜头及邻接区间；不自动覆盖旧片或升级已安装插件。
