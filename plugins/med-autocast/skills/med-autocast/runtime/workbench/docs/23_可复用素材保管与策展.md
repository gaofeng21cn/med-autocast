# 可复用素材保管与策展

素材库保存可再次创作的材料，而非把历史整片变成所有新片的模板。导演仍决定故事、镜头、材质、比例、节奏与声音；库提供可看、可追溯、可独立复制的起点。

## 保存什么、放在哪里

| 内容 | 保存形式 | 权威位置 |
| --- | --- | --- |
| 透明纸件、纹理、环境板、固定件 | 原始 PNG 等文件、来源许可/提示词/回执、登记连接点、审核范围 | `assets/paper-theatre/entries/<id>/<revision>/` |
| 通用绘图、场景、动作组件 | 冻结源码、依赖及使用条件、可运行样本或短视频 | 同一版本库；开发母版仍在 `templates/animation/` |
| 动作和镜头方法 | 可复用函数及简短导演用法、样例的精确时间和审看边界 | 同一版本库；原疾病镜头作为示例，不直接升级为通用组件 |
| 音乐、拟音 | 未混旁白的原声、分轨、可编辑 MIDI/工程、音源和许可依据 | 同一版本库；大型音源可留 `assets/audio/instruments/` 并注明依赖与哈希 |
| 作者身份和参考声线 | 授权母版、验证依据、品牌参数、基线版本 | `assets/authors/<id>/` 与 `profiles/authors/<id>.yaml`；库可以保存作者范围的图形/音乐快照 |
| 历史静态构图参考 | 原图、源视频拒用决定、有限静态审核 | 继续用 `assets/keyframes/`，不冒充可运动单件 |

环境板与透明单件分开；通用材料、选题、系列、作者分别记录 `reuse_scope`。同一纸件在不同镜头可以有不同含义，标题、标签和用法应说清它能承担的动作与不适用情境。医生形象、个人声线、品牌印文不进入无身份的通用材料。

## 两份记录，各有职责

`catalog.json` 是持久版本目录，列出每个独立包的 ID、revision 与 record。包内 `record.json` 保存实际文件 SHA256、字节数、来源、用途、范围、依赖和质量债。文件和记录一起保管；原单集或试验目录撤走后，归档件仍能使用。

`index.json` 与离线 `index.html` 是可重建的检索和看图投影。工程扫描结果标为 `managed: false`，查得到不等于已经保管。普通查询只读；刷新完整投影不受查询条件影响。看图库支持类型、范围、检索和透明底色切换；媒体默认不播放。旧版本继续留在 catalog，最新登记版本只是默认候选，不是自动批准。

复制到新集时保留精确版本和来源，`uses.json` 记录被哪一集、哪一个素材 ID 使用，便于来源变化或医学修订时定位受影响集。旧片的冻结副本不会随库更新自动变化。包中的相对资源引用须能独立解析；外部依赖注明实际位置与版本，不用原工程绝对路径维持隐式依赖。

## 贯穿制作的策展职责

策展能力在选题/导演准备时先查询、看图、看动作；在素材制作和逐镜 Review 时保存有复用价值的原件、修订原因及明确边界；交付后 `asset-curation` 汇总精选入库和经验。它不是必须等医学终审完成才能运行的最后一步，也不是交付门。

判断复用价值时优先看是否有清楚的视觉工作、正确的分层和接触、适合当前风格的材质、可理解的动作、真实来源。反复出现的错误解剖、图册残片、身份漂移、无意义色块与线段留拒用理由，不升级为默认素材。数量不代表库质量。

复用前看实际纸件内容及 alpha 边界，按认知主次、独立物件/纸上插画/比喻装置的区别和画面平衡缩放。尺寸由新镜头决定，不比较 PNG 外框后统一宽度，不强求全片实物等比例。连接点保留但新材质和镜头仍重新检查。

旧素材的视觉、动作、听感和医学结论按原范围保留；新镜头从待审开始。被医学否决的素材不能进入新画面；可以保留带拒用标签的修订依据。一般欠项记录质量债并继续可消费工作，工具只守路径、身份、版本和字节，不以字段齐全代替审美或医学判断。

## 工具操作

继续使用单一入口 `paper_project library`，无第二套调度与制作状态。下面的 `W`、`P` 是工作区和单集绝对路径，`T` 是当前使用的 paper_project.py；OPL 运行通过随包 `workbench_tool.py --name paper_project` 调用同一实现。工作区工具目录缺少新版本时使用随包版本，不覆盖该区专用脚本。

```sh
# 查询只读；kind / scope 是筛选，不是必须匹配的类型 Schema
python "$T" --workspace "$W" library --query 信封 --scope general

# 将所选项目的实际图像与已有来源证据独立归档
python "$T" --workspace "$W" --project "$P" library \
  --ingest-project --notes /path/curation-notes.json

# 保存源码、动作样例、声音等文件包
python "$T" --workspace "$W" library --register /path/records.json

# 刷新完整看图库；普通 query 不会写这个页面
python "$T" --workspace "$W" library --refresh

# 精确版本复制到新集；图像可指定本集 ID，不覆盖已有不同文件
python "$T" --workspace "$W" --project "$P" library \
  --use ELEMENT_ID --revision REVISION --asset-id NEW_LOCAL_ID
```

`--notes` 是按单集 asset_id 索引的可选策展说明，可补 `id/title/kind/tags/reuse_scope/usage_notes/quality_debt`，不改源素材医学状态。`--register` 接受一条记录或 `{"records":[...]}`；每条以 `id` 和实际 `files` 定位，`entry` 为包中入口，`files` 中 `source` 相对登记文件、`path` 相对包根，`role` 可标 payload/evidence/poster/sample。下面是普通文件包，不是限制所有创意输出的模型表单：

```json
{
  "id": "paper_pocket_motion",
  "kind": "motion_recipe",
  "entry": "src/pocket.ts",
  "reuse_scope": {"kind": "general"},
  "usage_notes": "袋口和前袋轮廓来自当前素材；新镜头重新设计姿态和节奏",
  "dependencies": [{"id": "kit", "revision": "precise_version"}],
  "files": [
    {"source": "../src/pocket.ts", "path": "src/pocket.ts"},
    {"source": "../preview.mp4", "path": "samples/preview.mp4", "role": "sample"},
    {"source": "../poster.png", "path": "samples/poster.png", "role": "poster"}
  ]
}
```

源码包复制进 `src/library/`，其他包进 `assets/library/`。工具复制实际文件与回读哈希，提供依赖和位置；导演/开发者显式接入代码，不自动注入 import、改 score 或改 brand。图像复制时追加本集素材记录，保留原审核来源并重置新镜头审核；作者范围资产只能复制给同一作者档案。缺一项文件时保留其他成功包和欠项，不把整个策展流程卡死。

Med Auto Cast 的只读发现入口还可用 `med_autocast.py assets --workspace W --library animation --query 关键词`；不加 `--library` 保持原关键帧查询。主 Skill、导演和专业素材策展 Skill 都消费同一库，不另存一次批准。

## 收尾与清理

先验证包内实际文件、来源、版本和样例可打开，再清理原试验工程。当前认可版本、仍被正式成片引用的回执、作者基线和稳定音源继续保留。不要为了“清理干净”删除唯一来源，也不要把整个项目、node_modules 或逐帧缓存当作复用素材。

同一内容重复入库复用已有版本；字节或策展说明变化创建新 revision，旧包不覆盖。升级只影响显式采用新版本的作品。经验沉淀记录可复用的判断和失败修复方法，具体疾病、作者和构图参数留在对应选题/系列档案。

## 跨工作区外挂资产库

多个系列共享纸片、环境板、动作组件或 BGM 时，同步到外挂仓库 `/path/to/mac-media-assets`。工作台 `assets/` 是本地缓存和兼容入口；外挂库持有统一 `catalog/assets.jsonl`、实际载荷、来源记录与 Review 边界。`workbench.yaml.asset_library` 是可选接入配置，查询或同步失败只形成诊断和质量债，不阻断 Progress First。

```sh
python3 /path/to/mac-media-assets/tools/query_assets.py --query 纸景
python3 /path/to/mac-media-assets/tools/verify_catalog.py
```

垂体瘤历史 ID `pituitary_tumor_s01` 与 `pituitary_paper_theatre` 是同一查询别名。真正复用仍写入本集 `asset_manifest.json` 和 `uses.json`，并重新做当前镜头审看。
