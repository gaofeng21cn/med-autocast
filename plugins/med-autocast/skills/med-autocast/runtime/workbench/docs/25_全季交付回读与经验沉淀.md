# 全季交付回读与经验沉淀

用户交付和制作过程是两个消费面。`publish/<series>/` 只保留每集唯一最新版，用户不需要在候选、时间戳和版本号之间挑选。目录位置不改变动态、听感、医学或上传状态。

## 当前版本与交付位置

读取 `workbench.yaml` 的系列/单集登记、当前 `project.json`、`out/current.json` 和 `deliveries/<series>/<episode>.json`。指针中的 `current` 是用户单集目录，`manifest` 指向内部交付记录。不要按 mtime、最大 vN 或旧 checkpoint 猜版本。

```text
publish/<series>/                 面向用户，可整目录转存
├── README.md                     一张清单，直接进入各集
├── 观看入口.html                 可选的离线观看页，不自动播放
├── 全季发布文案.md                可选文案合集
└── <episode>/
    ├── video.mp4                 唯一最新版
    ├── 封面.jpg                   有封面时附上
    ├── subtitles.srt             可选外挂字幕，已烧录时无需再上传
    ├── 小红书文案.txt
    ├── 微信视频号文案.txt
    └── 发布交付包.md               简明使用方法与真实审核状态

deliveries/<series>/              内部交接，用户无需在此找成片
├── <episode>.json                精确当前交付指针
├── <episode>/manifest.json       当前母版、来源、文件映射与审核状态
├── manifest.json                 可选系列机器汇总
└── stages/<stage_id>/            Stage 输入/输出引用、Review、质量债

archive/deliveries/<series>/<episode>/<revision>/
                                 被替换用户包、内部记录和原指针
```

publish 中不放 `current/`、`archive/`、日期/版本目录、多个 MP4 候选、Score、旁白 WAV、动作 strip、预览 JSON、源码或审查日志。它们属于原制作工程、内部 deliveries 或工作台 archive。旧材料保留恢复路径，但不在交付首页建立“选哪个版本”的入口。

## 实际打包与回读

代码动画使用 `paper_project package`：从 `out/current.json` 选择母版、校验实际源码/声音/Score，暂存并回查复制字节，再替换本集唯一最新版。旧包移到交付目录之外；其他集不动。显式 `--output` 用于 publish 外的过程导出，不为用户增建版本目录。旧多版本包使用 `organize_delivery.py --workspace <目录> --series <系列>` 按精确指针整理，不重新编码或改变审核状态。

`--delivery` 传内部 `deliveries/<series>/<episode>/manifest.json` 文件，母版路径先从 `out/current.json` 解析。preflight-workbench 同时兼容旧包记录；通过只证明当前性、来源、字幕和视频字节，不批准艺术、听感、医学或上传。

全季回读当前制作版本、交付视频、字幕、平台文案和 manifest 的实际一致性。用户首页的链接须在转存整个系列目录后仍可用；哈希、来源、完整检查与归档清单留在内部目录。文案唯一权威是系列 `release_catalog`，打包不创造新医学事实。只改文案不渲染；只整理目录不重渲染；换成片后审查记录必须绑定新的精确字节。

## 质量判断与 Progress First

联系表、事件帧、ASR、响度、字幕布局和完整解码只定位各自问题，不能替代连续动态、完整听感或医生终审。审核状态与放置目录分别保留；已有候选可交付供审看，缺项记录为可继续消费的质量债。不因 Stage 字段不完整丢弃进度；身份、权限、字节当前性和不可逆授权仍守真实边界。

## 经验沉淀

通用方法回写 SOP、专业 Skill 和随包工具；品牌、声线、疾病素材和镜头坐标留在工作区。可复用资产独立入库后再整理原工程。目录迁移记录应包含实际原位置、新位置、归档和字节回读，不能把旧路径描述为当前入口，也不能伪造 OPL Stage 运行或批准回执。
