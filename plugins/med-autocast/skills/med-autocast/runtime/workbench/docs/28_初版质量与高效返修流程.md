# 初版质量与高效返修流程

提高初版质量靠前置创作判断和小样，不靠成片后增加检查脚本。先把患者问题、医学关系、可见事件、实际纸件、语境读音和声线统一，再扩展制作。已有可用材料允许并行、跳转和局部返修；推荐产物缺项不阻断进度。

## 前置工作与责任

| 工作 | 最早责任 | 交给下游的可用内容 | 尽早看的小样 |
| --- | --- | --- | --- |
| 患者问题与医学边界 | 内容策划 / evidence-plan | 本集希望改变的判断、事实依据、适用条件和排除内容 | 用日常语言复述主要问题，检查画面会不会新增诊断或因果暗示 |
| 故事、纸面空间与视觉锚点 | 内容＋导演 / story-directing | Treatment、真实物件事件链、景别和相邻镜承接；透明层与环境身份 | 一镜风格帧和短动作、去文字 animatic；先证明主关系能看懂再加材质和微动 |
| 配音稿与读音 | 内容＋导演 / story-directing | 审定正文、逐语境读音标注、配音专用输入与停顿意图 | 首句和含高风险术语的完整声段；保持同一参考声音与方向 |
| 素材与动画 | 导演＋制作 / media-production | 有来源的实际纸件、内容 bounds、接触锚点、命名事件和可复现镜头 | 精确首帧、接触窗口、邻镜；看比例、纸边、叠压、字幕和文字位置 |
| 成片质量 | visual-review | 当前候选与真实覆盖范围，具体时码和修复建议 | 正常速度的连续画面、无音乐旁白、最终混音分别审；机器只辅助定位 |
| 跨阶段判断与用户交付 | meta-review / review-handoff | 缺陷归属、剩余质量债、精确母版和唯一最新版用户目录 | 比较当前作品与患者目标；不把输出文件、技术通过当医学/艺术批准 |

## 把已知失败变成前置决策

- PPT 卡片、无意义色带和线段：在导演稿明确每件东西是什么、为何在场、发生什么变化。不能承担动作或必要命名的背景卡先去掉；环境也用一致纸景语言。开场用视觉事件而非把题目写大。
- 拼贴质感不足、素材错误、比例失衡：看实际原件和透明边界，先画主次构图；认知比例按内容及纸剧场层级判断。撕边、固定件、接触阴影、厚度和随机错位服务纸件的身份与动作，不对全层机械抖动。
- 语气漂移和错读：交付配音稿时已按语境注明多音字、术语、数字单位和缩写；不用“某字统一读法”。固定授权声线及方向，先试首句和高风险整段。实际模型词表由后端转换；发音意图、模型输入和听到的声音分开记录。
- 字幕挡主体或变长句：在 animatic 预排字幕；断句属于内容与导演，retime 保留断句，只提出新时码。比例映射不是词级对齐，修订窗口仍需声画复核。ASR若仅识别段落后半部分，不得把完整正文压入残余识别窗口；整段提案保留实际声段起止，逐词识别只辅助导演定位。
- 首帧占位、错误旧稿和版本串用：资产加载完成才渲染，单独看零秒；构建绑定当前输入，返修复制独立可编辑文件。历史审核不随复制自动通过。
- 发布文案过薄、用户难找：文案由内容策划按该集事实写实用解释，不是旁白摘要；只从登记 catalog 物化。publish 每集只放最新版视频、封面、字幕、平台文案和说明；过程和历史移出。

## 返修只重做真正受影响的工作

先定位最早原因，再改最小依赖链。只改文案不渲染；只改视觉不重配音；只改某句注音重配该声段，复用其他有效音轨；新时长更新字幕、镜头、混音和成片。动作事件保持导演安排，不统一拉伸。未变纸件可复用原件与来源，不能复用旧整片的动态、声音或医学结论。

用 `paper_project revise --from-project` 建立独立修订，保持旧交付可恢复；素材和音轨按精确版本与字节复用。先在首句、代表镜头和局部窗口暴露错误，再一次正式编码，最后打包一次。中途失败从已完成步骤继续；不靠版本号排序猜当前工程。

Canvas 2D 在尺寸一致、完全不透明、无 CSS 变换或 DOM 覆盖时可直接捕获原生画布 PNG；否则仍由浏览器截图。预览与渲染共用同一捕获路径。它降低编码前取帧成本，不能改变艺术表达，也不保证所有后端同样提速。

## Review 不停留到最后

常规 Stage 按 OPL 的 producer / reviewer / repairer / re-reviewer 处理已有输出，缺陷回到最早责任。独立 Meta Review 综合判断一次，不再套一轮自身 formal review。内容、导演、声音都在前置小样和实际制作过程中参与；机械扫描提供定位，不能代替理解故事、读音或医学含义。

Progress First 保留可消费草稿、诊断和质量债，继续不依赖缺口的工作。明确拒用的医学素材或声音不进入有效成片；不支持的发音 token 先修该段，不静默换声线。完整动态、实际听感和医生审核未完成就如实待审，不因文件存在升级发布资格。

本流程能提高初稿下限和局部迭代效率，不能证明任意新主题、风格和后端都已达到稳定成片质量。代表作品连续视听与医学复核是判断稳定程度的依据。命中旧问题后同时修产物、最早责任提示和对应工具，避免只增加复盘文档。
