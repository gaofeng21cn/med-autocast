# 初版质量与高效返修流程

提高初版质量靠前置创作判断和小样，不靠成片后增加检查脚本。先把患者问题、医学关系、可见事件、实际纸件、语境读音和声线统一，再扩展制作。已有可用材料允许并行、跳转和局部返修；推荐产物缺项不阻断进度。

## 前置工作与责任

| 工作 | 最早责任 | 交给下游的可用内容 | 尽早看的小样 |
| --- | --- | --- | --- |
| 患者问题与医学边界 | 内容策划 / evidence-plan | 本集希望改变的判断、事实依据、适用条件和排除内容 | 用日常语言复述主要问题，检查画面会不会新增诊断或因果暗示 |
| 故事、纸面空间与视觉锚点 | 内容＋导演 / story-directing | Treatment、真实物件事件链、景别和相邻镜承接；透明层与环境身份 | 一镜风格帧和短动作、去文字 animatic；先证明主关系能看懂再加材质和微动 |
| 配音稿与读音 | 内容＋导演 / story-directing | 审定正文、逐语境读音标注、配音专用输入与停顿意图 | 首句和含高风险术语的完整声段；保持同一参考声音与方向 |
| 素材与动画 | 导演＋制作 / media-production | 有来源的实际纸件、内容 bounds、接触锚点、命名事件和可复现镜头 | 精确首帧、接触窗口、邻镜；看比例、纸边、叠压、字幕和文字位置 |
| 成片质量 | visual-review | 当前候选与真实覆盖范围，具体时码和修复建议 | 正常速度的连续画面、无音乐旁白、最终混音分别审；机器只辅助定位 |
| 跨阶段判断与用户交付 | meta-review / review-handoff | 缺陷归属、剩余质量债、精确母版和唯一最新版用户目录 | 比较当前作品与患者目标；不把输出文件、技术通过当医学/艺术批准 |

## 把已知失败变成前置决策

- PPT 卡片、无意义色带和线段：在导演稿明确每件东西是什么、为何在场、发生什么变化。不能承担动作或必要命名的背景卡先去掉；环境也用一致纸景语言。开场用视觉事件而非把题目写大。
- 拼贴质感不足、素材错误、比例失衡：看实际原件和透明边界，先画主次构图；认知比例按内容及纸剧场层级判断。撕边、固定件、接触阴影、厚度和随机错位服务纸件的身份与动作，不对全层机械抖动。
- 人物拼装与复杂小图：在导演稿前查角色/姿态覆盖，准备完整母版与动作状态，用人物＋椅子/器械试装验证真实手、脚和坐面。`use` 后回读锚点已进入本集；同名修订不按哈希大小猜新旧。关键复杂结构需要读清就扩大、近景或拆解，小尺寸对象选简化版本。方法见[人物与尺度契约](44_人物素材与画面尺度契约.md)。
- 语气漂移和错读：交付配音稿时已按语境注明多音字、术语、数字单位和缩写；不用“某字统一读法”。固定授权声线及方向，先试首句和高风险整段。实际模型词表由后端转换；发音意图、模型输入和听到的声音分开记录。
- 段落切换后“少了两个字”：逐段比较配音输入、源 take、拼接轨、归一化轨、mix 与最终 MP4，区分漏读、截字/错位、采样率处理、音乐遮盖和旧轨。静音本身不会删词；能量或 ASR 只定位，不按阈值裁弱辅音。源信号保留后按真实新时长 retime、build、mix、render，不能为旧时长配平。只修当前登记目标，历史副本保全。方法见[旁白拼接边界](33_旁白拼接边界SOP.md)与[逐集表意与段首完整性验收](39_逐集表意与段首完整性验收.md)。
- 修复后的音频交接：在任何声段重配、无损重拼或混音修改后，运行 `audit_audio_freshness.py` 检查 source/timing/mix/render/publish 的当前字节绑定；报告只定位旧轨和交接失配，不能把机器结果当发音或完整听感通过。发现 publish 旧轨时沿当前项目依赖重跑并逐字节回读用户目录，避免“工程已修、用户仍听旧片”。
- 拟音事件失配：旧 Score 可能引用已经改名或删除的事件。混音器应跳过该条拟音、在 `mix-receipt.json` 的 `unresolved_foley` 留下 `shot_not_found`/`event_not_found` 及候选事件，不伪造时间也不让旁白与画面链路崩溃；该项仍是待返修质量债，需在听审前补齐或明确删除。
- 字幕挡主体或变长句：在 animatic 预排字幕；断句属于内容与导演，retime 保留断句，只提出新时码。比例映射不是词级对齐，修订窗口仍需声画复核。ASR若仅识别段落后半部分，不得把完整正文压入残余识别窗口；整段提案保留实际声段起止，逐词识别只辅助导演定位。
- 首帧占位、错误旧稿和版本串用：资产加载完成才渲染，单独看零秒；构建绑定当前输入，返修复制独立可编辑文件。历史审核不随复制自动通过。
- 发布文案过薄、用户难找：文案由内容策划按该集事实写实用解释，不是旁白摘要；只从登记 catalog 物化。publish 每集只放最新版视频、封面、字幕、平台文案和说明；过程和历史移出。

## 初稿交接：先验证表达，再铺开数量

内容与导演交出的不是逐句配图清单，而是观众看得见的事件链：谁或什么在场，原来的关系是什么，哪个动作改变它，结果停在哪里，哪件东西被带入下一镜。分集先明确患者任务、误解、核心判断、事实引用及排除范围；旧系列有事实库不等于可以沿用旧故事、镜头和集数。

纸剧场先设计完整纸面空间，再拆成环境、可表演主体和前景。桌面背景加几张说明卡不能自动成为拼贴动画。撕边、异质纸纹、固定件、叠压、接触阴影和有目的的不完美应进入物件与动作；画面丰富度来自有职责的层次，不靠加大底板或堆道具。纸片按实际内容、认知主次和画面重量缩放，不按 PNG 外框统一尺寸，不强求实物等比例。隐藏解释文字后仍应看见主要对象、关系变化与结果；必要的解剖命名可保留。

先选择能代表本季常用解释方式和风险的镜头，做真实风格帧、短动作和首句/术语整段声音小样，再做一集完整 animatic。代表镜头验证局部技法，代表集验证开场、邻镜、节奏、声音和结尾，二者不能互相代替。扩展时复用已成立的材质、动作、声线和工具，重新设计每集的空间和事件。欠项不阻止其他集的事实研究、故事设计或独立素材准备；未审过的表达只能作为候选，不能因批量完成而升级质量状态。

可用 [初稿复核记录模板](../templates/series/08_first_draft_review.md) 保存已看的具体版本、范围、问题和下一步；它是可读交接材料，不是必须填满的表单。代表样片获得什么依据、还有什么欠项，都按实际填写。

当前工作台会在 `render_javascript_animation.py --preview` 和正式渲染时自动运行 `audit_motion.py`。它把 OpenDesign 的 `build / breathe / resolve`、动作方向多样性、长停留、重复配方和事件阶段覆盖转成可读质量债，并保留 `blocks_stage_progress=false`。导演必须结合代表镜头、事件前后帧、12 姿态 strip 和邻镜处理这些发现，不能用分数或重复率机械批准或退回。每集的 `signature_shot` 是前置创作交接，不是脚本启动门。

## 素材与声音在第一轮就解决

生成请求写“透明底”不证明实际透明。准入时看原文件的 RGBA/alpha 分布及浅、深、彩底合成：全不透明 alpha、画出来的棋盘格、内部破洞、邻件残片和外围光晕都需区分。完整环境板可不透明，可运动单件要有真实边界和分层依据；不强迫所有素材都透明。问题件优先重新生成单件或换有许可素材，不靠大色块遮盖。保存原件、来源/许可或生成回执、实际内容 bounds、连接点、医学用途/边界和拒用原因；自动 bounds 只是布局辅助，不批准解剖或比例。

旁白第一稿同时交正文与配音专用输入：按完整语境标注多音字、医学术语、数字单位、缩写和停顿。保留期望读音、理由及所在声段；不要用全局同字替换。后端在批量合成前核对当前模型原生前端（VoxCPM2 使用大括号拼音，历史 IndexTTS 使用已登记词表），保存请求 `tts_text` 和实际 `model_text`，固定授权声线与表达参数。发音小样覆盖完整首段和高风险词所在整段，观察异常尾音、语气突变及段间接缝；未实际听辨就标待审。`audit_pronunciation` 只定位风险，ASR 同字转写不能区分多音字，响度一致不能证明语气稳定。专用声线不可用时先修后端，不静默切 Edge；没有专用声线或明确跳过时才用备用方案。

## 构建、预览与编码以真实产物为准

排版从分镜就安排阅读区和动作经过区，标题、数值/单位、固定件与正文分开。制作时纸与字共享局部变换，明确宽高并量真实字形；检查全过程的纸页遮挡，而非只量最终宽度。布局回看使用普通 `preview` 的正式画面（含画内标签与字幕）；`--clean` 仅作去文字反向读图，不能承担文字布局审核。回执显式标明 `primary_view`，成功预览仍保留布局质量债。具体失败与修法见[纸片文字与遮挡SOP](37_纸片文字对齐SOP.md)。

局部或批量制作统一调用 `paper_project`，改过源码、素材、Score 或品牌输入后重新 `build`，再 `preview`，审看受影响窗口及邻镜，最后 `render`。它已有构建输入绑定与过期检测，不需要另造一套质量校验器。过期构建先重建，媒体缺失先修实际断点；保留已有产物和可读诊断继续其他工作，不能沿用旧 bundle 冒充新结果。

预览返回成功退出可能只意味着诊断已保存。回读本次 `preview.json` 的状态、实际帧与事件窗口，确认引用当前工程；不能用旧联系表证明新预览。编码后核对 `out/current.json` 的精确路径、当前输入引用、输出字节与实际 MP4 的音视频流/时长和可解码性。预览、编码回执与输入不一致时先定位源码、构建、素材、混音或入口哪一层漂移。静帧、SHA、解码和字段齐全只证明各自范围，不证明连续动态、听感或医学通过。候选导出后继续改源码时，先用独立修订保留对应输入；批量回读还需比较当前源码、构建与编码回执。只保存旧 MP4 不证明历史源码完整可恢复，不把旧片自动归为当前实现。

## 返修只重做真正受影响的工作

先定位最早原因，再改最小依赖链。只改文案不渲染；只改视觉不重配音；只改某句注音重配该声段，复用其他有效音轨；新时长更新字幕、镜头、混音和成片。动作事件保持导演安排，不统一拉伸。未变纸件可复用原件与来源，不能复用旧整片的动态、声音或医学结论。

用 `paper_project revise --from-project` 建立独立修订，保持旧交付可恢复；素材和音轨按精确版本与字节复用。先在首句、代表镜头和局部窗口暴露错误，再一次正式编码，最后打包一次。中途失败从已完成步骤继续；不靠版本号排序猜当前工程。

完整 Score 同时包含导演说明和声音事件，纯说明变化不能成为意外改音轨的理由。声音依赖未变时，用 `mix --reuse-from-project` 核对原回执和真实音频输入，沿用原 WAV 字节并生成可追溯的新绑定，再 build/preview/render；镜头说明仍如实更新。原输入保留在独立工程或明确的仅音频输入快照，方法见[单集工具](20_纸剧场单集工具与局部返修.md)。声音时码、事件或源音改变时按真实依赖重新混音。

Canvas 2D 在尺寸一致、完全不透明、无 CSS 变换或 DOM 覆盖时可直接捕获原生画布 PNG；否则仍由浏览器截图。预览与渲染共用同一捕获路径。它降低编码前取帧成本，不能改变艺术表达，也不保证所有后端同样提速。

## Review 不停留到最后

常规 Stage 按 OPL 的 producer / reviewer / repairer / re-reviewer 处理已有输出，缺陷回到最早责任。独立 Meta Review 综合判断一次，不再套一轮自身 formal review。内容、导演、声音都在前置小样和实际制作过程中参与；机械扫描提供定位，不能代替理解故事、读音或医学含义。

Progress First 保留可消费草稿、诊断和质量债，继续不依赖缺口的工作。明确拒用的医学素材或声音不进入有效成片；不支持的发音 token 先修该段，不静默换声线。完整动态、实际听感和医生审核未完成就如实待审，不因文件存在升级发布资格。

本流程能提高初稿下限和局部迭代效率，不能证明任意新主题、风格和后端都已达到稳定成片质量。代表作品连续视听与医学复核是判断稳定程度的依据。命中旧问题后同时修产物、最早责任提示和对应工具，避免只增加复盘文档。

经验保存为“具体失败 → 最早原因 → 前置决策/小样 → 最小返修 → 实际证据及未覆盖项”。通用方法写回本 SOP、对应 Stage prompt 和专业 Skill；可复用纸件/动作/声音带可看样例与失败边界入库；病种事实、品牌、声线和镜头参数留工作区。本轮四季记录见工作区 `work/four-seasons-paper-renewal/经验复盘与初稿改进.md`；项目记录不作为随包通用依赖。

## 新专题生产中的三个前置防错点

网上原文取回后先核对实际标题、正文主题和对应结论。HTTP 成功、非空或字符很多，也可能只是 404 导航页；错误页面保留为拒用检索证据，不能列为已核对指南。专题研究稿中的归因和机制需回原始文献，不把患者体验相关性写成确定病因。正文使用足以完成当前患者任务的术语；不必要、读音未确证的专业名称优先改成准确的通俗表达，内部事实库仍保留完整名称。

完整环境板不能替代导演事件。首轮风格帧应检查：所谓桌面是否像无来源色带，所谓袜子/手/固定件是否实际可辨，放大或遮挡是否来自物件关系，报告、日历和资料袋是否相互盖住内容。删掉抽象占位，再使用真实纸件；动作图层保持透明，完整纸景只承担环境。来源、素材原图及真实构图的审核范围分开记录。

重复 `retime` 时，音轨与实际镜头切点不变，应保留已采用的断句时码，不能把声段前后留白一次次重新映射。发现既有漂移，用明确的原始编辑 Score 或已核对字幕作为 `--reference-score`，仅更新相关集的 Score、预览、混音、构建与视频；不为字幕返修重配未变音轨。参考稿仍是时间提案，不能批准实际发音和完整听感。

## 从真实纸景检查字幕和道具

字幕的可读性依实际落点和背景纹理判断，不能因为没有主体重叠就认为已可读。先看亮/暗环境中的字幕原尺寸帧；优先调整字色与细描边，不为方便排版添大色带。Canvas 模板可确定性读取已经画好的字幕区域背景辅助选色，结果仍要视觉复看；跨季更换环境时不沿用旧环境的结论。已交付或已编码的集数只更新确实受影响的镜头/字幕，不随模板变化全量重做。

导演先核对道具的实物身份与形状。烟草、饮料、药物、补充食品、血液/尿液和组织样本不能仅用同一个瓶形换标签来区分；标签正确不代表视觉正确。用真实纸件或专用可辨形状表达，辅以准确内容比例、接触和收纳动作；错误道具留拒用原因，替换后复看落点及邻镜。

一季同时有批量生产和局部返修时，交付从登记的当前单集工程与其实际媒体回执读取，等待仍在写同一目标的任务结束。只有与当前构建、Score、混音一致的母版进入用户目录；成功编码后才更新修订的当前登记。静帧/布局定位、完整动态、实际听感、医学终审分别记录，质量欠项不禁止交审看包，也不能由数量和机器结果补填通过。

## 资产库前置动作

### 尺度与自然组合在风格帧前移

先明确当前必须看懂的对象、关系和变化，再按[人物素材与画面尺度契约](44_人物素材与画面尺度契约.md)选择总览、解释近景或简化版。小图承担简单识别，复杂核心获得足够阅读面积；先看原尺寸，再用移动端宽度看主次和细节是否还成立。统一判断原则，各集保留自己的构图。

人物换成完整素材后，旧几何纸偶的臀部原点、脚跟pivot、手部坐标和独立投影经常失效。把人物、椅面、椅腿、地面、器械和接触层当作同一个关系组重新试装；按真实可见臀部、脚底和手掌定位。清理仍在绘制的旧手片，再看完整头脚、接触、动作极值及相邻姿态。只把人物图片替换成功会留下悬坐、多手、裁头和脚影分离。

有序样本应标明实际视频帧时刻。声明切入不是整帧时，首个片内帧用向上取整定位；切出前帧留在当前镜头区间。最近帧四舍五入可能取到上镜尾，不能写成精确切入。抽样只判断实际看到的状态，短接触另用事件窗口补看。

新系列的视觉导演稿之前先查询外挂医学视频资产库或工作台本地库，实际查看候选纸片、背景板、透明边界、内容 bounds、接触点、动作样例和 BGM 分轨。候选资产先写入 treatment 的 `asset_intent`，再决定它是否真的承担本镜头的视觉事件；没有职责的色块、线段和大卡片不因“库里已有”而保留。资产库同步缺失时继续不依赖该缺口的故事、声音和低保真预览，留下质量债而不是停住。

第一版完成后，把新生成且可跨集复用的原件、源码、可编辑配乐和失败素材的拒用理由写回外挂库；只登记真实载荷和精确版本，不把含旁白成片、静态关键帧或一次性帧缓存伪装成通用资产。这样下一集可以更快找到稳定下限，同时保留导演自由和当前镜头重新审看。

## 2026-10-18 五小时级全季优化后的初稿前移

长任务不能等全部镜头编码后才看动作。第一次 animatic 就检查当前物件、变化/稳定关系、停顿、结果与邻镜；用真实帧/动作窗口记录判断。resolve_motion_audit 现只导出现有声明，不能从事件名称自动补反应、落定、方向或连续性；历史自动补写也不证明已修好。前置小戏、道具状态图和节奏打磨见[纸剧场制作方法适配](42_paper-collage-mv制作方法适配.md)。

批处理必须可恢复：每集写阶段回执，按最近完整 `retime/build/preview/mix/render/package` 继续；修复 Score、素材或代码后重新绑定 build、当前母版和 publish，不能沿用旧预览、旧 MP4 或旧 SHA。每集仍独立做去文字反向读图、连续动态、段首/接缝听辨和医学检查；批量成功只证明工程推进。
