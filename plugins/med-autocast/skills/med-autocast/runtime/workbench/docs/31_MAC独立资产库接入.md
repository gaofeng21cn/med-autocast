# MAC 独立资产库接入

`mac-media-assets` 是 MAC 的公共媒体能力依赖，安装 MAC 时由 Framework 自动安装，工作台通过 `asset_library` 配置或当前安装目录发现。公开库不保存品牌、授权声线、医生形象或签名音乐，作者资料留在私有工作区。

`media_asset_library status/ensure/query/use` 提供发现与精确版本取用；`collections/use-collection` 提供装配与事件集合，成功部件逐一保存，欠项不会撤销成功导入或阻断其他创作。独立PNG原记录即使没有历史项目的 `asset` 包装，也会在导入时建立本集素材登记，原记录和revision不改写，当前审查状态重置为待审。

分类与同义词不固定故事、构图、镜头或复用率。新资产标签欠项时可按标题和用途查看，缺库或未找到匹配素材时继续新创。实际工具、几何、组合与声音选择见 [资产发现与可重组事件 SOP](32_资产发现与可重组事件SOP.md)。
