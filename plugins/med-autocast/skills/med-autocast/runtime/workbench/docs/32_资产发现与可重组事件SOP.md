# 资产发现与可重组事件 SOP

在选题事实和患者任务明确后，导演先写可见事件，再按对象、叙事用途、动作和情绪查 MAC Media Assets。库能提高下限，不决定故事、镜头数量、比例或风格上限。

## 发现、查看、试装、取用

1. `media_asset_library query --query 甲状腺`、`query --category 配乐 --query 探索`、`query --motion-action 翻页` 返回名称与用途匹配的原件。分类、动作、视角及媒介是发现标签，欠项不会阻断生产。
2. `collections` 返回装配、事件与声音登记。`query --collection door` 看门框/门扇的精确版本，再看库根 `tools/preview-engine/index.html#door` 的可拖动时间轴小样。声音在 `audio.html` 逐分轨和变体试听。
3. 使用原图坐标接触点、各部件独立内容bounds与实际画面重量试装；不要共用整个包的bounds。需要独立动作的物件分别保管。外观/切面不能未经配准就冒充连续剖开；同图局部放大与视图切换可以作为不同技法。
4. `use-collection --project <单集路径> --id <集合ID>` 按原版本分别复制，保存组合来源及本镜头待审状态。个别部件失败保留成功导入、记录债务并继续其他工作；可以换源或新创。
5. 先完成真实代表镜头和整集animatic。工具的帧检查或几何检查不批准动作质量，静态通过不批准医学含义；新脚本与配音的语义由Review/Meta Review判断。

## 声音与成熟度

配乐与拟音分别管理。配乐看情绪、真实BPM、起音密度、分轨、剪辑点与尾音；谱面密度不等于听感密度。拟音挂在接触事件，物件无接触的移动可以安静。旁白优先，声音原件、无BGM旁白和最终混音分别审听。

原件、静态换底、组合试装、连续动作、医学语义、完整听感和当前镜头批准分别记录范围。集合提供部件关系与可看小样，不是固定台词或固定场景。新标签不设为Stage启动门；机器仅守资源、身份、版本与确定性边界。

## 交付后内化

值得复用的新创保存原件、来源、独立部件、动作与使用边界。公开库只保存通用无品牌资产，作者身份、声线与签名音乐留私有作者档案。分类和同义词在外库发现层维护，原件版本不因重分类改变。库升级不自动修改已经完成的影片。

新创归档可在原记录中附加 `discovery`（category、aliases、story_roles、actions等）。公共同步接收这些可选标签，已有外库策展结果保留；没有标签时按标题与用途继续发现。几何测量绑定 `geometry_revision`，原件换版本后不沿用旧bounds；标签与成熟度证据不作为硬艺术评分。
