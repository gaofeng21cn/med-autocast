# 纸剧场纵深与媒介统一 SOP

## 这条经验从哪里来

89 集做了一轮"相机语法"批量升级：给每个疾病系列不同的基础构图、景别、进入节奏和推移方向，然后重渲染全部 89 集。核对代码后发现，这轮**没有改善动画本体**：垂体瘤 12 集源码一行未改，其余 77 集只把 `camera` 换成了慢速推拉，场景仍然是 `env(s,'kitchen'); meter(...); notebook(...)`——物件并排摆好然后停住。kit 里 13 个纸件动作（掀角、撕开、折叠、翻页、拉条、剪开、笔迹、夹合、落纸、展开图）几乎没有被调用。

结论：**相机运动不能代替物件动作和景深**。给平面拼贴加推拉，只会把"静态幻灯片"变成"会呼吸的幻灯片"。

## 根因

渲染管线里 `Stage.camera()` 对整幅画面施加同一个变换。环境板、主体、前景一起缩放平移，画面只有一层。纸拼贴之所以读起来像拼贴而不是幻灯片，靠的是**层与层之间以不同速率移动**——即视差。Canvas 2D 没有景深，需要显式造出来。

第二个根因是媒介冲突：环境板是照片质感台面/实验室，主体是手绘纸片。两种媒介并置时，画面会读成"照片上贴了几张图"，而不是一次拼贴创作。

## 落地实现

`templates/animation/paper_theatre/src/kit/staging.ts` 提供两件事：

### foreground() — 前景纸层与视差

在镜头变换**之外**绘制，用两层撕边纸片加接触阴影。纸层跟随相机但跑得更快：`lead = (zoom-1)*90 + drift`，横向扫动 `sin(t*0.32)*lead*0.22`。因为变换率不同，主体与前景产生相对移动，画面立刻有了纵深。

**硬约束**：字幕基线在 `height-67` 且居中，前景横向侵入量被限制在 `w*0.14` 以内，永远不得进入中部字幕带。撕边压字幕比没有纵深更糟。

### paperWorld() — 媒介统一

整幅画面叠一层纸纹（multiply 暖色罩染 + overlay 纤维漂移）+ 径向暗角，把照片质感环境板拉进纸的语汇。纤维漂移振幅极小，只让表面"活着"，不构成抖动。

### Shot.depth

```ts
type Shot = {
  depth?: 'theatre' | 'flat' | number;  // 默认 theatre；0/'flat' 退出
}
```

`player.ts` 在镜头渲染后、字幕绘制前调用这两层。导演可按镜头需要逐条减弱或关闭，不需要改渲染管线。

## 动作因果的硬要求

纵深解决"平"，动作因果解决"死"。每个场景必须有：

1. **进入** — 物件从画外进入，有轨迹和落点
2. **接触** — 物件碰到什么，接触点要有阴影或形变
3. **反应** — 接触后对方要有可观察的变化
4. **落定** — 动作结束在稳定、可读的状态上

动作时点从 `score.json` 的命名事件读取，不要从 `t` 猜。`beat.events` 是旁白与画面的共同时钟；`const ev=(c,k,d)=>c.beat.events[k]??d` 是标准写法。

## 初稿质量门

新单集 preview 后逐项确认，任一不过就返修：

- 关掉文字标签，画面能否表达主对象、关系和动作
- 前景层是否存在，且没有压住字幕或关键主体
- 环境板是否已被纸纹罩染统一，不再读作照片
- 每个场景是否走完"进入→接触→反应→落定"
- 动作极值帧与接触落点是否单独抽帧看过

## 失败边界

- 纵深幅度过大时主体被挤压：调小 `travel`，不要关掉纵深。
- 撕边遮挡关键医学结构时，把该镜 `depth` 调小或设为 `'flat'`，并改构图而非删纵深。
- `paperWorld` 罩染过重会让报告文字对比下降：宁轻勿重，默认值已偏保守。
- 这套层只提供下限。它不能替代逐镜的空间设计和动作编排。
