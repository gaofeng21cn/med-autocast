# 纸剧场纵深与媒介统一 SOP

## 先分清缺陷和技法

历史返修曾只给整幅平面画面加慢推，再把重新渲染称为动画升级。相机运动不能替代真实对象关系、物件操作与结果；代码调用和材料层增加也不证明观众看懂。先按[逐集表意与段首完整性验收](39_逐集表意与段首完整性验收.md)反向读图，核对本镜对象、关系、变化或稳定状态，再选择空间与材质技法。

纸拼贴可用纸件叠压、厚度、接触阴影、遮挡、前后层和有目的的视差构成空间。稳定解剖关系、对象特写、观察或直接比较可以保持平面与静止；不是每镜都需要前景扫动、运镜或固定动作数。环境与主体的材料语言应服务本镜，也允许有理由的照片、印刷和手绘拼贴组合；不能以“罩了一层纸纹”自动批准媒介一致。

## 可用实现

`templates/animation/paper_theatre/src/kit/staging.ts` 提供 `foreground()` 与 `paperWorld()`：前者在相机变换之外绘制撕边纸层，可形成相对移动；后者叠纸纹罩染与暗角，辅助统一材料。它们是导演可选择、减弱或关闭的工具。`Shot.depth` 可按镜头设为 theatre、flat 或强度；具体默认行为以当前 player 实现为准，不把默认值写成审片门。

选择视差时看真实相对位移、接触和空间感，不能只看相机参数；选择纹理时看主体边缘、背景注意力、字幕对比与实际纸感。前景遮挡压住关键结构、对象或字幕时，调整构图、局部范围与强度，必要时关闭该层。不能为满足“有前景”保留无来源色带和占位纸片。

## 按解释任务组织变化

- 操作、交接、夹合、翻页、收纳：核对准备、接触、反应和结果，接触点、阴影、遮挡及最终状态真实可见。
- 揭示、对比、解剖关系：核对展示顺序、对位、区别和阅读停留，不强添物理接触。
- 持续观察、生活情境或时间变化：核对状态与同期旁白是否同向，细节是否承担当前事实，而非全层机械晃动。

重要动作与声音使用 `score.json` 命名事件。真实旁白变化后重新安排动作与停留；不按镜头时长同比拉伸所有动作。后续旁白很长而核心动作已结束时，按含义接局部事件、真实细节或结果；清楚静态关系可以保留理解停留，不以固定秒数否决静止。

## 实际审片

隐藏解释文字先描述实际画面，再恢复同期旁白；看原尺寸精确首帧、动作关键状态、结果、邻镜及正常速度。联系表和 strip 只帮助定位，代码中的层、动作或事件存在不等于画面已发生。

检查物件是否可辨、尺寸与视觉重量是否平衡、结果是否延续、材料是否干扰阅读、字幕是否清楚。已知表意错误回最早导演/素材/实现环节，不用追加胶带、色带、标签或运镜补救。候选、质量债与独立工作可继续；未实际确认的基本意思、动态和声音不记通过。

## 失败边界

视差过大造成无意义扫边、挤压主体或抢注意力时减弱或关闭；罩染过重、漂移影响文字或医学细节时减薄。技法模块只降低实现成本，不提供艺术合格证，也不锁定本集空间与动作设计。
