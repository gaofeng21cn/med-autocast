# 医学科普独立调研 SOP

版本：1.1，2026-11-13

本 SOP 将原先面向 Gemini/ChatGPT Deep Research 的“一次性长报告提示词”改造成 Codex 可持续执行的证据研究流程。可参考用户授权的既有疾病调研提示词并回到当前医学原始来源，服务 Med Auto Cast 的 `medical-video-researcher`，交接给 `medical-video-content-planner`，再进入故事、剧本和导演阶段。

## 1. 目标与边界

研究的终点是内容策划拿到足够、可用且可追溯的医学科普材料：每条可用结论有原文定位、适用条件、时效、证据类型和表达边界；每个关键缺口、冲突和待临床审核项都有记录；视觉和情境参考有许可及“不能暗示什么”的说明。研究包不是临床诊断、个体治疗建议、医生终审或发布授权。

## 2. 输入与目录

用户至少给出主题和目标；MAC 需要继续收敛患者任务、受众、地区、截止日期、平台/时长与排除边界。系列已登记时，研究包放在登记的 `content_root/research/`；主题尚未登记时先建立 `content/<topic_id>/research/`，不把临时材料散落在 `work/` 或 `publish/`。

```text
00_research_brief.md       # 研究对象、患者任务、地区、截止日期和排除范围
01_source_registry.yaml    # 原始材料、检索来源、版本、定位和拒用线索
02_evidence_matrix.yaml    # question_id → claim_id → source_id 的原子证据表
03_conflict_log.md         # 冲突、时效、外推限制和未解决问题
04_visual_research.yaml    # 医学参考、患者情境、物件和许可边界
05_patient_question_map.md # 患者困惑、判断、行动和急症边界
06_research_report.md      # 面向内容与导演的研究交接报告
07_research_receipt.yaml   # 范围、检索时间、覆盖率、缺口和 owner 回执
```

## 3. 证据规则

官方指南/共识、监管文件和适用药械说明书优先；系统综述和循证总结用于整合；关键机制、诊断准确性、疗效、风险与预后再补原始研究；权威机构患者教育只用于公众表达校准。来源等级不能替代对具体结论的直接支持。

每条 claim 必须回答：谁、在什么地区和场景、观察或比较了什么、结论是什么、数字的分母和单位是什么、有哪些限制。必须把“观察到”“推荐”“证明”“可能”分开。诊断/筛查、关联/因果、相对/绝对风险、群体结果/个体建议不得混写。

治疗、药物、监管和快速变化事实默认优先五年内来源；基础定义和经典机制可以更早，但要留下适用理由。来源发生版本冲突时，保留冲突和版本，不用新来源的标题覆盖旧来源的具体条件。

## 4. 从研究到故事的交接

研究员只交“事实、条件、患者问题、视觉机会和缺口”。内容策划据此建立主题级事实库、系列边界和每集核心判断；导演将已标记的视觉边界转成可见事件。任何旁白、字幕或画面新增医学判断，都必须回到 `claim_id` 和来源，不能在写作或生成阶段凭常识补齐。

### 研究完成与医学批准分开

调研完成按实际内容判断：主要患者问题已有来源支持的实质答案，机制、评估与管理解释连贯，比较、常见误解、家庭/就诊准备与画面参考能供策划直接使用。只有目录、四问四答、来源入口或缺口清单时，保持 `research_in_progress` 并继续补正文；达到可用水平再用 `research_ready_for_planning`。临床终审仍由实际专业复核决定，不能用“待医生审”推回研究员本可独立完成的查证和资料整理。

### Progress First 的执行

读原文后直接形成解释、事实和素材。碰到不可读来源，定向尝试其他权威入口或用范围明确的可靠来源完成可回答部分；未解决项说明影响，但继续做其余必要研究。发现错误就在当前任务修正，检查仅服务于内容交付。一次必要回读后继续交付，不以结构检查、状态降级或统计告警代替研究进度。

## 5. 对旧 Deep Research 提示词的继承与修正

保留其优点：专业角色、来源优先级、问题拆分、核心结论/证据来源/证据类型/关键数据/链接这组输出骨架。修正五点：

1. 不再固定“认知—希望—同行”三幕，改由患者任务和主题问题树决定覆盖。
2. 不再只输出一篇 Markdown 长文，增加来源登记、原子 claim、冲突/缺口、视觉许可和执行回执。
3. 不把“有链接”当作“已核实”，要求原文主题、标题、版本和定位回读。
4. 不把近五年当作所有问题的硬阈值，按变化速度和基础知识性质决定时效。
5. 不把一次模型回答当作深度研究完成证据，Codex 的工具调用和文件产物必须可观察、可恢复、可审阅。
