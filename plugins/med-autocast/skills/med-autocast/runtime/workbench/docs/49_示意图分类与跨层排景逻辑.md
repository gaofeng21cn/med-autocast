# 示意图分类与跨层排景逻辑

## 目的

纸剧场里“不按现实尺寸也自然”的前提不是对象属于医学，而是观众能看出它处在另一套解释坐标系。真实人物、桌椅、纸夹和手持物要共享物理世界关系；结构图、数据图和符号只在明确的图解层内按阅读任务定比例。两套坐标系混在同一地面、同一接触关系里，才会产生巨型器官、缩小人物或漂浮物件的违和感。

## 七类视觉尺度

| `scale_mode` | 典型内容 | 比例依据 | 跨层规则 |
| --- | --- | --- | --- |
| `world_scale` | 患者、Dr.咩、家属、桌椅、报告纸、文件夹、手机、药盒、检查设备 | 同镜 `pixels_per_cm`、姿态身体段、接触与地面/桌面锚点 | 可共享地面、桌面、手持、阴影和遮挡；人物之间必须做同场试装 |
| `diagrammatic_structure` | 器官位置图、解剖关系图、病理结构、细胞/微观结构、机制剖面 | 讲清结构、方向、层级和差异所需的阅读面积 | 必须有纸张、屏幕、插图框、切片边界、镜头转场或其他图解信号；不与真实人物共享身体标尺 |
| `magnified_detail` | 放大镜内局部、组织切片、局部剖面、从报告切出的近景 | 放大倍数与阅读任务；不等同于场景中的真实物理尺寸 | 保留来源对象和回接关系；用放大框、裁切线、镜面或镜头语法说明“这是局部放大” |
| `data_visualization` | 检验趋势、风险分层、时间线、比较表、坐标/刻度/曲线 | 数据轴、单位、比较关系和可读性 | 数据几何服从数值和轴语义；图表容器仍按纸张/屏幕的物理尺寸排景 |
| `symbolic_metaphor` | 箭头、旗标、颜色 token、路径、风险标记、条件分叉、手绘强调 | 视觉语法和注意力，不声明物理体积 | 不得有真实物体的接触、投影和落地暗示；用纸签、印章、线条或浮层身份固定其语义 |
| `document_flat` | 报告内的印刷示意、纸上小图、表格单元、报告页眉 | 外层纸件按物理尺寸；内部内容按纸面版式和阅读职责 | 内部图解不能推导人物或家具比例；翻页、折叠和遮挡仍服从纸件物理关系 |
| `screen_content` | 手机/平板/电脑内的报告、图表、影像和界面 | 屏幕硬件按物理世界；屏幕内容按 UI/图解/数据规则 | 屏幕边框与手持关系要真实；内容不与屏幕外人物共享身体比例 |

`diagrammatic_structure`、`magnified_detail`、`data_visualization` 和 `symbolic_metaphor` 属于可脱离现实物理比例的解释层。`document_flat` 与 `screen_content` 是容器和内容两层，不能把整件纸或手机简单标成“示意图”后忽略桌面、手和遮挡。

## 允许脱离现实比例的四个条件

一个素材只有同时满足以下条件，才可在镜头中按解释职责放大、缩小或独占近景：

1. **身份明确**：manifest 写明 `scale_mode`，并记录它是在纸上、屏幕内、放大框内还是独立图解板上。
2. **观众有提示**：边界、纸纹、屏幕、放大镜、切片线、坐标轴、箭头或镜头转场至少提供一种图解信号。
3. **来源可追溯**：结构图、数据和医学关系有来源或医学审核入口；符号隐喻写清 `must_not_imply`，不能被看成真实器官、药品或患者。
4. **关系不误导**：图解层不与真实人物共用脚底、椅面、手持、投影或接触阴影；如果同镜并置，必须有局部坐标、层边界和观看次序。

不满足条件时，按 `world_scale` 处理，或者重写镜头让图解先进入纸面/屏幕/放大框。不能仅把 `visual_layer` 改成 `medical_diagram` 来掩盖人物之间的比例失衡。

## 一镜多层的排景顺序

先确定本镜的主焦点，再分别建立物理层和图解层：

1. 物理层先按共同 `pixels_per_cm` 排人物、家具、纸件容器和接触组。
2. 图解层在自己的局部坐标中定面积、方向、数据轴和阅读停留，不参与人物标尺。
3. 用纸张、屏幕、放大框、切片边界或镜头切换建立两层的关系；需要来源回接时，让箭头、裁切线或镜头运动指向具体对象。
4. 检查图解出现前后，观众是否仍能说出它解释的是哪个物件、哪句旁白和哪种关系；隐藏标签后，物理层和图解层都不能互相冒充。

图解可以比人物大很多，但不能同时拥有真实人物的地面投影、手持接触和房间透视。若一张“器官图”被画成患者胸前的实体物件，就要重新选择 `document_flat`、`magnified_detail` 或 `world_scale`，并按对应规则排景。

## manifest 最小字段

示意层素材至少写入：

```json
{
  "visual_layer": "diagram",
  "scale_mode": "diagrammatic_structure",
  "diagram_class": "anatomy_structure",
  "visual_meaning": "解释甲状腺位置与结节结构",
  "must_not_imply": "不是患者身体的真实尺寸或影像",
  "diagram_context": "paper_inset",
  "source_or_medical_reference": "..."
}
```

真实人物仍写 `visual_layer=character`、`scale_mode=world_scale` 和 `human_scale`。纸张或手机写 `world_scale`；其中的图解另以 `diagram_context` 或独立素材登记，不把容器与内容混成一个比例判断。

## 审片结论

机器检查只确认分类字段、图解边界和物理人物合同能回读。视觉审看仍要看原尺寸、移动端、动作接触、邻镜和去文字画面，并记录“观众读到的层级、来源和关系”。图解层通过不等于人物比例通过；物理层通过也不等于医学含义通过。
