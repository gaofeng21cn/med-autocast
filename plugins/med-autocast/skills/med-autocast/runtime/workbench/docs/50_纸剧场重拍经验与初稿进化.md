# 纸剧场重拍经验与初稿进化

这份文档是纸剧场逐集重拍的经验入口。它把已经在真实镜头中验证过的做法沉淀为下一集初稿的前置检查，保留每集独立导演的自由，不把上一集的故事、构图或整套表演复制到下一集。

## 画面文字的边界

观众知道自己在看动画，画面不需要反复解释“这是动画”“非真实影像”“仅供示意”或“手绘示意图”。这类文字如果没有改变观众的医学判断，就从画面中删除；方法说明写在导演稿、素材记录或审看回执中，不放进成片。

画面上仍保留真正帮助理解的内容：报告名称、检查项目、单位、时间、风险类别、数据轴、必要的来源和医学标签。图解层可以通过纸张/屏幕边界、独立插图框、放大关系、图表坐标和纸件材质自然表达其身份。需要防止误读时，优先调整对象、边界、关系和镜头语义，再决定是否需要一句有具体医学作用的说明。

每集在初稿复核中增加一项：逐镜检查文字是否只是防御性解释。若删掉后观众仍能正确理解对象和关系，删除它，并在本集经验卡记录“删除原因”和证据帧。

## 排景与素材

按 [示意图分类与跨层排景逻辑](49_示意图分类与跨层排景逻辑.md) 给每件素材写 `scale_mode`。人物、家具、纸夹、报告、手机、药盒和设备进入 `world_scale`，共享同镜 `pixels_per_cm` 和接触关系；器官/解剖、放大局部、数据图表和符号进入各自图解层，只在纸面、屏幕或明确局部坐标内按解释职责定比例。

环境层只建立舞台，不参加主体碰撞和字幕避让。真正需要检查的是人物、纸件、手持物、图解局部、文字与字幕之间的关系。复杂结构读不清时扩大、近景、拆层或换简化素材，不用标签或“示意”字样补救。

可运动素材必须是透明单件或透明完整姿态包。生成新素材时记录来源、载荷哈希、透明边缘、适用动作和失败条件；先实际看原件，再接入本集镜头和 manifest。透明素材的存在不等于本集语义通过，仍要看原尺寸、移动端宽度、动作极值和邻镜接触。

## 自然性是独立质量维度

纸剧场的自然性来自观众熟悉的身体和物件关系：人物先注意对象，身体和视线再朝向对象；手先接触，物件才移动；交接完成后物件跟随手或在桌面有明确落点。单臂或局部接触层不是一律禁止：在明确的视角、画边进入/退出、人体连接点和同一材质关系都可见时，合理的操作特写可以成立；中央断臂、来源不明的悬浮部件、没有身体或支撑连续性的局部，不能作为正式动作主体。

文字必须属于它所在的纸件或题注区域。药品名称、药单标题、单位和勾选项要在自己的纸面内排版，不能穿过药盒、人物、桌面边缘或字幕；发现遮挡时先改纸件位置、层级和文字归属，再考虑缩放或删字。每集在 `qa/naturalness-review.json` 记录文字可读性、人物完整性、动作因果、接触落点、去文字反向读图和移动端复核。

这一检查与透明度、尺度、连续动态和听感分别记录。

`naturalness-review.json` 只记录版本、镜头范围和证据路径，不是独立形式门。机器可核对确定性绑定，不能因为根 `passed` 或字段存在就批准自然性；文字归属遮挡、身体空间连续、注意力与动作因果、支撑接触和跨镜状态，必须由导演与视觉 QA 逐镜查看原尺寸、手机宽度、动作中间与结果。文字包围盒报告只能定位疑点，不能自动判定自然；需要由本集导演和视觉 QA 结合事件前、接触时、落定后三个状态做语义判断。

## 每集独立制作与经验回流

一集必须按本集患者任务完成：单集故事、导演稿、分镜、关键姿态/粗动态、动画脚本、素材与尺度契约、独立镜头代码、预览、渲染、声音和交付回读。跨集可共享 kit 原语、透明素材、材质和经过审看的动作配方，不能共享整套镜头排列、统一故事节奏或固定人物收尾。

经验回流分三层：

- **本集修复**：回到最早责任文件，修导演、素材、尺度、实现或字幕，重新跑受影响下游。
- **可复用能力**：只有在真实镜头、邻镜和正常速度中成立的素材、动作代码或排景规则，才登记为可复用版本。
- **初稿规则**：把跨集反复出现的缺口写入 [初稿经验卡](../templates/series/09_episode_experience_note.md) 和工作台工具/模板，供下一集开工前读取。

每集收尾至少记录一条有效经验和一条失败边界。有效经验要说明它帮助观众理解了什么、在哪个镜头成立、依赖哪些素材和尺度；失败边界要说明什么条件下不能复用。经验卡不能只写“效果更好”，要绑定版本、镜头和证据路径。

## 开工前的最短复核

1. 本集是否有独立患者任务、误解、可见对象/关系、结果和行动？
2. 是否已经决定哪些内容属于 `world_scale`，哪些属于图解层？
3. 同场真实人物是否已完成共同标尺、姿态标定和试装？
4. 所有主要运动素材是否透明、身份连续、实际接入本集？
5. 画面是否误用“非真实影像”等防御性说明？能删除的先删除。
6. 是否有代表动作、整集粗动态、去文字反向读图和声音边界证据？
7. 本集完成后是否写入经验卡，并把可复用能力接回素材库或初稿预检？

工程检查只能确认文件、资源、构建和字节绑定；是否自然、是否有故事、是否帮助医学理解，仍由逐集画面和声音审看确认。
