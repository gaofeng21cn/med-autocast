# 线条动画

线是解释关系的主体，路径拓扑、笔顺与线端承担观看信息。抬笔必须保留，不能在断开的子路径之间生成无意义连接线；医学上的相连、分叉、阻断与穿越必须来自审定关系。

用有限线宽、少量重点色和足够空白；线条不是所有风格通用的装饰。节点、端点、方向和局部填色按功能区分，不能靠一串箭头弥补不清楚的对象。

绘线按弧长计时而非曲线参数平均推进，保持笔速感；必要时在分支或转折停一下。measurePath/trace 支持 M/L/Q/C，pointAt 可供线端或镜头跟随；它是细分近似，极端特写要加密。未审定的医学路径不能由自动拓扑生成。

镜头可随正在建立的关键关系轻移，但最终整图要回到可理解的构图；不能追线端导致已画关系不断出框。需要强调时重描局部或用留白隔离，避免全面闪烁。

声音可选短铅笔刮擦或几处转折轻音，不持续给每条线配噪音。旁白顺序与路径建立顺序一致。

失败模式：笔速忽快忽慢、线桥误连、线端跳回、先画无关装饰、最后没有读图停留。Canvas 可实现现有模块；SVG 是可替换路径后端，当前未把 SVG 适配登记为已安装能力。
