# 手绘纸拼贴

以完整纸面空间承载事件：环境可以是完整板，承担接触、揭示、压迫或转运的主体必须有独立透明层、连接点和前后遮挡。纸张厚度、撕边、剪刀缺口、纤维方向、铅笔或印刷痕迹共同建立手工质感，胶带、图钉与夹子只在确实固定物件的地方出现。不是给普通矢量图加一张泛纹理。

用有限的纸材家族与一两种焦点色维持一致；可以有报纸、薄描图纸、旧票据与牛皮纸，但不可把随机小件铺满重要医学关系。先按实际内容和认知主次定大小，再排空间，不能统一 PNG 外框。文字独立排也能成立；缺乏物件职责的大色带直接删掉。

动作来自媒介：折轴展开、滑入纸袋、图钉支点转动、撕开揭示、纸片堆叠、戳印接触。对象可用 on-twos，镜头保持连续。小偏差在本镜固定，接触后的 settle 衰减到静止；不让所有图层永久抖动。每次动作都有准备、落点和读图停留，动作弧由导演安排。

镜头围绕物件的意义变化：俯拍建立关系、近景看关键接触、沿传递物移到下一空间。需要跨镜时让承接物的位置和状态可追踪；不要规定必须有四种运镜。阴影随离纸高度变化，收纳由容器前层遮住，不能把遮挡变成屏幕矩形遮罩。

声音选择薄纸摩擦、轻碰、折痕与克制的木质/拨弦动机；重点接触取 score 命名事件，空白与静默同样能建立节奏。旁白有声线基线，音效不能盖过医学术语。

常见失败是背景卡片替代舞台、装饰线冒充关系、素材图册残片、悬空手掌、同一中心构图，以及把粒子和抖动当叙事。先改物件事件和构图，再打磨运动。模块仅提供技法，不能锁住单集导演创意。
