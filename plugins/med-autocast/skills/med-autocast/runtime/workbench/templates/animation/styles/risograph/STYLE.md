# Riso 孔版印刷

少量专色版、半色调、粗糙油墨与固定套印偏差形成 Riso。叠色得到第三色，纸纤维在墨层内可见；不是 RGB 随机杂点或每帧错位。

先设计分色：每版持有独立轮廓、纹理密度和偏移，multiply 或等效混色要看真实结果。文字与细小解剖尽量保留稳定单色，不让错版妨碍判断。

动作可让色版落下、滚印揭示、局部反印或叠版发生，偏移在本镜固定。对象运动与版内网点一起运动，不每帧换 seed；整体轻度停格可选，不成为全部动作。

镜头可从一个墨层的近景拉回完整构图；半色调尺度需在最终分辨率实际检查，远景可以减少网点细节。统一版色不等于所有集都同一个中央构图。

声音可用压印、辊轴轻击和克制的节奏；技术样例使用原创合成音，只证明事件同步。正式音乐风格仍按故事情绪选。

失败模式：随机闪烁、暗色叠到不可读、纹理覆盖小字、JPEG 中间帧的色度损失。保留 PNG 帧管线并同时看最终 H.264 平台编码，网点不应只在源 PNG 好看。

技法原件见 `../SOURCE.md`；可观看例子由 `animation_lab` 生成，故事稿与风格不变量分开保存。新片按故事重写，不复制样例时码。
