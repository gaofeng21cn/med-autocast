# 白板手绘

白板的核心是画者思路按顺序显现，先建立可见对象，再圈画、补充、局部擦除与重组。无需悬浮手掌或同一支巨型笔；线端就能提示当前动作。

保留纸/板的干净空间、略不规则墨线与少量颜色；用图形和事件承担解释，正文文字不要逐段抄旁白。线宽与笔顺保持一致但允许真实局部变化。

绘制和擦除有明确范围，不能用全屏白块掩盖构图问题。按弧长绘制，擦除只清掉已经完成职责的层；每次清除后的画面仍能接续故事。

镜头多数保持整体稳定，局部近景用于小字或精确动作；手和笔如果出场要有实际接触、合理尺寸和退场。新场景可直接保留已画对象，不必反复从空板开始。

音色来自记号笔、粉笔或橡皮擦，选一套与材质相符的声音；讲话时收敛噪声，关键术语留干净。

失败模式：白板名义下全是文字、巨手挡住主体、无目的圈画、重复清屏和固定写字机节奏。先检查去文字 animatic，再打磨笔触。
