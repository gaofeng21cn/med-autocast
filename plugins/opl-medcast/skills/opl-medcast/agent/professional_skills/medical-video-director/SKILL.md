# 医学科普视频导演

以显式 `workspace_root` 定位制作数据，按目标系列解析作者覆盖和后端档案。OPL 持有阶段运行；本 Skill 保留原工作台专业职责。下文 `scripts/`、`backends/`、`content/`、`productions/`、`work/`、`publish/` 均相对制作工作区，方法链接相对本 Skill。工具通过 [工作台工具接入](../../../docs/workspace-adapter.md) 定位：优先使用现有工作区入口，缺少通用工具时使用随包工具；不得默默替换工作区的专用修订入口。案例中的疾病、尺寸和作者选择只适用于对应案例。


目标是在内容草稿阶段共同设计患者能理解的视觉解释，并把审定方案落实成连续视频。按[十阶段SOP](../../../runtime/workbench/docs/04_医学科普视频系列SOP.md#0-十阶段流程与交接)，S05提前反馈、S06与`medical-video-content-planner`共同冻结故事包，S07取得最终音轨后排时选段，S08核对叙事承接。选题、证据及系列边界由内容策划负责，导演不替代医学复核。先从`workbench.yaml.series`读取目标作者档案，未覆盖时继承当前作者；后端从制作单或部署档案读取，不猜测身份、声线、形式或实现。

新设计先查[关键帧资产库](../../../docs/keyframe-library.md)，按观看任务选已有构图、人物关系和场景，再判断真实生成缺口。复用时核对原图、身份和使用边界，制作单记录资产ID及实际路径；新图收尾按差异化SOP第5节判断是否入库，不把库中普通角色替代作者母版。

## 从内容到镜头

当前视觉合同以[连续性SOP第0节](../../../runtime/workbench/docs/11_解释对应与叙事连续性SOP.md#0-视觉视频的首要原则)为准。第0.4节要求先备齐能执行的基础表达，再尝试增强；新镜头记录失败接回的具体素材及区间，“后期解决”不算替代。人物行动、具体物体和关系占据主画面，文字辅助。新片先共同设计旁白与可见事件；不能把旁白逐段变成文字框或泛动作。精确信息进入审定设备、记录、包装或结构；正确首帧不保证H3后续保持。批量前完成样片形式复核。

新系列或解释优化先读 [解释对应与叙事连续性 SOP](../../../runtime/workbench/docs/11_解释对应与叙事连续性SOP.md)。先建立整篇理解路线与固定病例/图示锚点，再按具体关系分镜；逐镜说明观看所得及前后承接。核心解释不能降为摆药盒、递资料等泛动作，单句多机制不能默认一段一镜。同概念保持同套符号，生成前审完整故事板。

1. S06先读单集简报、旁白草稿、系列边界和事实含义，设计完整事件链及估计节奏；此时不要求最终音轨已存在。S07读取冻结故事包及实际音轨时码，按问题变化、解释对象、转折和行动建议校准观看区间；镜头边界跟随语义，不按总时长平均切分。
2. 给每个区间写一张语义镜头卡：`narration_range`、同期旁白、`visual_intent`、观众应获得的观看信息、主体与空间关系、动作起点/发展/落点、素材类型。没有这些信息时先完成导演设计，不进入生成。
3. 先从本篇和同系列素材中选可用区间，核对同期含义、患者身份与来源；复用同一机制图或行动素材可以成立，但不能照抄整篇镜头顺序。相邻连续旁白可共用一个连续动作，不为镜头数硬切。
4. 从患者最容易理解的形式中选择：人物情境、简化医学关系、检查或就医动作、线索整理。医生/患者场景适合承接解释和行动，简化图适合展示位置、方向、多少、先后或三条路径。
5. 一个生成镜头通常只保留一个主要观看任务。人物镜头写清谁、在哪里、物体放在哪里、做什么；解释镜头写清核心对象、关系如何变化以及最后停在哪里。
6. 医学机制可以简化，但画面必须解释同期对象和关系。精确解剖不稳定时用审定位置图与确定性后期；只有旁白在讲检查职责时才用相应检查，不能用视野检查代替手术解除压迫。情境镜头承担承接，不能包办核心解释。

## 生成提示词写法

人物镜头默认采用完整头部的中景或全景，首帧在所有人物头顶预留约画高8%的构图余量；这是设计余量，不是自动验收阈值。正向提示同时写清完整头部、双手和关键物体在动作起点与终点均在画内，优先固定机位。不再使用“躯干作为背景”或只保留手和菜的推近设计。确需物体特写时，采用不含头颈与大块躯干的俯拍对象构图，避免半头或无头身体；先核对实际首帧，再审核完整选用区间。提示词不能保证模型守住边界，后段漂移须缩短可用区间或替换素材。

确需H3新素材时读[H3提示设计](references/h3-prompt-design.md)，按真实模式用官方结构；能力证据见[调研策略](../../../runtime/workbench/docs/12_H3调研与制作策略.md)。先看完整首帧，明确参考职责；一个语义任务可能仍包含多个高风险交互，要按实际依赖缩小动作。运镜为可选增强，必要信息不能依赖模型保持构图。完整提示走 `official_prompt` 直通，保存实际发送稿；旧 `motion_prompt` 有历史包装，不能混用。未验证模式不作为本篇必需能力。

提示词先写可见的正向画面，并按时间顺序描述：开场构图，主要动作或关系变化，结尾构图。明确人物与关键物体的上下、前后、桌面/地面等空间关系，让模型不必猜摆放方式。把旁白转成一个可观看的任务，而不是把整段旁白照抄进提示词。品牌、字幕和可读文字统一在后期完成。

图像与解释同时出现，短标签靠近对象；保留字幕，删掉重复讲义。先用基础素材排整篇与相邻连接，字幕及标签在实际画布预排。原音轨长于动作时接相关对象或结果，不让模型撑满整段；必要时调整旁白并重对齐命中部分。首尾帧、Ref2VA和运动上下文仅作有界试验，不把continuous或参考图存在当连续性证据。

生活物件应承担清楚的叙事意义：它与当前旁白直接相关，观众能看懂它代表的变化或行动，并且它的摆放和使用方式符合日常空间逻辑。

## 生成后的调整

对象显现时机可对照`build_timeline_review.py`的同期画面、SRT及可选逐词定位；不按等间隔依次亮出器官或路径。日常切点检查与HyperFrames取舍见[剪辑与联合时间轴检查](../../../runtime/workbench/docs/13_剪辑与联合时间轴检查.md)：简单图示未取得渲染提速，仅为复杂可控动画候选，不自动更换合成器。精确对齐是导演职责，现有PIL/FFmpeg同样可以实现。

全季去重复及图生实测见 [制作文档 6.3.3](../../../runtime/workbench/docs/02_视频呈现与制作.md#633-全季图生视频复盘) 与 [差异化 SOP](../../../runtime/workbench/docs/07_角色与视觉差异化SOP.md#31-全季复核经验)。先审本篇患者身份和完整场景；裁切同一对谈不算新镜头。无需读报告时优先选择资料闭合的已有片段；中央医学内容错误的区间停用，转向具体基础素材，不默认改图重抽或用标签掩盖。

先按[差异化SOP第3.2节](../../../runtime/workbench/docs/07_角色与视觉差异化SOP.md#32-全季与跨季时间轴复核)比较实际全季时间轴，任务涉及共享素材的多个系列时跨季核对。候选放回同期旁白后，按实际合格时长重新编排；短区间反复插入或动作重启不能为凑新素材占比而保留，减少插入、合并连续表达或接已审相关对象。生成与改图预算统一遵循连续性SOP第0.4节：模型行为失败接回预定素材，仅明确输入/调用缺陷允许一次定向修正；已反复失败的任务不换seed或模式继续。精确关系由审定画面承接，静态源如实声明 `reviewed_visual_insert`，不伪造运动或用文字掩盖结构错误。

## 输出

维护 `production_plan.yaml` 的实际素材、源区间、旁白时码及视觉意图；新生成才更新对应镜头提示。只改视觉时保持原 WAV/SRT，显式填写实际路径与时长。历史提示和回执保留原请求，不冒充新版提示已实测。医学条件仍由旁白/SRT 持有，`visual_annotations` 只提供必要短标签。

时间轴生成器的 `unassigned_*.mp4` 只是待绑定占位符；镜头来源必须按真实生成回执填写，不猜测供应商文件名。参考图使用作者档案当前资产；旧制作单的历史快照不自动成为新作者母版。
