# 医学视频视觉质检

以显式 `workspace_root` 定位制作数据，按目标系列解析作者覆盖和后端档案。OPL 持有阶段运行；本 Skill 保留原工作台专业职责。下文 `scripts/`、`backends/`、`content/`、`productions/`、`work/`、`publish/` 均相对制作工作区，方法链接相对本 Skill。工具通过 [工作台工具接入](../../../docs/workspace-adapter.md) 定位：优先使用现有工作区入口，缺少通用工具时使用随包工具；不得默默替换工作区的专用修订入口。案例中的疾病、尺寸和作者选择只适用于对应案例。


视觉 QA 的目标是判断可用片段是否动作自然、与同期旁白同向。完整规则见 [系列 SOP 第 6 节](../../../runtime/workbench/docs/04_医学科普视频系列SOP.md#6-质量检查)。联系表、像素差异与播放器状态只能证明各自检查范围，不等于完整音画、听感或医学终审。

先从目标系列登记读取作者与生产目录；不能用全局当前作者替代系列显式选择，也不能把其他系列的 QA 报告当成本集证据。按[十阶段SOP](../../../runtime/workbench/docs/04_医学科普视频系列SOP.md#0-十阶段流程与交接)，S06先看整篇故事板是否能解释当前问题、前后承接及替代方案是否成立；S07审核真实源片可用区间；S09审核合成后的当前版本。故事板通过不等于源片通过，源片通过不等于成片通过；视觉复核不替代医生医学终审。

本工作台当前用户要求采用后台检查，不直接打开或操控桌面播放器，不自动播放视频或音频。使用离线帧序列、切点对照、旁白/SRT时码与音轨分析；覆盖不到的连续动态或听辨项目保留pending。用户之后明确要求播放时再按其指令执行。

## 候选观看法

1. 按生成回执找到对应候选，先用后台有序帧序列核对动作弧线，再按目标旁白时码核对可用区间；不自动播放或发声，未覆盖的动态/听辨范围单列。
2. 依次判断三件事：观众能否说出这个画面正在帮助理解哪句话，动作是否真的发生，人物和作者档案要求的视觉风格是否连续。
3. 以“可用区间”记录结果。前半段自然、后半段漂移时，写清可用起止时间；找不到可用区间就交导演采用预定基础素材，不能默认整段重抽。
4. 重点观察观看信息、人物表情、手部动作、关键物体的空间位置、镜头节奏、背景稳定性和观看舒适度。画面不必逐字解释医学，但应与同期旁白谈论同一对象、关系或行动。
5. 检查模型自生文字、标识或小窗，品牌只认可后期固定资产。排除受影响区间；主体和医学关系污染时不得遮盖冒充通过，按预定替代处理，不另开提示优化循环。
6. 当作者档案启用 `visual_identity` 时，所有品牌人物镜头必须对照其 `character_reference` 和 `traits` 检查身份；明显变化不能解释成画风变化。未启用人物身份时不虚构这项门禁。
7. 有前篇时对照其实际已审版本并记录路径，不能把未发布写成已发布。差异化按 [角色 SOP](../../../runtime/workbench/docs/07_角色与视觉差异化SOP.md) 判断；首篇记录系列基线，不虚构上一集。功能素材可复用，但同一患者的身份漂移与整篇照搬要退回导演。

源片状态与范围必须同时有效：最新accepted为false即停用，残留usable_range不能覆盖否决。缩略联系表不能批准微小伪字、头顶或手部；选用区间首尾与新增/改变切点另做清晰复核，临界段加密，动作疑点扩展前后窗口。换源或收紧范围后重看实际成片及整篇节奏，执行细节见[连续性SOP第7.1节](../../../runtime/workbench/docs/11_解释对应与叙事连续性SOP.md#71-从缩略联系表到清晰切点)。

## 成片观看法

人物完整性是独立必查项：逐镜核对所有人物的头顶、头发、脸、下巴及画面边界，不能把半头或无头躯干解释为普通近景而放行。纯对象俯拍仅出现自然伸入的手臂可以成立，仍须判断是否与旁白相符。审首帧、中段、末段及全选用区间的有序帧序列；头顶靠边或推近时加密到逐帧检查临界区间。记录源片与成片分别是否截断、实际查看步长、问题时码和替代区间。抽帧仅支持抽帧范围内的结论，不能承诺零漏检；检测器只能辅助定位，不能代替视觉语义判断。修改成片后按当前版本复核受影响片段及相邻切点，不能直接继承旧结论；日常剪辑不计算或强制校验哈希。

先执行[连续性SOP第0.3节](../../../runtime/workbench/docs/11_解释对应与叙事连续性SOP.md#03-形式验收在技术验收之前)的形式复核，同时核对第0.4节的基础表达：新生成未采用时是否仍有实际可用镜头承接；备选是否变成大量静态或文字页。暂去解释文字后，主要动作/对象关系应仍可辨认；切点承接具体对象。精确标签可以必要，人物不能只是文字背景。样片不通过不扩大相同形式，结论绑定成片和实际范围，不冒充用户认可。

H3对照按[研究方案第6节](../../../runtime/workbench/docs/12_H3调研与制作策略.md#6-有界比较与失败处理)保留全部候选与可用源区间，比较动作结果、风格/身份漂移、旁白对应和相邻连接。原生推镜/跟随能揭示对象时可成立，静态图缩放不算生成动作。预览通过不能继承给新采样/高分辨率结果；社区参数和官方示例不是本机出片证据。解释质量由语义审核判断，不以像素运动分数或字段齐全代替。

按 [解释对应与叙事连续性 SOP](../../../runtime/workbench/docs/11_解释对应与叙事连续性SOP.md) 区分直接解释、操作示范与情境承接；核对核心关系是否实际可见、符号是否前后一致、事件是否倒序、不同患者是否被误读为同一病程。仅“相关且无矛盾”不能批准为解释充分。记录逐镜、相邻切点和整篇结论及实际查看范围，抽帧不代替动态或完整音画审核。

按全时长帧序列、旁白/SRT、切点与音轨分析核对：上一句话是否已经结束，新画面为什么在这里出现，它是否帮助理解当前句子。再检查开头、字幕、BGM电平、品牌和结尾行动边界；这些后台证据不等于完整音画听感。若画面虽然好看、有运动，却无法说明它服务哪一句旁白，应回到导演重设或重新排时。

关键帧入库按[差异化SOP第5节](../../../runtime/workbench/docs/07_角色与视觉差异化SOP.md#5-关键帧沉淀与复用)与[资产库说明](../../../docs/keyframe-library.md)执行：记录真实来源、看图范围及复用限制，问题图登记原因；静态参考价值不继承为关联视频或新成片通过。

## 记录与交接

切点、解释落点或声音疑点可用`scripts/build_timeline_review.py`输出同一范围的画面+PCM波形+审定SRT+可选ASR时码。用项目`.venv/bin/python`运行；单集切点批量入口、示例与边界见[剪辑与联合时间轴检查](../../../runtime/workbench/docs/13_剪辑与联合时间轴检查.md)。Whisper是节拍局部时码时同时提供`--beats`，不能直接当全局；ASR错字不得覆盖SRT。输出PNG/JSON只是范围内定位证据，不替代全片覆盖、连续动态、听感或医学审查。

同类构图故障的成因与检查陷阱见[人物构图复盘](../../../runtime/workbench/docs/production-lessons.md)。抽帧前用结构化时长校验时码，并确认本次确实产生新图；超出源时长可能不输出，不能误读临时路径中的旧帧。共享源按各集实际选用区间复核，记录停用范围与可用范围。

本轮实测：正确关键帧仍可能在后段出现假报告、假影像、底部伪字或自动淡黑，必须检查完整可用源区间。只可清理已确认没有主体和信息的空白污染，并复看清理结果；中央内容错误要退回。新场景进入成片后另查标签与人物/字幕遮挡，不能继承旧位置的通过。细节见 [制作文档 6.3.3](../../../runtime/workbench/docs/02_视频呈现与制作.md#633-全季图生视频复盘)。

在 `visual_delivery_manifest.json` 写入来源、旁白区间、视觉意图、可用源区间和实际审核结论。新任务从 pending 开始，不复制模板或旧片 approved。只有相应审核成立才填写 `approved_watchable_motion` / `approved_audio_visual_alignment`；稳定插图不申报运动，编码误报处理见制作文档第 6.3.2 节。

复用未变源区间可继承有依据的动作审核，但仍须判断新排时和当前含义。只做逐秒画面对照 SRT 时，明确写 `review_method` 与继承依据，完整听感保留 pending；前三篇历史 approved 字段不能被扩读为重新完整试听。技术门通过或播放器到结尾不授权补填通过；受阻时列出未完成项并继续独立文件工作。

含品牌人物的篇目还要记录 `author_profile` 和 `brand_identity_match`；生成镜头记录实际 `backend_id`。系列差异、听感和医学审核分别记录，机器不能用状态、帧哈希或相似度分数代替语义判断。
