# 医学科普视频制作 SOP

完整方法以随包的[十阶段流程与交接](../runtime/workbench/docs/04_医学科普视频系列SOP.md#0-十阶段流程与交接)为准。六个 OPL 阶段是执行组织方式，六个专业 Skill 按原职责跨阶段参与，不删减工作台能力。

| OPL 阶段 | 原工作台职责 | 参与专业 Skill |
| --- | --- | --- |
| evidence-plan | S01 作者定位与表达基线，S02 受众选题，S03 事实研究，S04 系列设计 | 总编排、内容策划、导演 |
| story-directing | S05 单集叙事与 S06 内容视觉联合设计、故事包冻结、完整代表样片方案 | 内容策划、导演、视觉 QA |
| media-production | S07 配音、字幕、镜头及源片选段，S08 剪辑、品牌、混音和成片合成 | 后端、导演、视觉 QA、成片打包 |
| visual-review | S09 技术、视觉、连续动态、完整听感与医学复核；必要时回溯事实和故事 | 视觉 QA、成片打包、内容策划 |
| review-handoff | S10 当前母版、双平台文案、说明和清单交付；授权上传单独回读 | 成片打包、内容策划、总编排 |
| asset-curation | S10 反馈修订、事实影响传播、已审关键帧与经验沉淀；跨阶段恢复 | 总编排、内容策划、导演 |

按当前请求决定范围；规划不启动生成，纯视觉修订复用原 WAV/SRT，纯文案更新不渲染。S05/S06 在正式配音前共同设计；最终音轨用于校准。完整代表样片先审形式再扩展同类制作，不能用单镜成功代替。S09 待审允许交付如实标注状态的审看包。

事实变更回 S03，篇目边界回 S04，旁白回 S05/S06，纯视觉回 S06—S08，文案物化留 S10。反馈追踪受影响事实、集和镜头；不盲目重做整季。参见[工具与原合同接入](workspace-adapter.md)、[交付](delivery-sop.md)、[恢复](recovery-sop.md)。
