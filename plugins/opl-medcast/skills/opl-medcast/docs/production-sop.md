# 医学科普视频制作 SOP

适用于新系列、单集修订和有界恢复；现有可用成果直接复用，不为凑流程重跑整季。

1. 读当前请求、workbench.yaml、作者与媒体后端 profile、目标系列制作单，确定受众、期望集数和当前修订。OPL Med Cast源码路径与制作workspace_root分开。
2. 核对医学来源、适用人群、日期和证据强弱，形成证据表与单集患者行动目标。不同指南差异由专业判断说明，不能拼成普遍阈值。
3. 导演先组织整篇故事。按旁白时间码写可见事件、解释作用、镜头承接、拟用来源与替代，不先批量生成再硬贴配音。
4. 查关键帧catalog与现有源片。静态参考需查看；已有WAV/SRT未变就复用。真实缺口才交后端；模型服务日志不能代替出片。
5. 剪辑前根据当前制作单预检选集、母版、源ID和区间。accepted=false即拒用，不读取其残留可用区间作为批准。
6. 按完整源片区间、时间轴与成片切点检查；临界医学细节及所有人物构图需实际查看。听感、动态、医学分别记录。
7. 当前母版、制作单、字幕、配音、QA与publish审看入口一致后交付。反馈返修所有受影响使用处，而非只修首次发现的一处。
8. 仅将已看且值得复用的关键帧入库，将实证经验更新相应专业SOP。保留产物来源、原图和使用限制。

原工作台十阶段S01—S10在标准Agent中合并为六个面向交付的阶段；合并不删除质量职责。见agent/stages/manifest.json。
