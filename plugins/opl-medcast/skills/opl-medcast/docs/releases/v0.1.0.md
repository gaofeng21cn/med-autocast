# OPL Med Cast 0.1.0

The first release of OPL Med Cast brings medical evidence, story direction, audiovisual production, review handoff, and reusable keyframe curation into one medical education video workflow.

- Three actions, six stages, and six professional skills follow the OPL declarative agent structure.
- Production SOPs capture practical lessons: reuse reviewed assets and unchanged narration, exclude rejected footage, review story continuity and framing, and repair specific findings.
- Three read-only helpers inspect workspaces, search the keyframe library, and check delivery packages.
- English and Chinese READMEs share the same English workflow illustration in the OPL hand-drawn style.

## Installation

```bash
codex plugin marketplace add gaofeng21cn/opl-medcast --ref v0.1.0 --json
codex plugin add opl-medcast@opl-medcast --json
```

Download the source archive, Codex plugin bundle, and `SHA256SUMS` below. Helpers require Python 3.10 or later and PyYAML 6.x. See the [installation guide](https://github.com/gaofeng21cn/opl-medcast/blob/main/docs/installation.md) for details.
