# 视听复核 SOP

先核对当前制作单、源片审查决定和整段旁白。机器守路径、区间与状态，AI判断解释对应和连续性。

- 源片accepted=false绝对优先于usable_range；残留范围不能重新启用被拒视频。
- 审完整采用区间，并查入出点和相邻镜头。人物头顶、面部、手部、医疗设备、表盘或数字等关键细节看实际尺寸；联系表只定位，不能替代批准。
- 只剩短区间时重编整个叙事段，检查碎镜、跳切、主体变化与观看任务；不循环或长冻结凑时长。
- 对跨集多样性看真实源、场景和讲述作用，不能用裁切、改名或开头几秒变化冒充不同。
- 静态关键帧、源视频区间、continuous_motion、成片technical、visual、完整listening、medical分别记录。缺证据写pending；不把抽帧检查称作完整动态审看，不把音频文件存在称作完整听审。

默认后台检查，不自动播放器或发声。需要完整听审而当前不允许发声时，保留pending并交付明确待听项。发现构图或医学源问题，查询所有使用处，逐项修订并重查切点，不能只改首处。
