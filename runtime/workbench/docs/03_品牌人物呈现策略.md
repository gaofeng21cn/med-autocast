# 品牌人物与视觉叙事策略

状态：通用品牌人物与视觉叙事方法  
当前实例：`profiles/authors/dr_mie.yaml` 选择手绘医生陪伴式讲解；这是作者档案，不是工作台的硬编码默认

本文档保存可复用方法和已验证经验。展示名、人物特征、参考图、参考声音、品牌文字、动画形式和混音参数的唯一当前来源是已选作者档案。

## 1. 当前结论

V2 的问题不是“医生不能出镜”，而是要求 H3 同时维持人物身份、逐字口型、医学解释和复杂转场。V3 又走到另一个极端：用静止医生规避口型，最后变成 PPT。第二篇连续十轮精确医学镜头返修仍失败，进一步说明需要改变导演任务，而不是继续微调同一提示词。

当前 `dr_mie` 档案的节目形式如下：

- 旁白和字幕完整承担医学事实、条件、风险和行动边界。
- `Dr.咩` 可以坐着或站着讲解、翻阅资料、示意方向、倾听患者或陪伴决策；她是稳定的观看锚点，不必每次与精确医学对象共同构图。
- 患者、家属、就医、取资料、进入诊室等生活情境负责代入感和节奏变化。
- 品牌识别由固定声线、人物特征、插画语言、色彩和纯文字 `Dr.咩` 共同建立，不把全部品牌压力压在一张人物图上。
- MiniMax H3 是手绘动画的主要生成路径，但它只负责自己擅长的人物、情绪、环境和简单动作，不负责精确解剖、报告、文字和多条件信息图。
- 医生可以有自然说话感和轻微嘴部动作，但不要求与旁白逐字同步；大张嘴、面部畸变或明显音画冲突仍淘汰。
- 片头和片尾使用同一独立审定头像做短时识别，持续使用小尺寸纯文字 `Dr.咩`；头像不从患者场景、复合图或 H3 输出中临时裁切。

这项调整承认一个简单事实：对患者科普而言，画面的首要价值是降低枯燥感、建立信任和引导注意力，不是把每句话变成精确动画教材。

## 2. 三层职责

三层各自负责不同问题：

```text
旁白与字幕：医学上说什么
生成动画：怎样让人愿意继续看
审定插图：少数必须看图才能理解的结构
```

生成镜头至少满足：动作自然、与当前话题相关、不会产生相反或危险暗示。它不需要离开旁白独立表达完整医学含义。

对于 1-3 分钟视频，常用视觉单元按模型适配度排序：

- `presenter`：医生坐姿或站姿讲解、抬手、转身、翻阅资料、指向画外。
- `patient_moment`：患者担忧、休息、回想变化、准备就诊、与医生交谈。
- `caregiver_action`：家属扶稳、拿手机、递资料、陪同进入医院。
- `care_path`：走进医院、候诊、问诊、抽血、查看影像等简单可识别动作。
- `reviewed_visual_insert`：短暂、静止、已经审定的解剖或关系图，仅在确有必要时使用。

常用镜头为 5-10 秒；单一人物和单一动作可延长到 10-14 秒。长旁白用多个简单镜头承接，不把更多概念塞入同一个生成任务。

## 3. 按故事选择呈现形式

所有形式都使用同一节目骨架，但按题材调整 H3 场景：

| 故事类型 | 默认呈现 | 人物职责 | 不适合的做法 |
|---|---|---|---|
| 解剖、机制、检查原理 | 医生讲解 + 简单就诊动作 + 极短审定插图 | 用声音讲机制，图只做必要定位 | 让 H3 精确画结构或流程 |
| 症状困惑、初诊焦虑 | 患者时刻 + 家属支持 + 医生解释 | 建立代入感和行动方向 | 把症状画成诊断图标清单 |
| 治疗选择、随访决策 | 医患交流 + 查看资料 + 复诊路径 | 体现共同决策和持续管理 | 让 H3 画完整分支图 |
| 常见误区、单点判断 | 医生纠偏 + 两种生活情境 | 用人物反应和切换维持节奏 | 依赖屏幕文字和勾叉 |
| 1-3 分钟综合科普 | 医生陪伴式讲解 + 患者 B-roll | 形成稳定节目感 | 一个镜头承担多个医学概念 |

成人医学科普默认使用最后一种。这里的“讲解”是画外音配自然表演，不等于口型驱动的数字人口播。

## 4. 品牌人物的合理出场方式

### 4.1 品牌分层

品牌不等于人物出镜时长。当前按以下层级建立识别：

1. 稳定的温柔成年中文女声和一致的表达方式。
2. 统一的手绘线条、配色、转场语言和医学图示风格。
3. 后期确定性叠加的作者档案品牌文字。
4. 经本人确认的卡通人物，在必要叙事节点作为引导者出现。

即使某一条机制密集视频里人物很少，前三层仍能维持品牌连续性。这样不会为了“露出”而牺牲信息密度和自然度。

### 4.2 人物进入画面的四种方式

- 正面讲解：坐在桌前或站在诊室内，做一个自然手势；旁白独立播放，不要求逐字口型。
- 侧身示意：面向患者、资料或画外空间，抬手或转身一次。
- 医患互动：倾听、递资料、邀请坐下或一起查看无文字影像袋。
- 结尾陪伴：人物与患者处于安心、准备行动的场景，品牌文字由后期叠加。

开头可以使用会自然活动的医生，也可以直接进入患者情境；唯一不可接受的是全屏静态人物或假推镜。

### 4.3 固定识别特征

- 具体外观、衣着、气质、品牌文字和参考资产只从已选作者档案读取。
- 已启用人物身份时，视觉 QA 按 `character_reference` 和 `traits` 审核；未启用时不强行生成品牌人物。
- 片头片尾头像必须是已单独审定的资产，不得从场景图、多人合影或生成视频中临时裁切。
- 生成场景内不得自行生成角标头像、品牌文字或人物小窗；这些由后期确定性叠加。

### 4.4 动作与表情边界

- 不要求 H3 生成逐字口型；出现大张嘴、持续 `O` 形嘴或夸张下颌运动时淘汰该区间。
- 每次出场只承担一个可读动作，如抬手、递物、翻阅、侧身、起身或轻微点头。
- 使用同一审定角色参考图和清晰的单动作提示，不要求跨多个复杂场景保持完全一致。
- 自然呼吸、目光和手势可以服务观看体验，不必强行绑定一个医学信息点。
- 人物不遮挡关键解剖、字幕或患者行动信息。

同一原则适用于医学解说图：静态图不以持续缩放、平移或漂移制造“在动”的错觉。没有明确语义的镜头运动应删除；需要变化时，改用局部高亮、路径、脉冲、显隐或有信息的新镜头。

人物时长不设上限；限制的是静止和重复，而不是人物本身。即使整条视频以医生为主，只要动作自然、镜头有变化、旁白有价值，也可以成立。

## 5. `dr_mie` + H3 原型的历史经验

本节是当前实例的复盘，不是新作者或新视频模型的配置。

### 5.1 V2

V2 证明 RTX 4090 + H3 能完成端到端视频生成、女声旁白和后期字幕，也暴露了生成式人物口型和表情不可控。它是技术链路证据，不是人物呈现基线。

### 5.2 V3

V3 使用闭口参考图替换首尾人物段，成功去掉了大张嘴和伪口型。其复现脚本、参考图和成片继续保留，作为“静态替换能够规避口型”的技术证据。

但 V3 的用户观看验收未通过，原因是：

- 0-3.5 秒和 9.3-14.4 秒均为静态人物，约占全片 60%。
- 人物没有与医学对象、患者情境或动作发生关系。
- 中间医学动画只有约 5.8 秒，无法成为全片视觉主线。
- 画外音与全屏静止人物并置，仍造成“她为什么不说话、不行动”的违和感。

因此，V3 不能写作“自然呈现已验证”或后续默认模板。后续也不能只给 V3 加眨眼、点头或手势，因为这不会修复医学视觉叙事不足的根因。

### 5.3 第一篇完整原型

第一篇 121 秒成片不再让医生人物承担连续讲解。患者形象只负责“拿到报告后的担心”和“准备就诊资料”等故事情境；医学画面负责垂体位置、激素、视路、变化和检查组合；`Dr.咩` 由同一参考声线、纯文字品牌和片头片尾独立头像建立识别。

这次还暴露了一个容易误判的问题：H3 曾在患者场景左上角自行生成患者头像小窗，看起来像品牌角标。后期再叠正确医生头像不能消除这种身份混乱。因此品牌身份有两个硬边界：场景生成阶段禁止任何头像小窗；构建阶段只接受独立审定头像文件，不允许对大图使用固定坐标裁切。

第一篇结论是这套“最小人物露出”比 V2/V3 自然，但当时仍缺少多篇验证。

### 5.4 第一季第 2-12 篇

其余 11 篇此前采用静态 animatic，未达到手绘科普动画要求，相关通过结论已经撤销。重制使用固定声线、确定性字幕和 H3 手绘人物场景；不再要求 H3 精确生成机制、检查、治疗和随访流程。

第二篇先验证“主持医生 + 患者情境 + 就医行动”的新骨架。第三篇进一步验证内容优先的低频品牌人物方案：15 个语义区间中仅 R02、R15 出现 `Dr.咩`，其余镜头由本篇症状、关系、检查和证据整合承担。第 4-12 篇复用这种能力边界和语义镜头卡方法，但必须按各篇内容改变开场、主空间和镜头语法，不能复制同一医生串场模板。

### 5.5 前三篇优化后的复用经验

2026-09-05 前三篇返修补充：品牌人物、患者连续性与素材复用按 [角色与视觉差异化 SOP](07_角色与视觉差异化SOP.md) 执行。第一、二篇本轮均复用已有动画；第三篇稳定片尾医生可承担品牌识别，但其纸带运动不证明自然人物表演成功。第二篇删除身份跳变和无关母婴画面后，保留家中、家属求助、到院与资料整理主线；第一篇急症插段明确作为情境例外。已有片尾医生时关闭额外头像，避免重复人物遮挡。技术 QA 通过不代表完整听感和医学终审完成。

## 6. 参考案例带来的边界

- [Psych2Go](https://psych2go.net/the-evolution-of-psych2gos-animation-style-where-we-started-and-where-were-heading/) 说明简化人物和小动作可以配合旁白，但有效画面仍需跟随内容变化；“经常静止”不等于整段只放一个人物。
- [Amoeba Sisters](https://www.amoebasisters.com/press-kit.html) 的品牌角色是进入知识世界的导航员，教学主体仍是细胞、过程和图示。
- [Kurzgesagt](https://www.youtube.com/watch?v=lXfEK8G8CUI) 依靠一致的视觉世界和机制动画建立品牌，而不是让角色持续对口型。
- [Dr Binocs](https://www.youtube.com/watch?v=YS7vsBgWszI) 的主持人负责串场，大量时长切入知识对象；其儿童向夸张表演不适合直接复制给成年患者。
- [Asta](https://jakubsvehla.com/project/asthma-allergy) 与 [Hank the Heart](https://doi.org/10.1002/pul2.70072) 提示患者化身可以承载生活经历和情绪，但角色动画不能替代完整、准确的医学解释。

这些案例提供的是形式证据，不是可以直接复制的风格模板。项目仍需从自己的受众、医学内容和品牌气质出发建立视觉系统。

## 7. 后续原型的验收问题

在生成新视频前，先完成一份 1-3 分钟分镜草案，并逐节拍回答：

- 当前画面是否自然、有人味、不会让患者觉得枯燥？
- 它是否与当前话题相关，并且没有制造相反或危险的医学暗示？
- 这个镜头是否只有一个主体、一个场景和一个动作？
- 是否错误地把未经验证的文字、报告、精确解剖或复杂流程交给了当前生成模型？
- 这张医学图是否真的不可缺少；能否只靠旁白讲清？
- 如果模型失败，是否应该换成它更擅长的情境，而不是继续赌同一精确构图？
- 全片是否完全不让生成模型排字，字幕和作者品牌是否都由后期添加？

后续先用镜头表或低成本 animatic 检查人物分布、场景重复和节奏，再调用已选生成后端。画面不需要在静音状态下讲清医学知识；最终验收必须把旁白、字幕和画面一起看。
