# JavaScript 动画默认技术路线

本工作台的新医学科普视频默认采用本地 JavaScript/SVG/Canvas 动画。浏览器负责绘制，Playwright 按固定时间轴逐帧捕获，FFmpeg 编码并与旁白、字幕和音乐合成。它不需要 MiniMax H3 或其他视频模型，适合在本机 CPU 或 Apple Silicon 上重复渲染，且每一帧都能用 `window.__seek(t)` 精确复现。风格与渲染器分别由 `style_id` 和 `renderer` 指定，默认 `paper_collage` + `canvas2d`。

2026-09-29 流程更新：代码是镜头执行器，不是导演。必须先完成[纸剧场导演流程与质量框架](18_纸剧场导演流程与质量框架.md)规定的故事卡、处理稿、关键姿态和 animatic；代码阶段只实现已冻结的主动作、承接物和时间事件。当前 v13 中第一幕手部残片、机制幕无语义短线和字幕整宽底纸说明“素材、导演和实现层混写”仍会产生低质量初稿。

## 原型评估

| 原型 | 做得好的地方 | 主要问题 | 结论 |
| --- | --- | --- | --- |
| `科普视频JS/` | 场景拆分清楚，拼贴、纸张、缓动和 Edge TTS 组合能快速验证叙事方向；几乎零部署成本 | 直接打开 HTML，依赖全局 `Math.random()`，没有统一的可寻址时间轴、稳定帧捕获、渲染回执和后端合同；音频脚本与页面耦合 | 保留为灵感和素材试验，不作为生产入口 |
| `productions/js_collage_short/` | SVG/Canvas 绘制由时间纯函数驱动，种子噪声稳定；`window.__seek(t)`、Playwright 定帧、节拍清单、音频混音、FFmpeg mux 和审计脚本已经形成闭环 | 目前仍是单片项目，入口和输出路径写死；还需要把项目路径、帧率、音频和输出写入制作单 | 作为默认后端的参考实现和第一条生产样片 |

## 默认工作流

```text
审定旁白与故事包
  -> 患者问题地图与系列分集
  -> 单集故事卡、视觉处理稿、关键姿态
  -> 低成本 animatic（去文字审片先通过）
  -> 查已审关键帧/插图库，补充透明单件素材
  -> 素材准入检查（医学关系、alpha、来源许可、接触点和逐镜覆盖）
  -> 全篇统一配音基线，校对术语、情绪和音轨时码
  -> 导演稿把每镜写成可执行的动作、承接和声音事件
  -> JavaScript/SVG/Canvas 项目实现 window.__seek(t)
  -> Playwright 固定 fps 捕获 PNG
  -> FFmpeg 编码，叠加审定字幕、旁白、BGM 和音效
  -> 去文字审片、连续 strip、整片视听和医学画面复核
```

素材选择必须先复用当前系列和工作台的已审资产，再生成或检索新素材。ImageGen 生成的图像进入 `assets/` 或单集工作目录前要保留提示词、生成时间、来源和人工取舍记录；生成图像只承担被明确设计的主体、材质或背景，不替代医学事实审核。

素材不能只按风格挑选：每件素材都要回答“谁使用、从哪里进入、与什么接触、在哪里停下、如何退出”。图集、带背景合成图、主体边界不稳定的透明 PNG 只能进入风格参考，不得进入正式运动层。手、人物和医学主体优先单件生成或合法检索；JS 负责纸张、胶带、图钉、阴影和文字的确定性排布。

配音顺序是：先确定作者/医生形象、参考声线和表达方向；有 `Dr.咩` 基线时，使用本机 IndexTTS 2.5 读取 `voice.reference_audio`，整篇共用同一参考音频、情绪参数和模型实例。只有用户没有设定声线基线时，才使用 Edge TTS `zh-CN-XiaoyiNeural` 做保底技术测试。Edge 需要联网，不复刻作者声线，也不能替代作者基线。2026-09-28 本机 Apple Silicon runtime 按固定 commit 建立于 `$HOME/ai/index-tts-mac`，从工作站复制模型，MPS smoke 和 8 段垂体瘤旁白均已真实生成；主配置因此切换为 `indextts_local_mac`。

视觉默认也先锁定作者档案：`Dr.咩` 的角色参考、手绘拼贴材质和品牌边界在 S01 冻结，再进入导演分镜。镜头必须有可见的开场构图、一次关系变化和落点；纸片展开、遮挡、汇合、折叠和景别变化承担叙事，轻微不规则运动只用于手工质感，不能用随机抖动掩盖静态标签动画。

MiniMax H3、Seedance 等视频模型保留在后端目录中，只在 JavaScript 动画无法承担的连续真实动作、复杂镜头或用户明确选择时使用。切换后端必须在制作单记录 `primary_video_backend`，并保持同一套内容、字幕、音画对齐和医学审核门。

## 生产合同

每集 `production_plan.yaml` 继续记录 `delivery.primary_video_backend`。使用 JavaScript 后端时增加：

```yaml
animation:
  renderer: javascript
  renderer_id: canvas2d
  style_id: paper_collage
  style_profile_ref: templates/animation/animation_style_registry.json
  project_root: productions/js_collage_short
  entry: work/render_frames.mjs
  mux: work/mux.mjs
  fps: 30
  seek_api: window.__seek
```

`animation.renderer: javascript` 保留为旧制作单的后端兼容字段；`renderer_id` 才是具体的 Canvas/SVG/DOM/WebGL 适配器。所有适配器共享 Score、Shot、Asset、Layout、Review 合同，不能为同一集维护第二条主时间轴。可用风格和成熟度见 `contracts/animation_style_registry.json`：`paper_collage` 当前 active，`line_art`、`scientific_diagram` 等可按项目选择，未实现的选择记录质量债务并继续交接。

现有 `js_collage_short` 仅提供渲染机制参考，不代表艺术风格、素材正确性或完整听感已通过；其中入口与输出仍有单片路径，新的单集要先按本集制作单实现并验证项目入口，不能直接把该短片当通用模板。浏览器预览、静态 animatic 或单张关键帧不算动画候选。`final/video.mp4` 只有在动画门、技术 QA、视听对齐和医学画面复核均有证据后才能进入 `publish/`。

默认艺术风格为叙事性的手绘拼贴（hand-drawn collage），具体素材与配音入口见[素材准入与配音基线](13_素材准入与配音基线.md)。用户已否定 `deliveries/pituitary_tumor_js_short` 的素材和语气质量，该样片不能作为默认风格验收依据。

生产顺序固定为“患者问题地图 -> 系列故事圣经 -> 单集 episode_blueprint/beat grid -> 粗动态分镜 -> 素材计划与准入 -> JS 时间函数 -> 字幕避让 -> 固定帧/连续 strip QA”。分镜必须为每镜写 `visual_intent`、读取顺序、因果事件、动作起点/发展/落点、转场、素材层级和字幕安全区；素材计划必须优先准备透明底、可独立运动的医学主体和情境主体。一口气把旁白变成代码会造成标签堆叠、动作职责不清和字幕遮挡，不能作为默认生产方式。质量下限和持续打磨循环见[纸剧场前置策划与质量门](16_纸剧场前置策划与质量门.md)。

## 手绘拼贴的分镜与字幕预排（本轮修订）

先完成整片分镜和低成本动态分镜，再准备缺失素材，最后实现 JS。分镜是制作输入；从已有代码反写的分镜只能记录现状，不能冒充前期设计已完成。动态分镜用现有旁白和粗略纸片检验观看任务、剪辑点与阅读时间；由制作代理自主判断并修订，不逐镜等待用户确认。

每镜写清起点、关系变化、落点和下镜承接。围绕同一件物体建立叙事，例如“报告展开为解剖窗口 → 信息汇成评估 → 分出并行路径 → 装订为个人计划”。镜头在对象特写、人物中景、桌面俯拍之间有目的地变化；避免每镜都固定标题、居中主体、四周标签。装饰纸屑和轻摆只提供材质，不能代替事件。

素材按动作准备：可独立翻动的纸页、夹子、前后遮挡层，以及确有需要的人物姿态。医学结构使用正确且已核对的透明主体；纸带、折页、印章可用确定性 JS 绘制，不为简单道具强制图生。先做能验证核心动作的短段，再完成全片；多张大场景图不能替代可操作的层。

字幕安全区在构图阶段预留，正文与动作的运动包络、阴影、旋转和运镜缩放均须避开。当前横屏候选使用 1280×720 中的 x=60、y=610、w=1160、h=100，正文下缘目标不超过 y=595；尺寸是本片设计，不是所有画幅通用常量。检查正文彼此是否重叠，不能只查字幕。优先调整构图、删掉与旁白重复的长句或分时呈现，不用缩小字号挤满画面。竖屏需重新分镜和排版。

字幕轨道默认透明，不使用整宽底纸。只有当字幕纸条本身是故事物件，并且有进入、固定、翻页或退出动作时，才允许使用独立纸片承载字幕；它必须在分镜中登记物理来源和运动职责。

固定帧检查覆盖动作前、极值、落点及切点两侧；逐秒联系表支持全片排版复核，但不替代连续运动、完整听感和医学终审。把旁白静音、暂隐藏长标签后，仍应看出对象发生了什么变化。

新版工作流在 MP4 编码前调用 Med Auto Cast 随包 `render_javascript_animation.py --preview --review-candidate`。项目声明 `window.__cuts` 和 `window.__seek(t)`；预览生成每镜五个关键姿态、联系表和浏览器错误报告。先看这些画面并返修构图、透明层与字幕避让，再编码成片。本工作台 Dr.咩系列沿用 `profiles/authors/dr_mie.yaml` 中的声线、品牌纸章和已登记人物基线；纸章以固定字形、材质、位置及片尾盖章动作建立系列识别。单集人物是否出镜由故事决定，不出镜仍是 Dr.咩 系列，也不等于跳过人物基线。只有用户明确放弃人物基线时才记录为跳过；品牌标记和专用声线分别按作者档案决定。
