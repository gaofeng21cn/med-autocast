# 新用户首片：本机 JS 手绘拼贴

此入口的目标是让智能体完成专业决策和实现，用户只提供主题、受众、大致时长及已有素材。工作区、脚本、分镜、素材、动画、配音、字幕和审看包由智能体准备。不能以环境报告或技术 smoke 代替完整样片质量。

## 开始与可跳过项

1. 先定位用户选择的目录。空目录调用随包 `setup_workbench.sh --workspace <目录>`；已有目录先检查，保留专用实现和作品。系统包缺失时按当前机器与授权安装；只在真正需要管理员权限或缺少信息时询问。运行 `--check` 确认使用工作区 .venv、真实浏览器和中文字体。
2. 推荐确定医生形象和授权参考声线。用户不提供时默认不露脸、不叠头像、采用平静的 Edge `zh-CN-XiaoyiNeural`；这也是有效基线选择，不能阻塞创作。已有授权声线用本机 IndexTTS。用户明确跳过时运行 `configure_voice --mode edge`，保留参考音频；恢复用 `--mode reference`。全篇只使用一种模式，换声后重新校时。
3. 智能体建立 series 登记和本集路径，参考 `templates/series` 完成内容、来源、事实和叙事设计；不要求用户手写 YAML。事实及风险边界按具体主题审核，不自动继承示例疾病的结论。

## 形成稳定的制作起点

- 新工作区采用 1280×720、24 fps 的本机 JS 起点；用户有明确平台画幅时按平台调整。此参数不覆盖已有作品的制作单。
- 风格统一为 hand-drawn collage：纸张与剪切边、独立可运动的透明主体、手绘描线与材质、轻微有种子的运动。镜头必须包含观看对象的动作或关系变化，并由遮挡、推拉、纸张展开等动作衔接；大幅静态海报缩放和标签堆叠不能当作风格完成。
- 医学主体先查已审资产，缺口使用 ImageGen 或有许可的网络素材。主体、器官、人物、前景、纸张分层准备；检视透明边缘、医学位置和视角。逐镜登记用途、限制、参考和来源，拒用素材不能通过候选模式放行。
- 先做分镜、素材计划和字幕避让，再写 `window.__seek(t)`。时间轴不能依赖实时时钟或无种子的随机数。所有字幕在真实画布检查中文字体、正文、时码与遮挡；不把字幕或医学文字交给图像模型生成。
- IndexTTS 固定参考音频、模型和情绪参数。Edge 默认整篇合成、固定 rate/pitch/volume，再响度归一化；场景接缝、音色、兴奋程度须完整审听，响度指标不能代替。音乐和音效从属于旁白，允许没有音乐，禁止为了补声场盖住人声。

## 运行与交付

共享 `render_javascript_animation.py --audio <最终音轨>` 接受单集 index.html，串接浏览器定帧与 FFmpeg。音轨时长为主时间轴；保存独立修订输出，不覆盖旧成片。使用固定时码抽帧检查接缝、运动落点与字幕；技术检查核对时长、音视频流与完整解码，语义审核看片判断。

首片先交可观看审看包，明确标注素材/视觉、完整动态、听感/语气、医学、发布的真实状态。缺图就补正确素材，构图差就改镜头，声线漂移就重做对应音轨并重排下游；不能为完成状态退成 PPT 或冒充专业质量。没有真实完整样片与审核依据前，不宣称“所有主题稳定达标”。后续复用已认可的美术、配音基线、工具和镜头动作，而非照搬完整篇目。

视频模型仅在制作单明确选择并有具体收益时使用。默认安装、首片创作和本机渲染不依赖 H3、4090、NAS、Whisper 或付费图像接口；已审素材与人工校对字幕可完成该路线。Edge 与 ImageGen/在线素材需要网络，因此“本机渲染”不能宣传为全流程必然离线。
