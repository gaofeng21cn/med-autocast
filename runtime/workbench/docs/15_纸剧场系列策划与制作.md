# 纸剧场：从医学素材到一季动画

2026-09-30 补充：[纸面舞台与声音导演](22_纸面舞台与声音导演.md)将完整场景、可表演透明层、前景接触、动态分镜和音乐弧线连接起来。系列复用纸材与音色语言，逐集重新设计空间、主焦点与可见事件；不复制首集整套构图。

更新：2026-09-28。默认技术路线是本地 JavaScript 手绘拼贴；视频模型只有用户显式选择时启用。品牌、医生形象与声线从作者/系列档案读取，用户可分别显式跳过人物和专用声线。本文补充系列 SOP 的 S02—S08，不新增阶段编号。前置策划的字段、质量下限和持续打磨循环见[纸剧场前置策划与质量门](16_纸剧场前置策划与质量门.md)。

2026-09-29：单集不能从旁白直接翻译成 JS。必须先完成患者任务、视觉处理稿、关键姿态和粗动态分镜；完整流程、当前样片审计和外部方法取舍见[纸剧场导演流程与质量框架](18_纸剧场导演流程与质量框架.md)。

品牌识别不等于医生人物出镜。系列档案可以规定固定的图形印记、字体、位置、材质和片尾收束动作；人物只在故事需要其行动时出现。某集没有人物不表示跳过已建立的人物基线，品牌仍可连续存在。通用 Skill 负责读取和复核规则，不写死具体品牌。

## 选题先成为患者任务，再成为剧目

资料研究同时提取事实、患者处境和可见对象。事实库持有医学结论与条件；问题地图记录患者在发现、评估、选择、恢复、长期管理中遇到的困惑；视觉库分别登记解剖核对参考、生活物件、风格参考及直接使用许可。漂亮插图不构成事实证据。

拆集看的是认知任务是否独立：患者要改变哪个判断、可以做哪一步、哪些条件必须留在本集。几个问题若共享同一个判断和行动，应合并；需要不同诊断条件或行动时再拆。低频亚型可以做支线，不强迫所有观众按教材顺序看完。急症入口在相关集保留，不能当下集悬念。

系列计划要回答每集为什么存在、为何在此处、与邻集哪里不同。内容策划与导演共同维护 `07_paper_theatre_bible.md`：系列一句话、患者旅程、角色职责、跨集母题、每集故事、可复用素材与不能复用的整套构图。它引用事实库，不建立第二份医学真相。

## 每集是一件物体改变了意义

纸剧场可以没有连续主角；故事也不必制造虚构病例。选一件患者认识的物体作锚点，例如报告、戒指、药盒或复诊本。开场它承载困惑，行动让新的关系可见，转折修正最初判断，结尾它成为实际下一步。故事一句话可以是“患者想弄明白 ___，但 ___，于是通过 ___，最后知道 ___”。

分镜写观看所得，不把每句旁白机械切成一镜。每镜注明：主体/道具、起点、可见关系变化、结果、景别/视线引导、下镜接续物、读取顺序与停留、医学条件、字幕避让、声响事件。动作发生后给观众看懂结果的时间；若一个镜头塞不下两个含义，拆镜或删掉次要内容，不能加速旁白解决。正式音轨只校准已设计的节奏。每镜至少保留一个因果事件，镜头长度由读取所需时间决定。

每镜再加两项导演字段：`motion_route`（本镜如何持续发生）和 `carrier`（如何把动作或物件带入下一镜）。`motion_route` 不能填写“轻微漂浮”或“随机抖动”；`carrier` 不能填写“淡入”。

叙事动作优先选择展开、翻面、套叠、揭开、交接、装订、移动观察窗、遮挡显现。纸片入场前有方向提示，运动结束有重量和阴影收拢，角色眼神/手势领先于身体。微小抖动、颗粒和漂浮纸屑只能补质感。把字幕和长标签隐藏后，仍应看见对象如何改变。解剖主体不得为了卡通效果拉伸或改变邻近关系。

线段只在确实表达指向、边界或医学图标内部结构时使用；不能用无语义的连接线、贯穿斜线、裂纹或刻度填充画面。短标签的纸片按文字包络设定尺寸，避免大块空白卡片抢走主体。容器纸片应先画在素材后方，不能把已发生的线索或动作盖住。

## 素材先适合操作，再适合装饰

先画粗略关键姿态和低成本动态分镜，确认核心解释成立后再生成成套素材。优先复用已审资产；缺口用合法网络素材或 ImageGen。大场景图只作背景或风格稿，不能替代透明主体。

资产计划按镜头动作拆层：背景纸、人物身体/所需姿态、手中物、前后遮挡片、医学主体与邻近结构、阴影、确定性文字。层只在需要独立运动时拆分。给每层稳定 ID、锚点、原始尺寸、透明边界、可用视图和医学禁画项。PNG 有 alpha 不等于抠图正确：把角色放在浅色、深色、饱和色三种底上查看头发、眼镜、白衣、手和鞋；不使用全图按亮度/颜色删除像素的方法，避免把材质和黑发也抠掉。生成输出保留原 alpha，不二次全局色键。

材质要有差异：纤维纸底、彩纸块、铅笔线、半调/印刷纹理、贴片接缝与薄阴影可组合使用。医学结构、皮肤和品牌服装保留自然颜色；不要用统一滤镜让全部画面偏绿或偏黄。背景材质的对比低于主体；同一镜头只有一个视觉焦点。由作者/系列档案指定调色与材质，不能把某个案例的米黄或青绿固化为通用主题。

手部素材单独审查：手必须有明确动作、腕部方向和接触点；不能用大张半调手覆盖主体来制造“有人在操作”的感觉。若动作不需要手，改用纸页、图钉、夹子或镜头运动完成叙事。

## 本地实现与边做边审

使用显式 `SHOTS`、`EVENTS`、资产映射和帧率；画面、字幕、音效读同一份事件时间。全片时间与镜头局部时间分开。`window.__seek(t)` 必须可乱序调用并得到相同画面，纹理和手工位移按资产/姿态固定 seed；不能累加前一帧的状态或使用未固定随机源。图片解码、字体和项目 `window.__ready` 完成后才截图。

可在 24 fps 输出中让纸片每两帧更新姿态，运镜和字幕保持稳定；轻微位移与旋转按画面大小调节，不把这种风格限制强加给所有对象。医学细节需要稳定时禁用抖动。阴影在飞行与落地时有变化，动作节奏由含义决定，不让所有层同时套同一缓动。

粗动态分镜检查故事；素材检查剪贴与医学关系；每镜实现后直接 seek 检查动作起点、极值、落点、切点两侧和**精确 t=0**。首帧必须有真实构图，禁止彩色占位块或全屏遮罩掩盖资产。现有 `preview_local_animation.mjs`/`render_javascript_animation.py --preview` 可在 MP4 前审画面；联系表之外，还要看每镜 12 姿态的连续 strip 和全片节奏。strip 中若纸片只是同一缓动反复入场，说明镜头事件没有成立，应回到导演稿。正文的运动包络、旋转阴影和运镜都要避开字幕，竖屏重新构图。

配音固定授权参考、模型和情绪设置，保留原稿与实际合成文字。医学术语、引号边界、数字、英文缩写、各段衔接须核对；必要时去掉朗读不需要的引号或将问题句自然分句，医学含义不变。异常发音重生成最小片段，再更新实际时间、字幕及相关镜头；不用整段变速掩盖错误。IndexTTS 为有专用声线的默认，Edge TTS 只作无专用基线的后备。响度、ASR 和同参数不证明语气听审通过。

音乐跟随解释的呼吸，纸张/夹子等声音只服务可见动作；不强制每次剪辑卡音乐节拍。急症段平静、明确，可降低配乐，不用兴奋声线、惊吓警报或闪屏。交付分别记录技术、素材/静态、连续动态、完整听感和医学复核；本次仅规划不能写成整季成片验收。
