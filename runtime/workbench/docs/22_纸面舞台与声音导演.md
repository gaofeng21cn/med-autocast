# 纸面舞台与声音导演

2026-09-30。适用于代码驱动的纸剧场。画面丰富度来自有层次、有动作职责的完整场景，制作质量来自导演、美术、动画、剪辑和声音的联合打磨；不是不断增加标签、脚本规则或装饰数量。

## 先设计完整画面，再拆可表演的层

导演先确定这一镜在哪里、观众先看什么、什么关系会改变、最后留下什么。用完整风格帧核对空间、材质、色彩与注意力，再从动作反推需要的独立层。环境可以丰富，当前主动作仍要清楚；背景物件不必全部动起来。画面被拼贴填满不意味着信息、文字和运动也必须同时填满。

环境板、透明主体和前景有不同职责。环境板建立诊桌、生活空间或就医入口；透明主体承载医学关系和可见行动；前景提供真实遮挡、接触和深度。环境板可以有撕边、不同纸材、胶带、纸夹、印刷纹理和纸做的建筑，但不把关键动作烘焙在大图里。需要打开的门、需要收入的资料、需要改变的医学关系仍须独立可控。图片中生成的 MRI、检验数值、医生身份或可读文字不能当事实，优先删掉或换成已审来源。

| 步骤 | 创作产物与实际作用 | 发现问题后的处理 |
| --- | --- | --- |
| 内容与故事 | 患者问题、医学条件、锚点物件的意义变化 | 回到事实或叙事，避免为丰富画面引入新结论 |
| 视觉导演 | 空间草图、风格帧、主焦点、景别变化、读取次序、声音弧线 | 构图重复或只剩文字时，先改场景与事件 |
| 动态分镜 | 真实旁白或临时声音下的准备、变化、落点、理解停留及邻镜 | 先调时间与因果，不等最终编码才审片 |
| 素材 | 环境板、透明单件、连接点和遮挡轮廓；来源与医学边界 | 素材不适合动作就替换，不拿白卡掩盖 |
| 逐镜动画 | 局部坐标、层序、命名事件、重量、相机与物件承接 | 返修受影响镜头；同一物件的内容和状态跨镜延续 |
| 声音与剪辑 | 音乐段落、声音事件、旁白避让、静默和结尾尾音 | 不改声线补音乐情绪；改音乐或最小问题片段 |
| Review 与交接 | 精确候选、已看范围、发现、修复、剩余质量债 | 保留可消费结果，进入下一项独立工作 |

这些是推荐的创作交接，不是脚本启动门。已有作品从真实缺口继续；字段或材料不完整时保留可用部分和待办，不重复制作。医学错误不能用装饰补救，安全替代、移除问题层和局部返修可继续推进。

## 纸的物理关系比装饰更重要

用一个主要动作调动多层空间，例如报告移开后露出相关物件、描图纸对位、夹子固定、资料在袋口后收纳、医院门沿真实门轴打开。胶带应跨在两种材料之间，纸夹应夹住纸，印章应落在接触点，入袋之后的资料在后续镜头仍然存在。无职责的手、彩色短条、悬空曲线和大块文字背景优先删除。

不同纸材保留各自颜色、纤维、半调或铅笔痕，主光与接触阴影保持一致。不要给整片统一套黄绿滤镜。纹理与外围环境的对比应低于当前主体；移动主体时先看它是否覆盖了邻近结构、文字和字幕，再决定是否调尺寸。

`src/kit/scene.ts` 提供有序环境、主体、前景绘制；镜头负责顺序和构图。环境默认不计入主体碰撞，前景默认计入，可用 `trackLayout: false` 明确排除装饰。完整环境画面本来就会延续到字幕下方，不能把它的包围盒误报成主体遮挡；也不能借环境身份排除真正的医学或动作主体。门洞等坐标登记为图像 anchors，资产替换时更新连接点，避免每镜散落坐标补丁。

纸件移动可按 on-twos 更新，稳定后允许停住。相机、旁白和字幕保持主时钟；接触与印迹共用同一真实事件，不因手工节奏把声效挪到另一拍。轻微不完美体现在边缘、微小材质差异、姿态与重量，不能让医学结构持续抖动。模板帮助控制局部坐标、遮挡和时间，不固定镜头数、素材数、构图或疾病隐喻。

## 按内容定比例，让拼贴画面平衡

纸片尺寸由内容角色、认知关系与视觉重心共同决定，不按图片外框统一，也不强求现实物件的绝对等比例。先区分解释主锚点、辅助证据、动作容器和环境，再辨别是同空间实物、纸上的插画还是比喻装置。解剖主体与试管共现时，不能让窄长的试管仅因素材纵横比而压过解释主体；视野窗也不应被当作真实眼睛、建筑或等比例实物。

透明边界可帮助排除外围留白，但不是语义边界或艺术评分。先看实际主体的宽高、剪影、色彩重量、纸边与阴影，再在完整风格帧中调整尺寸、位置、间距和前后层。主锚点通常更容易读出，辅助物件仍须可辨；不要一律放大所有主体，或缩到移动端认不出。允许为阅读与表演适度夸张。新旧影像需要对位时，同尺寸是有意的比较设计，不必强行制造差异。

比例规划进入分镜和动态分镜，逐镜说明哪些对象共现、谁先被读到、尺寸为什么这样安排。连续动作和同一景别的相邻落点保持稳定；景别切换可以有意改变屏幕尺寸，不要求全片同一物件永远一样大。资料页上的小插画另按纸面排版判断，不拿它和桌上的独立物件做物理比例比较。

缩放与位置一起修订，相关子物件、连接点和遮挡继续在同一局部坐标下管理。审运动的极值、接触、收纳终点与邻镜，而不只看静止姿态；缩小一张纸后仍核对字幕、标签、袋口和固定件。比例值由单集构图持有，重复出现的连续物件可共享本集尺寸参数。通用模板提供变换能力，不硬编码疾病、品牌、物件比例或自动阻断阈值。发现不自然的关系时返修该镜，保留可用候选并继续独立工作。

## 音乐先选叙事职责，再选生成方式

先写音乐简报：受众、情绪、旁白密度、开场动机、解释段的脉冲、转折需要加厚还是减薄、片尾如何收束。医学科普通常适合温暖、好奇、克制的器乐；急症用减薄或短暂停顿突出行动，不用惊吓警报、恐怖音色或突然兴奋的旁白。音乐无需每镜重启，不把剪辑强制贴在节拍上。

选曲有三条可替换路径：已核实许可的成熟作品，明确使用条件的音乐生成服务，以及原创乐谱由本地采样器演奏。先听少量候选放进真实旁白，再选择。服务不可用时可先完成无音乐审看，不静默调用视频模型，也不把廉价正弦波循环当成熟配乐。生成提示写清“无歌词、无语音、稀疏中频、可剪辑尾音与分轨”，但提示不构成听审或许可证据。

本地原创音乐可以保留 MIDI、演奏参数和分轨，使用 FluidSynth 或已有 DAW/采样器；音源许可单独保留。采样器不是核心依赖，已有 WAV 即可重混和出片。曲子与旋律归系列或本集，通用 Skill 不写死品牌动机、乐器或医生声线。

## 已落地的本机混音

现有入口支持单曲与分轨，不能同时传入：

```sh
python3 scripts/paper_project.py --workspace /path/workspace --project /path/episode mix --music /path/music.wav
python3 scripts/paper_project.py --workspace /path/workspace --project /path/episode mix --music-plan /path/episode/preproduction/music-plan.json
```

音乐计划中的 `tracks` 指向真实 WAV/MP3，路径相对项目根；每轨可有 `gain` 和可选 `loop`。可选 `bus_lufs` 规范音乐总线，`ducking` 调节实际旁白驱动的侧链：threshold、ratio、attack_ms、release_ms。没有音乐计划时沿作者档案读取单曲；没有音乐则保留旁白与有意义的拟音。

混音器输出 48 kHz 双声道，音乐做适度频段避让和首尾淡化，以旁白作为 sidechain 输入，分别保存压低前后的音乐、拟音、premix 和最终音轨。最后只做整篇统一响度处理，不对各镜单独归一化造成语气基线变化。当前起点为整片约 −16 LUFS、真峰值低于 −1.2 dBTP；音乐总线与压低参数是调音起点，不是通用艺术标准。

音效优先使用有来源的真实纸声；程序拟音须标明来源，不冒充录音。只有揭示、夹合、资料接触、盖章等有意义的事件需要拟音，画面与声音共用 `score.json` 命名事件。没有合适声音可保持静默，不为每次运动补 whoosh。

混音回执绑定旁白、乐轨、score 和输出，保存响度、声道、侧链参数及声音来源。响度、波形、ASR 与哈希只证明技术事实；首句发音、段间语气、音乐情绪、声效是否刺耳和完整听感仍单独审阅，不自动填写通过。后台检查不自动播放。

## 本轮实读的外部经验

以下资料于 2026-09-30 读取，作为方法参考。未复制第三方作品、角色或音乐。

- [Pasteup README](https://github.com/tmoody1973/pasteup)：参考图解读、独立素材、确定性本地合成、on-twos 与固定 seed。借其可拆层和手工节奏，未照搬固定色底与持续 wobble。
- [HyperFrames voice and audio](https://github.com/heygen-com/hyperframes/blob/main/docs/guides/voice-and-audio.mdx)：每条音轨有职责、按真实旁白排时、声音避让、只为有意义的事件配音、单独完整听审。落到本地混音与回执。
- [Remotion 官方 audio Skill](https://github.com/remotion-dev/skills/blob/main/skills/remotion-markup/audio.md)：音轨分层、显式起点、裁切和音量曲线，借鉴到现有时间轴；没有为这些能力强制切换 React。
- [Opus 5.5 案例索引](https://magiccreator.ai/claude-opus-5-5-demos)：索引列出 Moon Festival Collage、How Browsers Work 等代码动画，并标明部分纸纹理由图像模型生成。它支持“先做美术，再用代码编排”的方向；模型归属与效果仍为作者/索引声明，本轮未取得其完整工程并独立复现。
- [Planet Media 纸拼贴案例](https://planetmediallc.com/stop-motion-collage-video-with-google-flow/)：本轮搜索摘录提供独立对象、浅纸层深度、一个主焦点的设计建议。只作创作参考，未完整复现其 Flow 链路；不把建议的物件数量转成硬规则。
- [Scott Buckley 音乐使用说明](https://www.scottbuckley.com.au/library/using-this-music/)：曲库搜索结果明确署名许可与改编边界，可作选曲路径；本轮样片没有使用其音乐。

外部方法、工具测试和当前作品质量分别评价。完整作品仍按[导演流程](18_纸剧场导演流程与质量框架.md)、[单集工具](20_纸剧场单集工具与局部返修.md)与具体医学事实审阅。
