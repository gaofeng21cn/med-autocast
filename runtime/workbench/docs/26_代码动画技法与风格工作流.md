# 代码动画技法与风格工作流

本轮将 lemo-opuscar 的导演与媒介方法落到 MAC 的既有 Stage，不新增执行器或第二条时间轴。外部源、版本与适配取舍见 [来源](../templates/animation/styles/SOURCE.md)。风格库与可运行例子相互配合，默认仍是手绘纸拼贴。

## 从观看任务到代码

导演先用一个段落写本集的变化：患者看到什么问题，贯穿物件如何改变，结尾得到什么理解或行动。比较真正不同的讲法后选定，再读取对应 STYLE.md，写处理稿与 signature shot。病例、品牌与声线属于系列，不进入通用风格方法。建议稿见 [视觉处理稿](../templates/series/episodes/NN_slug/02_visual_treatment.md)。

把关键风格帧写成真实代码短动作，检查对象是否正确、纸材是否成立、认知比例与接触是否自然。可低保真试作与素材准备并行；正式素材的透明边界、层序、连接点和医学状态分别准入。接着完成有声音弧线的整篇 animatic，再逐镜生产。此顺序用于减少高成本返工，已有材料可跳转，不是脚本启动门。

动画制作 Skill 把导演事件转换成局部源码，导演保留物件、构图、镜头与节奏的最终选择。多种技法可以组合，主风格仍需清楚；不要为了调用模块把一集做成七种风格拼盘。

## 实际可调用模块

| 模块 | 能力 | 边界 |
| --- | --- | --- |
| paths.ts | M/L/Q/C 路径、抬笔、按弧长 reveal 与线端采样 | 细分近似，不自动生成或审定医学拓扑 |
| tracks.ts | 纯时间关键帧、相机轨道、hold/linear/smooth、接触后衰减、底轴展开与视差偏移 | 不持有独立时间线；复杂动作可自定义 |
| materials.ts | 稳定纸粒、撕边轮廓、透明胶带、纸厚阴影、水彩叠色/干刷、半色调 | 绘图技法，不是风格批准或物理仿真 |
| scene/stage/props | 局部层序、素材连接点、遮挡与变换 | 医学对象与认知比例由导演提供 |
| mix_audio + sound_materials | 注册声音与命名事件对齐、原创材质合成音 | 合成声音为试作底线，完整听感待审 |

源码位于 [paper_theatre](../templates/animation/paper_theatre/README.md)，kit 1.2.0。已有作品不自动替换 kit；仅显式迁移所需模块，重新看受影响动作和邻镜。

## 风格与声音

七个风格方法为纸拼贴、水彩与墨、线条、科学图示、白板、Riso 和纸立体书，见 [index.json](../templates/animation/styles/index.json)。既有其余风格仍可由导演规划。STYLE 是媒介方法，TREATMENT 是具体故事；不是照抄 DEMO 时码、品牌或旁白。

Canvas 样例实际实现不同动作，不是 SVG、Remotion 或 Three.js 适配的资格证据。纸立体书是 2.5D 投影，水彩是视觉近似。若医学关系需要真实三维视角或高精度路径，应另选择可用 renderer 并如实记录能力债。

每集联合设计声音 cue map。命名事件持有时间，声音材质配置只描述音色、录音/许可、力度与静默意图；不用另一个声音时码表竞争 score。注册素材优先；程序音效适合试作，正式片仍听辨。音乐支持已有混音计划与侧链；IndexTTS 授权声线优先与 Edge 保底策略不变。

## 样片、Review 与沉淀

通过 workbench_tool 调 `animation_lab list`；`create --project <新空目录> --complete` 依次构建、生成材质音效、预览和 MP4。失败保留源码与诊断，可从 build/audio/preview/render 继续。浏览器播放器不自动播放。独立样例包含七镜头共 52 秒；同一个 score 驱动画面与八个拟音事件。样例证明工具链和技法可用，不是医学成片。

实际单集继续用 paper_project，preview 输出每帧实际 renderer/style、全部画内文字框、字幕冲突/出框建议和 cue 显示时长；可选 TEXTS(t) 用于兼容外部代码的文字清单。它们是债务线索，不按字符数或速度裁决艺术，也不阻断后续 Stage。连续观看、完整试听、医学审核、技术与发布仍分开。

复用时保存模块源、kit 版本、示范 score、可观看样例与适用/失败条件；新单集显式复制版本，旧片不自动升级。工作区原画、成片、声线和审看片不进入源仓库。失败动作与修复理由也由策展保留，避免再次套用。
