# 纸片文字对齐 SOP

面向 Canvas 手绘拼贴纸剧场。解决一类高频缺陷：纸片上的标题、标签、条带题字与承载它的纸卡不对齐——短标签偏在纸卡左侧，长标签溢出纸卡左缘，条带里的题字浮在色带上方而不是坐在色带中间。

## 缺陷根因

`Stage.text()` 的 `textAlign` 默认为 `center`、`textBaseline` 为 `middle`。但每一集的本地 helper 用硬编码坐标放标签，x 偏移与标签长度无关：

```ts
s.paper({ x: 0, y: 0, w: 500, h: 92, ... });
s.text('每天稳定 比今天多少明天少重要', -230, -12, 24, '#33504c');
```

上面这段的意图是"把标题靠左放"，但 `textAlign='center'` 让文字中心落在 x=-230，14 个字宽度约 336px，实际跨度 `[-398, -62]`，而纸卡只有 `[-250, 250]`——左侧溢出约 148px。同一 helper 里短标签又会偏在纸卡左三分之一处。y 值（-12）通常合理，问题集中在水平方向与"是否放得下"。

这不是单集疏忽，而是 89 集共用的写法：审计 87 集发现 559 处纸卡文字配对，其中 307 处溢出纸卡边界、289 条条带标题 100% 偏离中心，最严重一条溢出 228px。

## 规则：文字坐标由纸卡 box 推导

纸片上的任何文字，坐标必须从纸卡的 `w`/`h` 推导，禁止手填与标签长度相关的偏移。用 kit 的 `cardTitle()`：

```ts
import { cardTitle } from './kit/labels';

// 宽短条带：色带题字双向居中
cardTitle(s, 500, 92, '每天稳定 比今天多少明天少重要', { size: 24, color: '#33504c' });

// 小便签：居中，留出顶部胶带位
cardTitle(s, 210, 110, label, { size: 20, color: '#33504c', y: 26 });
```

`cardTitle` 做三件事：

1. **x 由 box 推导**：`align='center'`（默认）落在纸卡中线；`left`/`right` 贴内边距。
2. **字号自动收缩兜底**：用 `measureText` 按 `w - 2*inset` 量宽，超宽就逐号降字号到 `minSize`。标签再长也不会溢出纸卡——这是下限保证，不是美术判断。
3. **y 可显式给**：小便签和横线卡保留导演给的垂直构图（胶带在上、横线在下），条带题字默认 y=0 居中。

`tagLabel()` 是小便签的便捷封装（默认居中、略微偏下）。

## 不能用本规则的情况

- **悬挂题注**：照片下方故意探出纸边的说明（如"以前"压在旧照片下缘）是有意的拼贴手法，不是标题，保持硬编码并逐集目视确认。
- **指向性标注**：文字指向画面某处结构而非承载它的纸卡标题，不走 `cardTitle`。
- **多分支纸卡**：纸卡宽度按 `shape` 分支（`if/else` 不同 w）时，单条文字无法静态配对到唯一 box，需在 helper 内按同一分支参数化 `cardTitle` 的 w/h，而不是让 codemod 猜。

## 机器门

`scripts/audit_label_alignment.py` 扫描每集 `episodeshots.ts`，配对 `s.paper({x:0,y:0,w,h})` 与其后的 `s.text`，按字号估算文本宽度，报告：

- `margin_left/right/top/bottom`：正值=文字完全在纸卡内，负值=溢出该边；
- `off_center_x`：文字中心相对纸卡中心的偏移，条带题条应≈0。

发布前期望：`overflow_any_edge = 0`、`strip_offcenter_gt_12 = 0`。剩余条目逐个确认是"悬挂题注"还是真缺陷。

`scripts/fix_label_alignment.py` 做机械改写（`s.text` → `cardTitle`），按 w/h 判断是条带（居中）还是便签/横线卡（保留 y），并跳过多分支歧义与非常规坐标。多分支和悬挂题注由 `fix_label_stragglers.py` 之类的定向修复处理。

## 与渲染的关系

改文字坐标属于源码变更，必须重新 `build` 再 `render`；`paper_project render` 会校验 build 绑定与音频 mix SHA，源码变了不重渲染会被"构建已过期"拦住。重渲染后抽帧复核首帧、条带题字与便签三类位置。
