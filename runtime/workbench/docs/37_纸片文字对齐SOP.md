# 纸片文字与遮挡 SOP

文字属于具体纸件，或作为独立题注存在。先决定它在镜头中的职责，再安排位置；不默认给每段字加色带。标题、正文、数值、单位、固定件与动作轨迹要在同一幅真实画面中成立。

## 本轮反复出错的原因

1. **坐标归属错位**：胸牌已经移到人物下方，名称却仍画在人物原点；或纸片在 group 中旋转，文字留在舞台坐标。纸与文字应共享同一局部变换。
2. **没有实际排版区域**：`Stage.text()` 只绘字，不知道纸件是谁。旧 helper 仅量宽、字号降到下限后继续绘制，不能保证不溢出；它也没检查高度和换行。
3. **容器与正文混淆**：打开的文件夹窄脊、日历后页、人物躯干、药盒封边都可能看起来像文字底板。糖尿病第 2 集的截图实际是钟挡住了人物，只露出躯干，标签又压在躯干上；缩字不能修复这种构图错误。
4. **只看落定、不看过程**：便签取出时扫过页头、笔杆穿过上一行、后进入的纸片盖住仍需阅读的标题。透明渐隐还会让两层正文同时透出。
5. **诊断没有传到交接**：成功预览曾以素材债覆盖布局债，造成帧内已有问题、顶层却遗漏。成功与失败分支都必须保留原质量债。
6. **审错了视图**：批量驱动曾用 `--clean` 隐藏部分文字和字幕，却把这些预览用于排版审查。默认预览现已恢复正式画面，回执标明模式；去文字视图只评估不用解释文字时的画面表意。

## 实现：显式区域，共享变换

纸上标题可用 `cardTitle`；正文、数值或独立题注使用 `textBox` 声明明确宽高。区域是创作者给出的布局选择，工具不猜最近的纸卡或自动移动物件。

```ts
import {textBox, cardTitle} from './kit/labels';

// 胸牌和名称共享原点、旋转、缩放。
s.group({x:1,y:48},()=>{
  s.paper({x:0,y:0,w:100,h:29,color:'#e6e7d9',name:'科室胸牌'});
  cardTitle(s,100,29,speciality,{size:18,inset:4,owner:'科室胸牌'});
});

// 题注独立存在，不需要大块底色。
textBox(s,{x:800,y:540,w:280,h:44},'从第一口开始计时',{
  size:26,minSize:22,maxLines:2,placement:'annotation',owner:'计时题注',
});
```

`textBox` 用实际 Canvas 字体 metrics 检查字形宽高，先尝试保持一行，在可读字号范围内调整，必要时换行。文字依然放不下时，不截字、不省略、不裁切；保留完整文字并返回 `fits:false`，供导演缩短文案、扩大真实纸件、重排或删除重复说明。不可承诺“再长也不会溢出”。

`Stage.text()` 是绘图底层原语，不再被当作排版 API。它现在用真实 `actualBoundingBox*` 记录字形边界；只有传入 `region` 才会生成显式区域记录。新增纸片标题、标签和正文默认使用 `Stage.label()` 或 `textBox()`，自由手绘字、图表刻度和屏幕题注才保留低层调用。`scripts/audit_label_contract.py` 会登记未绑定的低层调用，作为可消费质量债，不用静态计数阻断制作；正式 preview 仍是确认越框的依据。

`cardTitle` 的 w/h 是以当前局部原点为中心的真实纸件尺寸，y 是该纸件内的排版位置。小标题条已偏移时，先 group 到标题条，再使用 y=0；不能把“大纸件上的绝对 y”传给小标题条的高度。多栏正文各有区域，不能统一居中。`owner` 是可选诊断引用，不是流程启动门。

## 镜头：为阅读与动作留位置

- 必须读到的日历月份、检查标题和关键数值不靠紧密叠页展示；可并排、错层露出完整页头，或明确翻走上一页。
- 固定件按当前纸件尺寸留边，不以固定大夹子压到小标题上。药盒封边与可读面分开；数值和单位属于同一显示区。
- 铅笔按笔尖定位，笔杆朝向按本镜阅读区安排；检查写到下一行时是否扫过上一行。手、笔与目标共享轨迹。
- 打开的封面与插入纸页要有正确前后层。收纳完成后文字被封面正常遮住可以成立；未完成阅读时被盖住则返修。
- 透明度用来表达材质或转场，不能让两套正文重叠透读；真实纸页收纳优先用不透明遮挡。
- 悬挂题注、指向性标注允许在纸外，但必须有明确视觉归属、对比和留白；不能靠给任意文字套一个虚构大区域“消除报告”。

## 检查：当前画面为准

先 build，再 preview 当前受影响镜头与邻镜。看原尺寸首帧、进入路径、动作极值、接触点、阅读停留和切出；正常速度核对移动是否扫字。源码邻近关系、包围盒和联系表只定位，不代替观看。

布局复查使用普通 `preview`，不要传 `--clean`。普通预览会同时保存正式画面与辅助去文字画面；前者检查标签和字幕，后者检查视觉表意。`--clean` 会隐藏部分解释标签与字幕，不能作为正式布局审查依据。预览回执用 `primary_view: final|clean` 标明实际模式；历史未标模式的证据记 unknown，不推断为正式画面。

`window.__layout.textRegions` 保存明确区域、真实字形、字号、行数和 `fits`；`text_region_overflow` 是该区域确实放不下的诊断。旧文字没有绑定区域时，`unbound_text_subject_partial_overlap` 仅表示屏幕包围盒部分相交，不能猜所属纸件，也不能因为某个大背景包含了字就判通过。文字与文字相交、出画和压字幕仍需结合时刻判断。

全季定位用 `scripts/audit_text_layout.py --workspace . --previews <预览根目录> --output <工作记录目录>`；仅消费登记的当前单集，支持 `--override series/episode=/path/to/preview.json`。输出裁图、逐集索引和待归类疑点。疑点不自动改源码，不用数量、归零或字段完整性阻断可消费进度。旧 `audit_label_alignment.py` 只作源码导航，`fix_label_alignment.py` 不再批量改写。

代码契约先用 `scripts/audit_label_contract.py --workspace . --output <工作记录目录>/label-contract.json`，它回答“哪些文字仍绕过显式区域”，不回答“这些文字是否一定错误”。两份报告都必须绑定同一次正式 preview；文字属于哪张纸、是否应被后进入的物件遮挡，仍由逐镜原尺寸审片决定。

返修完成须看新预览与实际编码对应帧，再替换 publish 唯一最新版。布局修复只证明相应画面，完整动态、听感和医学 Review 的未审范围继续如实保留。经验写回最早出错的导演交接、制作 helper 与审片方法。
