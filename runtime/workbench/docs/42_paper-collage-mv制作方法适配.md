# 从 paper-collage-mv 学纸剧场制作

来源：[zexuanw958-svg/paper-collage-mv](https://github.com/zexuanw958-svg/paper-collage-mv)，读取日期 2026-10-18，commit `951e1cfd795e0d34e221a3575b54f57e190a06f5`，MIT。本次核对了 SKILL、philosophy / craft / motion / engine / taste、场景与纸艺引擎源码及公开画廊/对照图。上游模型对照和用时是作者报告，不作为 MAC 的独立效果证明。这里改写制作方法，未复制其人物、歌曲、字体、素材或引擎；本地样例为原创。

最有价值的是“先把一件事演明白，再做精致”，以及作者多轮纠正模型刷动作指标的经验。MAC 继续使用自己的 Canvas、单一 Score 时钟、资产库和医学审查，不安装另一套 MV 生产链。方法适用于手绘拼贴；其他风格可借鉴导演判断，不强加白纸边或木偶比例。

## 从一句旁白到可看的事情

先按语义段写“观众本来以为什么 → 看到什么证据/关系 → 现在能理解什么”，再用具体动词讲画面。这个过程与旁白联合修订，不把现成音轨平均切成几段后摆图标。

| 当前弱表达 | 更具体的纸剧场设计 | 必须保留的医学边界 |
| --- | --- | --- |
| MRI 和试管并排出现，再写“结构/功能” | 在同一会诊空间打开影像透视页看位置；镜头随另一路化验资料进入，二者对照后才形成判断 | 两项各有职责，不画成合并后自动得出诊断；不让试管和脑结构同样重 |
| “看字清楚”与“视野缺损”两张卡 | 同一个注视点保持稳定，周边目标按检查逻辑出现；随后切到正式检查与已核实的视路结构 | 看清字不等于视野正常；不能把家庭游戏画成可代替正式检查的自测 |
| 药盒、日历、资料袋逐个弹入 | 出门前翻袋检查，发现缺少实际用药资料，回身取来，放入袋中后再出门；手、袋口和资料保持接触 | 只演复诊准备，不把收纳动作冒充药物疗效或医学机制 |

没有变化的科学关系可以清楚地保持；不为每句旁白强加小意外。条件、否定、风险和不确定性要与声音同向，不能为了戏剧化把“可能”演成必然。解释复杂概念时可以跨句完成一个事件，不逐字卡动作，也不追求每秒都有新东西。

## 先造能表演的物件，再搭整场

导演选择道具时同时想它在戏里怎样被使用：打开后里面是什么，被拿起时哪里受力，进入容器后由哪层遮住，下镜保留什么。先做一张本集“道具状态图”，把真正用到的合上、打开、持握、放入、收好的状态排开，旁边附原尺寸局部。状态少的物件不用硬凑。

暂不看标签，先辨剪影和关键特征，再看材质及接触。试管、尿杯、药板、药瓶不能用同一瓶形替换；门必须有门框/合页/落地点，资料袋必须有后层、内腔和前袋口。动作中间仍要认得出物件，不只检查首尾。纸上的字与纸件共用局部坐标、变换和遮挡；接近屏幕边缘时不能只把字挪回画内，造成字纸分离。素材可以来自 mac-media-assets、合法网络资源、ImageGen 或代码绘制；来源不决定质量，也不禁止新创。

有角色才做姿态/表情小样：先重心、高低、朝向、距离和视线，再手势；每次表情变化要有触发，并保持到下一件事。医学内容不需要人人兴奋、哭笑切换或强制出镜。既有作者形象沿用母版，通用方法不规定年龄、外观、头身比或品牌。

## 把一件事演细，不把全片一直晃动

每段先用动词讲清，再在代码里安排实际时刻。手先接触，物件才随手移动；对象到位后身体/附属件才作相应反应。需要惊讶或利落操作时，保持旧姿势 → 短促到位 → 看清结果，比每两个关键帧间都慢慢变形有力。需要观察、慢回头或理解空间时则可以慢。事件密度来自内容、情绪和读图负担，不从样片抄节拍。

无角色时由物件状态、解剖关系或环境承接动作。必要关系保持稳定；环境微动小而不同步，不能让解剖、字幕或全舞台抖动，也不能用粒子掩盖没有解释。代码复用的是变换、关键帧、连接点、接触和材质，不是本集事件链。

本地 `kit/tracks.ts` 的缓动属于**离开该关键帧**的一段；上游 act 的缓动属于到达关键帧的一段。移植思路时注意这个差异。重复同姿态关键帧可以保留停顿；`hold` 用于有意阶跃，不能拿瞬移代替伸手或交接。时间仍读本集 Score，不能在独立轨另存一套主时码。

## 完整纸景、相机和转场一起设计

空间来自当前患者情境：住院床旁、复诊门口、检查室和家中餐桌应有各自的物件、光源、前后关系。满不是堆满：次要纸件建立地点，主事件保持可读；特写可以删去多余环境。可以用彩纸、水彩纸、描图纸、印刷痕和剪口，但不要求每件加胶带、所有纸边都白，或无条件压暗角。

先定有来源的亮处与焦点色，再加阴影和纸纹。浅色纸和窗光保持通透；暗场也保留视觉落点。不要所有颜色掺灰后再靠饱和色标签救场。纸边/投影在近景检查，不能随放大变成粗轮廓或烘焙光晕。医学对象的稳定色义和清晰边界优先于统一滤镜。

镜头替观众找证据：建立空间后靠近关键操作，跟随交接再落到结果；邻镜可以换景别、深度和框中框，但不按数量配额轮流推拉。该静止就静止。转场选当前戏中能承接的东西，可动作匹配、跟物移动、翻折场景、遮挡揭示，也可为解释清楚直接切。不能每次只是换一个盖屏物件；没有故事理由不必炫技。

转场中保持可追踪对象或有纸材身份的场景，逐帧看交接、最大遮挡和结束残片。普通实物/人物不依赖半透明消失解决重复，解剖透视和比较叠层的透明则有明确用途。不要把上游“转场类别最多两次”“很少硬切”变成医学片的硬指标。

## 一个镜头做深，再用整集验证

1. 内容＋导演完成语义对应、小戏、纸景与声音意图；用状态图验证核心物件，制作有角色才看角色表演样本。
2. 制作把本集最有解释力/风险的完整动作窗口做成真实代码：风格帧、动作中间状态、结果和邻镜。先修表达/身份，再修接触/节奏，最后材质细节。
3. 完整 animatic 检查故事与旁白是否互相解释；逐镜完成当前戏，不先给全季套相同动作。其他独立研究、声音、素材工作可以继续。
4. Review 先无文字反向读图，再恢复旁白和正式字幕；正常速度看节奏，strip/局部放大定位接触、纸边、字和遮挡。技术样例成立不外推所有集。

“换句测试”：把当前旁白换成同集另一句，画面仍完全成立吗？若是，检查它是否只是通用布景/摆资料；需要重新落实本句的关键关系。承接或情绪镜头可以不逐句解释，但导演要知道它的职责。对有角色的镜头再问：冻结胳膊，重心、距离、视线和状态仍在表演吗？这些是思考工具，不是自动打分规则。

## 工具不能自动宣布戏已经发生

`audit_motion.py` 只读 Score，事件稀疏不等于画面静止，字段齐全也不等于有动作。长事件间隔和相同事件顺序保留为回看定位，旁边可以列作者的停留说明；不因补一条 hold_reason 或改动作弧文字隐藏定位。不上动作数量、纸片数量、亮度、表情数或转场类型配额。

`resolve_motion_audit.py` 现只输出已有声明和待看位置，**不写 Score，不推断反应/落定，不猜空间方向、不自动挑代表镜头、不认证前后镜承接**。历史 `motion_director_evidence/v1` 来自自动补写，按未核实声明处理；其“审计清零”不是修好画面的证据。已有视频与发布文件不因本次方法更新被重渲染或升级审查状态。

## 本地可运行参照

`animation_lab create --study followup_bag --project <新目录> --complete` 生成原创“出门前补齐复诊资料”短动作、道具状态图入口、导演稿、同源预览和 MP4。它示范身体带动视线、从袋口发现缺项、取物交接、前袋口遮挡与结果停顿；无作者身份、无专用声线，不替代医学或成片审核。源码在 `templates/animation/paper_theatre/examples/followup_bag/`。按本集重新设计，勿把它复制成每集都翻袋。
