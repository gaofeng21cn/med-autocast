# 人物素材与画面尺度契约

这份契约处理两类反复出现的画面问题：人物被临时拆成圆头、梯形身体和独立手脚；复杂对象为了塞进版面被缩成无法阅读的小图。它约束素材准入和镜头复核，不规定每集的故事与构图。

## 一句话规则

主要人物先有完整、连贯、可复用的全身素材，再写动作和排镜；主要对象按叙事重量和复杂度占足画面，不能用标签勉强拯救一个看不清的主体。

医学科普视频读取目标作者档案。启用 `default_for_clinician` 时，所有医生身份、性别别名、`generic` 请求、旧公共医生 ID 与自定义医生别名均解析到当前作者的私有完整人物，姓名与形象不写入通用实现。缺姿态沿同一作者母版补齐，不换成公共医生，也不复制同一医生冒充多人。普通患者、家属等非医生角色仍按公共角色检索。作者人物、声线和品牌材料保存在私有工作区，不进入公共素材库或源码包；没有作者默认策略的工作区可使用公共医生。

导演稿、查询/取用结果、源码和 manifest 必须一起回读实际加载路径；作者范围始终隔离，通用医生的身份上下文不能被误认为作者身份。

## 人物：完整素材是生产入口

以下角色必须使用完整人物素材或预先制作的完整姿态包：

- 主患者、家属、医生或其他承担表情、对话、操作和身份识别的角色；
- 儿童、老人、孕妇等年龄/身体状态不能靠改色或等比缩放成人素材表达的角色；
- 承接报告、操作器械、坐下、行走、休息等动作，且观众需要看到身体关系的角色。

圆头、椭圆头、梯形躯干、独立腿脚和独立手片可以组成局部反馈或非叙事图标，不能临时拼成上述主要人物。允许在完整人物上增加独立袖口、手部接触层、衣袋、胸牌或道具，前提是主体轮廓、身份、连接和纸材质感连续。

人物素材在**剧本与分镜之前**按角色覆盖矩阵准备，至少检查：

| 维度 | 必须明确的内容 |
| --- | --- |
| 身份 | 患者、家属、医生、药师、普通路人，是否品牌人物 |
| 年龄与身体状态 | 儿童、成人、老年、孕期；不能用成人缩小代替儿童 |
| 姿态 | 站立、坐姿、行走、伸手、接取、躺卧、局部不适当前准备 |
| 视角 | 正面、四分之三侧、侧面，朝向是否能与对象建立关系 |
| 动作 | 独立动作、姿态切换、需要局部手部层还是完整替换姿态 |
| 裁切 | 头部、手、脚和接触点在当前景别中可见；透明边缘无残片和光晕 |

### 人物尺度：设计身高与原图像素共同标定

多帧动作先统一坐标空间。若裁切帧为原图中的(left, top, width, height)，帧内归一化点(u, v)须先转为原图像素(left + u×width, top + v×height)，再按原图宽高归一化；不能把帧内点直接当整图点。身体标定段、臀部承托、椅面、脚底、地面和接触点最终经过同一组变换。椅子也按实际座面与人物腿部试装，不从椅子透明外框猜宽度；有意景深差要同时作用于人物与家具。

例如原图880像素的身体段代表110厘米，原图密度为8像素/厘米；场景采用3像素/厘米时整张图等比缩至37.5%，这段身体显示330像素。另一张图即使分辨率不同，只要按同一场景密度换算，人体长度就能对齐。PNG 的打印DPI标签不参与；换图或重采样后须重新核对原图尺寸、哈希与标定点。设计身高与身体段厘米共同构成角色标尺，不能只改身高字段而沿用不一致的身体段长度。

分件器械也按真实装配试装：展开、已佩戴与拆下状态要分别适配。空筒原件叠到手臂上不等于已佩戴，旋转或挖孔不能修复错误的前后关系；准备贴合的前层、核对裸露部位和肘部，再让气管跟随原图接口的同一变换。放大为局部图解时重新建立近景空间，避免沿用全景房间形成巨型肢体的误读。

`human_scale.nominal_height_cm` 是角色脚底到头顶的设计身高，不是现实个体的实测身高。`scale_family` 指明确的同一人物母版，不能把所有成年男性或女性合并成同一身份。每件姿态另记 `pose` 和 `calibration`：原图尺寸、载荷 SHA256、归一化身体标定点 `from/to`、两点对应的设计长度 `span_cm`、依据及状态。公共检索注解还绑定精确 `source_asset_id`，不向同 ID 的历史图像继承几何。

这相当于为人体定义原图的像素密度。原图身体段长 `Lpx = hypot(dx × 图片宽, dy × 图片高)`；人物原图密度 `Lpx / span_cm`，共同场景密度为 `pixelsPerCm`，实际等比缩放为 `pixelsPerCm / 原图密度`。`Stage.humanImage` 使用这一换算，透明留白、床椅外框均不参与人体长度计算。场景密度由本镜空间决定，不是全季固定像素门。

站姿可用头顶到共同脚底基线标定；坐姿用同一母版的可确认身体段或已审姿态配准，不能把坐姿可见高度设为站立身高；侧视躺姿可用头到脚的体轴跨度。透视躺姿、遮脚或床人烘焙整件，不能凭床外框推定人体长度；准备尺度清楚的新姿态、使用已知身体段，或改变镜头。标定是制作近似，仍要核对头肩、躯干、四肢与家具承托。

同一地面/景深的人物共享场景密度；远近差通过明确的景深变换作用于人物与其接触组，相机再共同变换全景，不能给每个人暗加独立占位缩放。缺标定的资产保留 `pending` 和原件，可继续看图、补素材或独立镜头；不能据此宣称多人尺度已统一。按性别或年龄批填的身高仅为 `proposed_design_assumption`，不冒充已审定原图标尺。数值无自动视觉通过阈值。

儿童应保留儿童头身比；老人通过面部、发型与体态表达，不做脆弱化漫画；孕妇的腹部、重心、手部位置和衣服下摆应连贯。完整素材不能从头部、鞋或局部手片推断不存在的手臂和被遮挡身体。

标定端点与摆放锚点是两类坐标。`calibration.from/to` 只定义身体段密度；头部标定的 `to` 是下巴，不能传作脚底。`Stage.humanImage` 排景时显式使用 `registration.anchors.feet`、`seat` 或已核对承托点；改用另一锚点须共同换算落点。缺少脚底不从下巴推造地面。

同身份头部配准只能暴露原件的体量差，不能修复原件头身比。试装还应比较站高、坐高、座高、躯干和大小腿；若按相同头段密度后仍出现坐姿接近站姿高、座面过高或站走体量漂移，应补正确姿态。不能修改标尺数值把错误原件强行压进合理外框。

注册器分别接收身体标定段与真实部位锚点；不要将 `calibration.from` 批量写入 `head`。例如低头姿态用胫段配准密度时，`head` 仍须从原图独立标注头顶。修正错误锚点生成新不可变修订，更新当前实际取用和构建回执；PNG未变也不能覆盖旧记录。

### 替换人物时同时迁移动作接口

完整 PNG 替换几何人物后，旧 helper 的动作参数可能仍被调用接受，却没有进入新的绘制逻辑。例如 `q.right`、`q.left`、`awake` 继续传入，实际只绘制同一张固定姿态 PNG；编译通过，举手、换手或睁眼并未发生。人物素材替换与动作迁移要一起完成。

逐项追踪本镜动作参数的调用、读取分支、实际选用姿态、锚点与局部变换，再看动作前、中、后的真实画面。参数确实改变了什么，必须能对应到可见姿态或动作；声明与画面不符时回到最早断点修复。不再支持的参数应从接口和调用中删改；需要保留的动作准备真实同身份姿态、状态切换或绑定真实身体接触的局部层。固定垂手图不因参数存在就完成抬手，熟睡图也不因 `awake` 标记就变成清醒状态。

修后同步 Score 和导演稿中的动作说明，撤去未发生的动作。确认同一身份、年龄和服装在姿态切换中连续，关键手部、视线、接触与结果在当前镜头和邻镜中成立。类型检查和参数字段存在只证明工程声明，实际表演由画面验证；不保留静默失效的“假动作”。



## 同场人物：先统一身体体量，再排姿态

同一地面和相近景深的成人先按可信的身体体量配对。比较头部、肩宽、躯干和四肢共同形成的尺度，不能把不同姿态的 PNG 外框、整件宽度或可见高度拉成一样。坐姿因髋膝弯曲而降低头顶，不能为了填满版面把坐姿成人放大到与站姿成人等高；带椅子整件的宽度尤其不能充当身高标尺。真实身高、体型、年龄和远近可以不同，但应由人物和场景说明，不能来自独立的占位缩放。

在代表镜头中把坐姿与站姿放在同一地面，核对头肩、骨盆、腿长、脚底、椅面和投影。坐姿头顶应明显低于同体量站姿；头部大小只能辅助比较，不能单独用来等比化不同画风。素材本身头身比或姿态有误时换原件或补正确姿态，整体放大缩小不能修复身体结构。透视通过地面、遮挡和环境共同成立；分屏、图解与独立近景若采用不同景别，应有明确视觉分隔。

同一身份的站、坐、走和相邻镜头以稳定身体体量为基准，景别变化可改变屏幕大小，姿态变化不能凭空改变人体尺寸。素材准入除单件完整性，还要做至少一个同场多人或坐站组合小样；记录实际搭配、相机、地面和适用景别，不能从一张单人图批准所有组合。

## 尺寸：按职责与复杂度，不按外框
所有尺度以透明内容的实际 bounds、纸件实际轮廓和相机变换后的画面为准，不读取 PNG 外框。先给对象分职责，再判断画面大小：

| 叙事等级 | 典型对象 | 画面判断 |
| --- | --- | --- |
| 主人物/关键行动对象 | 患者、家属、医生，主操作的手和器械 | 能读清身份、表情与动作，通常承担画面最主要重量 |
| 关键医学结构/复杂道具 | 垂体、甲状腺、肾、子宫、血管壁、带机械状态的治疗模型 | 结构层级、病变/正常差异和动作接触必须可读；面积不够就换近景或拆分 |
| 辅助道具 | 报告、药盒、日历、食物、衣物 | 能辨认对象身份和变化即可，可与主对象形成明确层级 |
| 环境板 | 房间、桌面、街道 | 提供空间，不抢主体；必要时用前景或明暗托底 |
| 微小细节 | 刻度、按钮、括线条、纹理 | 只承担微证据，不能独自承载核心医学关系 |

复杂对象缩小后仍要求观众读清内部结构，是尺度问题而不是标签问题。优先扩大、换近景、拆分动作或换更简洁的结构图；不能把复杂器官缩到背景角落，再用文字说明覆盖。

人物大小至少同时满足：

- 当前景别能看全脸、手和脚的必要部分，不能出现无头躯干或半张脸被误作普通近景；
- 主人物全身/中景的可见高度与画面重量相符；次要人物能完整读出身份，不因占位缩成纸片符号；
- 人物与其他对象的接触点落在真实手上，不靠“抬手色块”指向；
- 同一角色跨镜保持年龄、发型、衣服、体态和比例连续，不用不同构造器在不同集重新发明身份。

这里不设一刀切像素门。1280×720 舞台上的完整人物在中景可以约 300–520 像素高；具体还取决于景别、遮挡和动作。小于上述范围时必须有远景、环境声或明确更低叙事等级的语义理由。

## 尺寸、复杂度与占比的统一原则

统一的是观看判断，各集仍按自己的故事选择构图。分镜前先说清本镜观众必须看懂的对象、关系和变化，再给它足够的视觉重量。判断对象的大小，要看实际内容、对比、位置、运动和周围留白；一个颜色很亮、不断运动的小物也可能抢走主位。

**核心关系越复杂，阅读面积和停留就越充分；对象越小，承载的信息就越简单。** 复杂度指本镜必须读懂的关系与变化，纸纹、装饰和已经解释过的细节不自动增加观看任务。小尺寸适合单一轮廓、归属标记、类别提示或已经解释过的归档缩图。需要辨认内部层次、结构差异、操作接触或身体变化时，采用大图、局部近景、分层揭示或拆镜。细节版被缩小后糊成一团，就换简化版；标签只负责命名，主体负责解释。

| 当前观看任务 | 尺度与组合的起点 | 实际复核重点 |
| --- | --- | --- |
| 一个复杂医学锚点 | 先给主体约一半至三分之二的有效画面宽度，再按横竖形状调整；局部关系可独占近景 | 观众能直接分出本镜必要结构及其差异，不必从标题猜图 |
| 两个对象比较 | 两侧采用相近景别和一致的比较尺度，共同基线、朝向与间距；一次突出当前比较项 | 大小差别是否表达真实比较，还是仅由素材外框或不同留白造成 |
| 人物操作器械或道具 | 人物与椅子、器械、手持物作为一个关系组排景；关键接触需要更近时切局部 | 头脸、真实手部、臀部承托、脚底与地面同时成立，动作路径有空间 |
| 多项原因或治疗选择 | 同级对象成组，当前项获得焦点，其余降低对比或暂缓出现；必要时分成连续小段 | 主次是否清楚，各项是否仍需读细节；并列过多时优先拆解 |
| 汇总、归档或远景 | 用简单轮廓或已解释过的小图保留来源，主要阅读面转到记录、计划或环境事件 | 缩图此时是否只需被认出；若仍承担新的内部解释，应恢复近景 |

表中的比例是排风格帧的起点，按扣除字幕和品牌后真正可用的画面判断，不是自动验收阈值。对象较窄、需要环境或刻意留白时可调整，以真实阅读结果决定。不要为了填满画面放大全部元素；主角、支持组与背景应有明确层级。

组合更自然时，观众能看出物件为什么放在一起：同一人物的脚、影子和地面共用落点；臀部确实被椅面承托；手与道具在真实接触位置相遇；需要比较的纸件沿共同基线摆放；同一任务的支持物间距较近，不同任务之间留出空隙。前后遮挡、视线与朝向帮助组织读取顺序，避免每个对象都像独立贴在墙上。丰富环境放在较低对比和较少运动的层次，当前解释获得最清楚的轮廓与动作。

人物从走姿切坐姿、对象从解释近景变为归档小图时，检查相邻镜头的身份、体量和落点。素材整体缩放、裁切或相机改变后，椅面、投影、接触层和文字一起重新排，不沿用旧绝对坐标。完整素材替换几何人物后，必须重新核对这些关系。

### 真实画面的复核方法

先看原尺寸的正式画面，再看约 400 像素宽的移动端预览，回答：第一眼看见什么，本镜必须读懂的关系是否仍清楚，缩小后哪些细节只剩噪声。400 像素只是常用预览尺寸，不能代替实际目标平台；需要细看时回到原尺寸确认，避免把压缩缩略图缺陷当作原片缺陷。

至少看切入、主要动作中间、极值/接触、落定及邻镜。四个等距状态帧可定位构图问题，不能覆盖所有接触极值或证明连续动作合格。发现问题后，对具体动作窗口加密取样并复看修后的候选。分别记录“小而复杂”“主体裁切/遮挡”“接触与承托”“身份/素材构造”和“层级优化”，保留实际镜头、时码与修法，不把它们混成一个面积分数。

素材策展为高频复杂对象准备总览、解释近景和简化图标三个用途的候选。沿用已有资产身份、版本及策展说明登记它们之间的关系、适用景别和不可读取的细节；只有真实存在且看过的版本才能写为可用。近景原件存在不等于已经具备小尺寸简化版。分镜按用途检索和看原件，缺合适版本就准备素材或改变镜头。

## 制作顺序

修改 Score 的导演说明后，也要先通过 `paper_project retime` 回读当前声段与完整字幕，再 build、复用未变混音、render。即便时码未变，Score 字节变化仍会使旧 timing receipt 过期；不能手改回执哈希来清除告警。仅改素材或绘制源码、Score 未变时，按实际依赖构建，不重做未变旁白。

导演稿前运行 `media_asset_library character-coverage --workspace <工作区>` 查看独立库的角色/姿态缺口，再用 `query --character-role 老年男性 --pose walk`（也可用中文姿态）取候选。覆盖矩阵是储备起点，已有一张步行姿态不等于完整步态；通用人物的不同姿态也未必是同一身份。缺动作先按同一母版准备完整姿态与中间状态，或改分镜表达。

按返回的精确外库 ID 执行 `use`，回读 `registration_readback` 与本集 manifest 的路径、bounds、registration。修订号必须遵循原件版本合同，包含载荷描述；不能用文件存在或目录哈希校验替代真实取用。旧片不随库升级自动改写。库或元数据缺项时，继续独立镜头和素材准备。

锚点使用原图归一化坐标，裁切、缩放、旋转要共同变换。头部点的具体定义读原记录；脚底可采用两脚共同地面基准，坐面点在臀部承托边缘，手点在实际可见手掌。画面左右与解剖左右分别说明；插兜、被遮挡或不可见的手不能被当作递接点。先把人物和椅子/器械按真实接触试装，再看动作前、中、后与邻镜。字段齐全只能证明登记，不能证明坐得稳、握得住。

动作图集先按真实透明沟槽确定每帧矩形，再把源图锚点转换为帧内坐标；生成图不保证等分，不能机械切网格。坐站沿同一身体标尺和固定家具落点，不给坐姿重新归一化高度。无法独立分层的医生与椅子、双人交接等接触单元按整件登记，改接触关系就重做姿态。真正的分层结构保留共同画布原点与同一变换，不能逐层按内容边界各自居中。检查全部状态与每次切换两侧，并核对落座承托、脚底和手持物；几何距离与渲染成功只证明各自检查范围。

同一角色的发型、服装、年龄和身体状态必须连续；不同人物可以共用材质，不能把相近衣色当作同一人。新姿态保存母版引用、朝向、允许的接触、适用景别与拒用边界。复杂对象准备总览、详细近景和必要的简化版本，按本镜头复杂度与可见尺寸选择。

1. 写角色与对象覆盖表，列清身份、年龄、姿态、动作和故事职责。
2. 先查 MAC 资产库，再按当前故事准备缺口；新创人物先做完整母版，再扩展姿态。
3. 用实际原尺寸素材和内容 bounds 试装代表镜头，检查人物完整性、尺度、遮挡与接触。
4. 再写最终分镜和动作。缺素材时先补资产或调整叙事，不把临时几何拼人当作默认退路。
5. 构建后看首帧、动作极值、接触、结果和邻镜；素材存在不等于当前镜头通过。

## 审查与定位

运行 `scripts/audit_character_and_scale_contract.py` 可定位程序化人物 helper 和显式小尺寸对象，但报告只是待审材料。定位器同时看函数名和函数内的人体结构：`walk`、`diner`、`walkingFigure` 等换名函数如果由头、躯干、四肢等多个几何部件构成，也必须命中。仍不能把“零命中”当成画面合格证明，实际判断必须回到当前成片和旁白：

- 人物是否在镜中承担主叙事？若是，程序拼人就退回素材准备。
- 复杂对象是否要求读出内部结构？若是，小尺寸就是确认缺陷。
- 人物动作是否真实发生，接触是否落在真实手部，结果是否留下？
- 缩小是否帮助建立环境层级，还是掩盖了对象不可读？

通过标准不是“没有检测项”，而是当前画面能用正确人物、正确对象和足够清楚的层级完成解释。
