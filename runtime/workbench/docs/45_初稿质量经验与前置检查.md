# 初稿质量经验与前置检查

更新：2026-10-24。本页把本轮人物、比例、复杂度、接触关系和素材接线返修中已经验证的规则，收敛成新集初稿前的固定检查。它提高初稿下限，不取代逐镜动态、完整听感、医学或发布审查。

## 已确认的失败模式

| 失败表现 | 最早原因 | 初稿前的处理 |
| --- | --- | --- |
| 人物由圆头、躯干和独立四肢拼成，儿童/老人/孕妇像成人改色 | 缺少完整动作素材时继续写分镜 | 先查角色/年龄/姿态覆盖；缺口先准备同一身份的完整姿态，必要时改写动作或镜头 |
| 同场成人一个像 2 米、另一个像 1.5 米；坐姿与站姿接近等高 | 按 PNG 外框或设计身高填占位，没有使用原图身体密度 | 用原图身体段像素÷厘米得到姿态密度，再换算到共同场景像素/厘米；坐、站、躺分别标定，脚底/椅面/承托锚点与身体标尺分开 |
| 复杂器官、检查设备或关系图缩成小图，只能靠标签说明 | 先塞版面再考虑阅读任务 | 小图只承载简单轮廓或已经解释过的归档；新的复杂关系给足阅读面积、停留时间，必要时近景、拆分或换简化版 |
| 替换完整人物后悬坐、脚影分离、多手或假持握 | 只换 PNG，没有迁移椅面、地面、投影、手部接口和旧动作参数 | 把人物、承托、投影、道具和接触层当作同一关系组重排；逐项核对动作参数是否真实改变画面，不支持的参数删掉 |
| 医生仍出现外国/公共 generic 形象 | 仅改 manifest 或依赖用户自定义别名 | 作者档案启用 `default_for_clinician` 时，源码实际加载路径、查询、取用和当前帧都必须解析到私有 Dr.咩；公共医生只保留为候选参考 |
| 动画参考被复制进目录但没有实际接线 | 资产登记与生产使用混在一起 | `query → 实际看原件 → use → manifest/uses 回读`；代码动作包登记精确入口、记录 SHA 和关联镜头，仍允许导演改写或新创 |

## 新集的最小前置顺序

1. 读取作者/医生基线和本集患者任务，明确每个角色的身份、年龄/身体状态、姿态、朝向和接触动作。
2. 运行 `media_asset_library character-coverage`，再按角色和姿态查询、实际看原件；人物缺口先补完整素材或重写分镜。
3. 运行 `python3 scripts/first_draft_preflight.py --project <单集工程> --pretty`。它只生成定位报告，重点回报人物拼片、小尺寸复杂对象、人物姿态标定和动画参考接线。
4. 在原尺寸和移动端宽度试装代表镜头：先看同场身体体量，再看主焦点、支持组、背景、椅面/地面、手与器械接触；复杂核心取得足够阅读面积。
5. 先完成一个包含开始、动作、反应、结果停留和邻镜承接的代表镜头，再完成整集 animatic；隐藏文字后对象、关系和变化仍应成立。
6. 旁白先做首句和高风险术语整段小样；声音变更沿真实音频链重新 retime/build/mix/render。
7. 返修后回读真实关键帧、正常速度窗口、最终 MP4 音轨和当前指针。机器报告只提供定位和字节证据，不把素材登记、构建、打包或哈希当作艺术、听感、医学或发布通过。

## 工具与记录边界

`first_draft_preflight.py`、`audit_character_and_scale_contract.py` 和 `check_animation_assets.py` 只负责结构化定位：它们不能从透明外框、字段数量、动作声明或素材版本推导视觉质量。`work/first-draft-review.md` 记录实际看过的版本、镜头范围、问题、返修和未覆盖项；静态构图、离散动作、连续动态、听感、医学和发布资格分别记录。

通用方法写回本页、对应专业 Skill、Stage prompt 和 MAC 随包工具；病种事实、品牌、声线和镜头参数留在目标工作区。对话断流或历史加密上下文不可验证时，从精简 checkpoint、当前 SHA、manifest 和 `out/current.json` 恢复，不重复灌入旧媒体或继续读取损坏历史。
