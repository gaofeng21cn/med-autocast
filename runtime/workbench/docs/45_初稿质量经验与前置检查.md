# 初稿质量经验与前置检查

更新：2026-10-24。本页把本轮人物、比例、复杂度、接触关系和素材接线返修中已经验证的规则，收敛成新集初稿前的固定检查。它提高初稿下限，不取代逐镜动态、完整听感、医学或发布审查。

## 已确认的失败模式

| 失败表现 | 最早原因 | 初稿前的处理 |
| --- | --- | --- |
| 人物由圆头、躯干和独立四肢拼成，儿童/老人/孕妇像成人改色 | 缺少完整动作素材时继续写分镜 | 先查角色/年龄/姿态覆盖；缺口先准备同一身份的完整姿态，必要时改写动作或镜头 |
| 同场成人一个像 2 米、另一个像 1.5 米；坐姿与站姿接近等高 | 按 PNG 外框或设计身高填占位，没有使用原图身体密度 | 用原图身体段像素÷厘米得到姿态密度，再换算到共同场景像素/厘米；坐、站、躺分别标定，脚底/椅面/承托锚点与身体标尺分开 |
| 复杂器官、检查设备或关系图缩成小图，只能靠标签说明 | 先塞版面再考虑阅读任务 | 小图只承载简单轮廓或已经解释过的归档；新的复杂关系给足阅读面积、停留时间，必要时近景、拆分或换简化版 |
| 替换完整人物后悬坐、脚影分离、多手或假持握 | 只换 PNG，没有迁移椅面、地面、投影、手部接口和旧动作参数 | 把人物、承托、投影、道具和接触层当作同一关系组重排；逐项核对动作参数是否真实改变画面，不支持的参数删掉 |
| 医生仍出现外国/公共 generic 形象 | 仅改 manifest 或依赖用户自定义别名 | 作者档案启用 `default_for_clinician` 时，源码实际加载路径、查询、取用和当前帧都必须解析到私有 Dr.咩；公共医生只保留为候选参考 |
| 动画参考被复制进目录但没有实际接线 | 资产登记与生产使用混在一起 | `query → 实际看原件 → use → manifest/uses 回读`；代码动作包登记精确入口、记录 SHA 和关联镜头，仍允许导演改写或新创 |

## 新动画的角色表演

主角表演从作者档案与导演阶段开始：明确关注对象、情境反应和行动，按需准备同身份表情、朝向、完整姿态及中间状态，再实际接入本集调用与事件。先深做代表短动作，检查视线、重心、手势、快慢与停顿，以及切换时身份、体量和接触是否连续；固定立绘的平移、缩放、倾斜不能替代角色表演。方法见[角色表演与灵动性](44_人物素材与画面尺度契约.md#角色表演与灵动性)。本项用于后续新动画与明确授权的返修，不自动改造既有成片。

## 新集的最小前置顺序

1. 读取作者/医生基线和本集患者任务，明确每个角色的身份、年龄/身体状态、姿态、朝向和接触动作。
2. 运行 `media_asset_library character-coverage`，再按角色和姿态查询、实际看原件；人物缺口先补完整素材或重写分镜。
3. 运行 `python3 scripts/first_draft_preflight.py --project <单集工程> --pretty`。它只生成定位报告，重点回报人物拼片、小尺寸复杂对象、人物姿态标定和动画参考接线。
4. 在原尺寸和移动端宽度试装代表镜头：先看同场身体体量，再看主焦点、支持组、背景、椅面/地面、手与器械接触；复杂核心取得足够阅读面积。
5. 先完成一个包含开始、动作、反应、结果停留和邻镜承接的代表镜头，再完成整集 animatic；隐藏文字后对象、关系和变化仍应成立。
6. 旁白先做首句和高风险术语整段小样；声音变更沿真实音频链重新 retime/build/mix/render。
7. 返修后回读真实关键帧、正常速度窗口、最终 MP4 音轨和当前指针。机器报告只提供定位和字节证据，不把素材登记、构建、打包或哈希当作艺术、听感、医学或发布通过。

## 工具与记录边界

`first_draft_preflight.py`、`audit_character_and_scale_contract.py` 和 `check_animation_assets.py` 只负责结构化定位：它们不能从透明外框、字段数量、动作声明或素材版本推导视觉质量。`work/first-draft-review.md` 记录实际看过的版本、镜头范围、问题、返修和未覆盖项；静态构图、离散动作、连续动态、听感、医学和发布资格分别记录。

通用方法写回本页、对应专业 Skill、Stage prompt 和 MAC 随包工具；病种事实、品牌、声线和镜头参数留在目标工作区。对话断流或历史加密上下文不可验证时，从精简 checkpoint、当前 SHA、manifest 和 `out/current.json` 恢复，不重复灌入旧媒体或继续读取损坏历史。

## 质控材料保留与清理

结果和可修改过程以源码、Score、导演稿、素材 manifest/uses、音频输入、当前指针、交付 manifest、JSON/Markdown 结论、问题集原始帧和压缩 contact sheet 为准。逐帧 PNG/JPG、旧编码预览、WAV/ffconcat 和重复 QA 页面是可再生质控缓存；清理时保留文本回执和紧凑摘要，在 `preview.json` 写明 `raw_visuals_pruned`，不把删除缓存写成删除审查结论。使用 `scripts/prune_workspace_history.py` 前先 dry-run 和当前 SHA manifest，按当前指针保护工程、publish 和 archive，再执行 `--apply`。

## 本轮重拍的前置判断

- **独立解释先于复用**：按本集患者任务先写独立故事、导演稿、分镜和动作，再比较相邻集的实际构图与事件。两个结尾反复出现同一诊桌、同一递袋和指向姿态时，判断这些关系是否由本集故事产生；机械复制就回导演重设，不靠改标题、计数或字段消除重复。每集以去文字画面检查起点、变化与结果，接触动作必须在真实帧中看见手、目标、接触和交接后的归属。
- **现实场景与解释层**：同场人物、家具及手持物按共同身体标尺与接触组试装；半身和全身人物核对头肩、承托、地面及景深。结构图、放大局部、数据图表、符号，以及纸面/屏幕内容分别按 [49](49_示意图分类与跨层排景逻辑.md) 判断，不把图解大小用于校准人物。环境层是背景，碰撞检查仍须关注真正承担信息的主体、纸件、接触和字幕。
- **素材以实际合成为准**：先查库并看原件，缺少或质量不足的主要对象、完整人物、姿态和道具用 ImageGen 补同风格透明素材，连同来源、版本和本镜试装入库；不以临时 SVG 或几何拼片冒充正式主体。透明 PNG 的不可见像素可能保留 RGB，查看器对透明区的显示可能产生假彩边：把原件真实 alpha 合成到浅、深、彩色背景并核对边缘，再判断污染；alpha 极值和单独看 PNG 都不足以判定。透明合成不替代动作、身份或医学审查。
- **画面文字承担含义**：移除“非真实影像”“这是动画”等只说明绘画媒介的重复文案；来源、单位、数据轴、必要医学标签和可能影响判断的条件继续保留。图解身份优先由纸面、屏幕、放大关系或可读图框表达，误导时修画面而不是追加免责声明。
- **预览缓存和证据**：明确目录与剩余空间。当前随包 `paper_project preview` 默认保留无损关键帧、事件帧、联系表、条带图及状态轨迹，不保留条带的逐张源帧；确需逐帧检查时使用 `--retain-motion-strip-frames`。优先只预览本集相关范围；可再生缓存清理由明确的清理回执和可重建路径支撑，保留源码、素材、音频、当前母版、问题证据和交付记录。旧安装须先回读实际支持的选项。

每集收尾写明实际证据、失败原因及可复用范围，并将经过真实镜头验证的素材、动作或技法写回资产库和相关 Stage。下一集先查这些经验，再独立决定故事、构图、声音和表演；技术编码、缩略图或同一人物纸件都不能证明创意质量。

## 自然性检查

“自然”是观众对人物、物件和文字关系的基本判断，不能用构建成功、透明通道或动作数量代替。每集在 `qa/naturalness-review.json` 留下实际审看记录，至少回答：文字是否只出现在自己的纸件、屏幕或题注区域；主要人物是否保留完整身体连续性；动作是否符合先注意—接触—移动—反应—落定的日常认知；去掉标题、标签和字幕后，观众能否说出谁在看什么、谁在移动什么、动作结果是什么；原尺寸、移动端宽度、事件前/接触时/落定后和相邻镜头是否都自然。

单臂或局部接触层不是一律禁止：在明确的视角、画边进入/退出、人体连接点和同一材质关系都可见时，合理的操作特写可以成立；中央断臂、来源不明的悬浮部件、没有身体或支撑连续性的局部，不能承担正式动作。药品名称、药单标题、单位和勾选项必须留在自己的纸件内，不能压到药盒、人物、桌面边缘、字幕或其他纸件上。发现明显违和时回到导演、素材或实现 owner 重写动作或换完整素材，不能用缩小人物、箭头、解释文字或持续抖动掩盖。自然性记录只绑定实际审看范围，不升级连续动态、听感、医学或发布状态。
