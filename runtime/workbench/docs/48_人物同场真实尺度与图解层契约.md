# 人物同场真实尺度与图解层契约

## 适用范围

这份契约适用于纸剧场、代码动画和其他把多个视觉元素放进同一真实场景的医学科普视频。它解决一个明确问题：人物素材不能只按 PNG 像素尺寸或占位框放进画面，否则 Dr.咩 半身、患者坐姿、家属站姿和家具会失去共同的真实世界比例。

## 两种视觉层必须分开

`visual_layer=character|person|human` 且 `scale_mode=world_scale` 表示现实人物或拟人的真实场景角色，必须进入人物尺度契约。示意层不再只有器官图这一类；结构示意、放大切片、数据图表和符号隐喻分别使用 `diagrammatic_structure`、`magnified_detail`、`data_visualization`、`symbolic_metaphor`，并遵守[示意图分类与跨层排景逻辑](49_示意图分类与跨层排景逻辑.md)。`document_flat` 和 `screen_content` 是物理容器加内容的双层对象，纸张/屏幕仍按现实关系排景。所有解释层都不能反过来作为人物身体比例依据。

## 人物进入同场前的最小合同

每件会与其他人物同场的真实人物素材都要登记：

- 设计身高或可复核的身体段长度；
- 原图宽高、载荷 SHA-256、姿态、身份和适用景别；
- `human_scale.calibration.from/to` 与对应的 `span_cm`；
- 头顶、下颌、坐面、脚底和可见手等真实锚点；
- 当前场景的 `pixels_per_cm` 与前后景理由；
- 如果是半身图集，记录每格可见身体段和被桌面/椅面遮挡的边界，不能把半身外框当全身高度。

原图像素只用于计算像素每厘米，不能直接当作屏幕身高。坐姿、卧姿和半身姿态分别用身体段、体轴或承托点标定；床、椅、桌和透明 PNG 外框不能代替人体标尺。

## 同场试装顺序

先按共同 `pixels_per_cm` 排人物，再排景别、前后景和动作。人物、椅面、桌面、脚底、投影、手持物和接触阴影作为关系组共同变换。至少查看一张原尺寸同场试装和一张移动端宽度试装，再看动作中间、接触/极值、落定和邻镜。

同体量人物的头肩、躯干、四肢、坐面和脚底应可信；坐姿头顶低于同体量站姿是姿态结果，不能为了填满画面把坐姿人物放大到站姿高度。景深可以造成比例差，但必须同时作用于人物与接触组，并写出本镜理由。

## 前置检查与质量债

单集 `asset_manifest.json` 在使用真实人物时写入 `scale_contract`，至少包含 `status`、`pixels_per_cm`、`human_asset_ids`、`same_scene_test_fit` 和 `enforcement`。新独立单集默认 `enforcement=required`；人物未标定、共同场景密度缺失、声明的人物 ID 与实际使用不一致、标定 SHA 与实际载荷不一致，或没有原尺寸/移动端/动作接触/邻镜试装记录时，`first_draft_preflight.py` 返回 `scale_contract_pending` 并阻止进入该单集的粗动态资格。旧工程可以先生成诊断，但不能把缺口写成比例已通过。

预检的机器结果只证明标尺合同和素材回读，不能替代实际画面判断。视觉审看仍要记录比例失衡、承托、遮挡、视线和邻镜结论；发现问题回到导演、素材或实现的最早责任点。

由导演按画面语义声明真实人物的 `visual_layer` 和合同 `human_asset_ids`；工具以这些明确声明与实际镜头引用核对，不用文件名、关键词或说明文字判断人物身份。已声明人物不得因名称未命中而跳过标定；同一载荷同时标成人物和图解时须先解决冲突。未声明角色是否为人物仍由导演逐镜判断，机器通过不证明没有遗漏。

## 例外与禁止

纯医学示意图使用 `visual_layer=medical_diagram`，在 `diagram_layer_exempt` 中记录后按解释职责单独排景。不得用大器官图的显示比例推导医生、患者或家具大小，也不得用“示意图”标签掩盖真实人物之间的比例失衡。

禁止用统一屏幕高度、素材外框相等、像素宽度相等、透明留白填满、代码编译成功或 registration 字段存在来批准人物同场比例。

## 沉淀要求

每集审片回执记录实际 `pixels_per_cm`、人物姿态/标定来源、同场试装范围、修复前后帧和是否有示意层例外。新姿态、标尺辅助函数和成功/失败样例只有在当前真实镜头和邻镜中看过后，才可进入可复用资产或动画原语库。
