# 初稿动态表现与跨镜状态规范

更新：2026-11-22。本规范吸收 OpenMotion 与社区主流开源代码动画项目（`video-talkcraft`、`anything2explainer`、`onetake`、`huashu-motion`、`cth9191/animate`、`hand-drawn-explainer-video-nikola`、`stickman-video-director` 等）的一线实战经验，聚焦**「不穿帮之后，如何让纸剧场初稿彻底摆脱 PPT 感、避免空首帧/落位即切/跨镜状态回退与空转等待，并把返修收敛到最小闭环」**。与 [45_初稿质量经验与前置检查](45_初稿质量经验与前置检查.md) 互补，只约束判断与证据清晰度，不规定镜头数、时长比例、动作配额或转场数量。

## 一、双轨判断：内容成立 ≠ 动态表现成立

每一关键段落必须分别回答两个问题，不能把“医学事实对了、功能/流程演示对了”直接等同于“初稿表现力通过”：

1. **内容与医学成立**：观众看清了什么事实、因果、边界或行动？去文字后对象与关系是否仍成立？
2. **动态表现成立**：时间、运动、景别或剪辑带来了什么观看收益？如果把动作抽掉只留终态静帧，表达是否没有本质差别？

### 医学科普纸剧场三类隐蔽“内容已对但仍平”反例

| 常见弱解（不穿帮但像带动画的 PPT） | 问题根因 | 初稿有效编排方向 |
| --- | --- | --- |
| 报告/药盒/图表被放进圆角卡片，整张卡片滑入→停留→滑出 | **容器在动，主体没有发生关系变化** | 让承载意义的主体本身变化：翻页显露异常项、对比值随标尺推进、旧药与新药在同一桌面完成替换，背景和载体可保持安定 |
| 3～4 条注意事项用完全相同的时长、缓动、间隔依次飞入，随后静止等待旁白念完 | **首次建立语法与后续推进未区分，且末尾大段空转** | 首项慢一点建立观看语法，后续同类变化可更紧凑形成推进；或让当前讲到的项占据视觉焦点，已讲完项退居稳定参考态，避免每条都像“重新开始” |
| 镜头一边大幅推拉缩放，一边在局部展开复杂解剖图或纸页 | **镜头运动盖过了主体局部展开的可辨窗口** | 先退/切到可读景别让关键局部变化在稳定尺度完成，再重新取景或匹配硬切；主体与镜头不必同时大动 |

## 二、关键动作的“时间形态短句”与空转时间（Dead Time）诊断

- **按短句编排动作**：把主动作、次级跟随（阴影、衣摆、关联纸件）和必要文字出现编排为一句有重音的时间短句（按需包含蓄势 → 主变化 → 接触/转折 → 跟随 → 可读落定），而不是让同镜每个元素各跑一次独立入场。精准清晰的医学对比也可以干脆、无回弹。
- **区分有意停留与无信息空转**：`paper_project preview` 已自动输出 `preview.json.motion_profiles`（每镜的视觉变化区间比 `active_ratio` 与末尾静止秒数 `tail_static_seconds`），并在疑似空转或全镜无变化时写入非阻断诊断 `possible_motion_dead_time` / `possible_static_shot`。
  - 若末尾静止是为了让观众读清复杂指标、剂量或急症行动指引，保留该停留并记录理由；
  - 若主动作早已结束、信息也已读清，只剩无意义等待章节时间耗尽，回到导演/联合时间轴调整段落切分、补充有效观察变化或重排上下文，**不用无意义缓慢缩放或背景装饰漂移掩盖空转**。

逐镜维护 Score 的 `shot_recipe.motion_arc`，由动画脚本说明起势、主变化、反应和落定。对照真实预览的切入、动作与最后可读状态。稳定图解写清读图任务和停留理由。若写了收纳，落定帧要能看到物件确实归位。若手机承担联系行动，屏幕要传达去向。已有成片的交接修订可用构建和画面比对验证，改动过的镜头另存实际编码证据。

## 三、跨镜对象状态单源继承与切点成对帧（`N-1 / N`）

- **复现的是对象当前版本，不只是相同名字**：同一对象（如被圈出的检验报告、划掉旧剂量的药单、已记录三天的血压表、换好支撑姿态的患者）在后续回顾、对比或结尾镜头再现时，必须在代码中引用同一状态定义（示意：`object.initial → object.revised`，不同景别/构图复用 `object.revised`），**严禁在后镜重新实例化初始态导致前镜已完成的修改无意回退**。
- **验证修改落定帧 vs 稍后再现帧**：跨镜再现检查不仅看相邻接点，还要对齐检查“修改落定帧”与“十秒后再现帧”的语义状态（文字、勾选、曲线形态、物件归属）是否一致。
- **切点成对帧检查（`cut-pairs.jpg`）**：`paper_project preview` 自动对每个内部镜头切点抓取精确的 `N-1`（前镜末帧）与 `N`（后镜首帧）并拼出 `cut-pairs.jpg`。重点核对：
  1. 覆盖/遮罩/纸页展开类转场中，旧场是否过早清空、新场底层是否提前挡住旧场；
  2. 同对象延续或匹配剪辑在切点是否发生意外跳位、朝向翻转或体量突变；
  3. 急症/关键揭示镜头在精确首帧 `N` 是否直接可读，无闪黑或未就绪占位。

## 四、360px 实寸手机阅读与三层排版排错

- **看实寸手机图，不靠大屏脑补**：`paper_project preview` 自动基于各镜中段稳定帧生成精确 `360px` 宽实寸拼图 **`mobile-360.jpg`**，同时采集 `preview.json.font_observations`（`document.fonts` 实际加载与失败状态）。
- 手机端竖/横屏预览重点核对：核心主张、最长医学标签/单位、药单/报告正文、字幕与结尾行动指引在 `360px` 实宽下的笔画清晰度、字距和留白；**最大字符数上限不能替代真实文案同框实帧核验**。
- **出现排版/字体问题时严格按三层顺序定位，先修最早根因**：
  1. **Resource（字体资源）**：查 `font_observations` 是否缺字、加载失败、发生非预期系统字体回退或伪粗体/伪斜体；
  2. **Hierarchy & Reading（层级与阅读窗）**：在 `mobile-360.jpg` 与正常速度窗口下查对比度、折行、字重层级、留白与稳定阅读时间；
  3. **Content & Fit（内容密度与主体竞争）**：判断是否文案过密或标签重复说明画面已有内容，优先精简或拆分段落，不靠无限缩字硬塞。

## 五、声画共用事件源与声音叙事留白

- 在纸剧场镜头的 `render(ctx)` 中，`ctx.t` 从本镜起点计时。全片时码的旁白或事件锚点换算成镜内时码后再参与判断，避免在比较阈值里把镜头起点重复相加。跟随动作、换姿和渐显用同一时间基准。转移性结直肠癌第 04 集曾在含时序的末镜使用全片阈值，导致动作分支全程触达不到。代码前置定位后，仍要核对开始前、变化中和可读结果三处画面。
- **先定声音职责，再选音效/配乐**：说明每段声音承担的是持续氛围、段落转折、关键因果强调，还是留白给患者读数字/听医学结论。
- **共用事件时间源**：需要精确声画同步的拟音与视觉动作共同引用 `score.shots[].events` 的同一具名事件锚点，并指向**视觉感知重点**（手接触纸件、药片落入格中、指标越过阈值、翻页到位），而非一律对齐动画起点；避免在代码和混音配方里维护两套易漂移的秒数。
- **杜绝机械点击噪声**：不要给每个词或每次元素入场都配同一个 click/pop 提示音；关键医学结论与行动数字出现时给语音和阅读留出听觉空间。

## 六、局部返修契约、证据失效与防趋同自检

交付回读同时核对工作台登记工程、当前渲染、交付清单和同步机实存成片的 SHA-256。两个成片来自同一个制作目录时，仍需核对实际渲染及其构建指纹。确认画面修订更晚、音轨同版且受影响区间通过后，将修订成片一并登记、交付。

1. **变化项 + 保持项双记录**：局部返修前先明确“本轮要改的对象/区间”与“必须保持不变的已确认内容（文案、声画锚点、邻镜构图、未授权改动区）”；返修后同时核对“目标已改善”与“保持项未退化”。
2. **受影响区间证据自动失效规则**：只要动作的起止、相位或可见完成时刻改变，或相关音轨（旁白、音乐、拟音）的来源、裁切或偏移改变，**即使总时长未变，受影响区间的旧声画同步与旧审看结论立即失效**；必须复看变更窗口及前后切点 `cut-pairs.jpg`，不得沿用旧回执。
3. **防跨集脚本趋同自检（写完分镜与审片时各问一次）**：
   - 去掉具体病名与检查名称后，本集动作流程是否能无差别套给任何其他疾病？若是，回导演按本集核心医学机制重写视觉事件；
   - 是否为了填 `events` / 承接物字段强行塞入无意义的手指点击、物体飞入或假装无缝的转场？删掉只为模板存在的动作，保留真正服务理解的硬切与静止。

## 七、反 PPT 构图、同屏预算与版式轮换

1. **同屏主体组预算与显式让位**：任一时刻同屏主体组原则上不超过 3 组（字幕与常驻品牌件不计），全程保留至少一个视觉呼吸留白区，同屏只允许 1 个 hero 大字或主焦点。前任主体完成讲述后，按是否还需回指二选一：不再回指则**真退场**；还需对照则用 `kit/motion.ts` 的 `demotePose()` **降权留守**——**降权留守元素仍占原槽位并计入同屏预算（`occupiesSlot: true`），新主体不得压入其槽位**。
2. **枢轴句归下一镜**：遇到“但其实不是……”“为什么会这样？”等转折/否定/设问枢轴句时，把切镜点提前到枢轴句起点，在干净的新舞台起势，不把反转叠在旧话题的满画面上。
3. **跨镜版式轮换与节奏落差**：连续 3 镜不得重复“人物同侧同景别 + 同一种居中图框”，至少变换人物景别/方位或道具容器/俯平视角之一；整集镜头时长随信息密度拉开长短落差，避免 `audit_motion.py` 标出 `uniform_shot_cadence`（所有镜头近似等长像翻页）。
4. **边界承接（Carry）优先于硬清场**：每个切点明确哪个视觉线索、道具或视线延续到下一镜；需要静止读图的图解镜头可用 `gentleDrift()`（线性极缓微推/微拉，不在镜尾刹停）维持画面活气，避免主体无故微抖，特写推近优先用 `focusOn()` 指定避开底部字幕带和人物侧的屏幕落点。

## 八、首帧即海报、未到拍不显形与读图稳定期

1. **第 0 帧即封面海报**：开场第 0 帧必须直接呈现可辨认主体，禁止用 `fadeIn(0)=0` 或全黑/纯白底干等首帧；`preview_local_animation.mjs` 自动检测第 0 帧纯单色空屏或首帧缺主体而中段有主体的 `poster_frame_blank_risk`。
2. **未到拍不显形**：词锚未到达的数字、结论、勾选或标注保持完全不可见（使用 `revealWindow()` 门控），禁止压暗/灰显“预告”，也禁止在行内数字位置先挂空洞。
3. **末拍读图保护带与出处停留**：关键变化或结论落定后应留足 **1.0–1.5s 读图稳定期**再离场或切镜（`preview.json` 的 `possible_rushed_ending` 与 `audit_motion.py` 的 `event_too_close_to_shot_end`、`opening_empty_wait` 会自动定位风险镜）；末镜头还要核对收尾动作与结论字是否被片尾淡出吃掉。**医学出处、适用前提或纠偏小字挂在镜头前半段（确保 ≥2.5s 可读停留）**，绝不塞在最后 1 秒。
4. **缩放字号与医学数字合规**：凡对包含文字的组施加 `scale < 1`，必须按「源字号 × 最小缩放系数」验算在 `mobile-360.jpg` 下仍清晰可读；计数/滚数动画不得在中间帧清晰闪出未核实的“假医学阈值、假年份或假剂量”。
5. **物理质感的确定性弹簧与细密纹理约束**：带质量感的纸件弹出、标注指向和多目标连续位移优先用 `kit/motion.ts` 的闭式二阶弹簧 `springMove()` / `springTrack()` 或 `tracks.ts` 的 `ease: "spring"`（无历史状态、倒序 seek 确定）；细密纸纹、网点或网格放屏幕空间静态层，不放进连续缩放的相机层以防亚像素抖动。

## 九、科普叙事分工、双语义岛、首镜打样与声音气口

1. **先情境后机制，画面与旁白分工**：用患者真实处境或问题开场，先解释现象与原因再贴医学术语（引入的术语后续应再次用到）；数字尽量换算成患者可感尺度；旁白承担因果、比较、风险与行动判断，画面承担结构、先后与关系，删掉“如图所见 / 接下来我们看”类复述画面或报幕废话；段落/章节交界处由上段留出问题、下段承接回应。
2. **双语义岛分步揭示**：当单镜需要呈现“起因 → 结果”“错误做法 → 正确做法”两阶段关系时，可在同一纸面布置左右两个独立叙事岛（中间留 6%–10% 空白沟槽、底部留字幕安全带、岛间不画跨区连线），按“左岛完成并短暂停留 → 左岛保留、右岛展开”推进；先核对旁白可用时长再控制细节密度，防止赶工糊成一团。
3. **首镜先出有声短样片定基线**：全集批量扩展前，先将代表镜（`signature_shot` / 首镜）做成含字体、纸感、相机幅度与真实混音电平的有声短样片确认全片基线，避免做完十余镜再改共性返工。
4. **关键音效让开满声旁白**：最具叙事重量的揭示、反转或结论落点，优先落在**句间气口停顿**（而非埋在满声旁白下被 duck 吞掉）。

## 十、冷眼审片三问与五种破 PPT 提档手法

视觉复核除检查事实与穿帮外，必须以冷眼观众视角回答三条“防平淡”问题，并把最弱一镜的根因回流到经验卡：

1. **哪一段开始让人走神，哪里“合规但平”？**
2. **把动作抽掉看，哪几镜只是“底板 + 居中图 + 下方字”的幻灯片？**
3. **全片最弱的一镜是哪镜，改哪一步收益最大？**

对确认像 PPT 的段落，按场景语义从五种提档手法中选择其一（不连续两镜重复同一种）：**满幅出血**（让真实病历/场景铺满整画幅）、**细节微距特写**（直接切到真正发生变化的局部刻度/病灶）、**空间透视递进**（同一桌面或空间中沿纵深推进）、**总览收拢**（先快切单项再拉开合成全局关系）、**对比碰撞**（误区与正解同框对照替换）。

## 十一、人物自然表演引擎、稳健自然默认策略与初稿实战防线

> **最高准则：自然是下限（含人物动作自然、透视遮挡合理与严格区分示意排版/写实物理比例），生动与富有创造力是上限；保下限，追上限。**

1. **一等人物表演套件与稳健自然优先（Option A 默认路线）**：
   - 常规新集与批量返修默认采用 `templates/animation/paper_theatre/src/kit/actor.ts` 的克制离散表演（`drawActorAtlas` / `drawActorPose` / `drawActorWalk`），配合收敛呼吸点头与无橡胶弹跳的平滑重心沉降；`drawActorPose` 默认 `blendWindow = 0` 避免跨姿双影/四臂叠化；`drawActorAtlas` 默认关闭 `allowBlink`，仅头肩手势完全同位格才允许眨眼。`kit/microActor.ts` 与 `scripts/build_micro_actor_rig.py` 作为按需微动点缀工具保留，不作为全集标配，不强制全集制作语音口型。
   - **节律与尺度红线**：3–5s 短镜最多 1 次自然转折（2 态，单姿停留 `>= 1.8s`），6–10s 长镜最多 2–3 态；无实物接触不空抓（不凭空消失手持物）；高举折臂指向立绘限高墙挂图/白板远景慎用，严禁用于医患面对面诊室交流；抽象放大信息排版镜（如将小物放大为卡片级）**严禁**硬插写实尺寸悬空断手（`drawActorEdgeHand` 仅限旁白明确演示真实物理接触操作且道具按真实比例配套移动时使用）。
   - **半身像与实心前景桌配对铁律**：齐腰半身表演图集（`drawActorAtlas`）**严禁置于带腿镂空 `desk()` 后或带地板线的房间景中**（会露出桌下无腿断身悬空）；必须搭配模板一等函数 `kit/rooms.ts` `drawCloseWallBackdrop(stage, 'bg_home')`（裁去底部地板线）+ `kit/actor.ts` `drawForegroundDesk(stage, { topY })`（贴画布底边实心前景桌）配 `clipBottomY: topY + 8`。需要展示桌腿与地面的中景房间镜头，一律改用完整全身已标定站/坐姿。
2. **高频初稿排版、落地与审看防线**：
