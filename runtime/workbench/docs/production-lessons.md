# 已验证制作经验

本文将来源工作台的本机复盘整理为可移植方法；实际系列状态以当前工作区记录为准。

- H3 首帧正确不保证后段正确。看完整采用区间，排除假报告、假影像、伪字、自动淡黑和构图漂移；中央医学内容错误应换审定素材，不能用标签遮盖。
- 所有人物检查完整头部、脸、下巴和双手。构图余量是设计建议，不是自动验收阈值。源片已截头不能靠合成补边修复；同源引用须逐集排查。
- 抽帧前读结构化时长，确认输出是本次新生成的图片；越界抽帧可能留下旧文件。联系表用于定位，临界细节查看原尺寸并加密采样。
- 一次观看任务累计生成预算；输入或调用缺陷最多一次定向修正，模型行为失败接回已有基础表达。换种子、首帧或模式不重置预算。
- 联合时间轴把画面、PCM 波形、审定 SRT 与可选 ASR 放到同一范围。局部 ASR 加节拍偏移；错字不覆盖医学原文。简单可控动画继续使用已有合成器，未经实际收益验证不替换为新工具。
- 跨集、跨季检查实际时间轴。同源裁切、改名、缩放不是新素材；短区间反复插入会造成碎镜和动作重启，应按同期含义重新编排。
- 原 runner、任务 ID、队列和精确产物是恢复依据。图像接口解码异常先检查是否已有生成结果；不批量导入旧图片对话，不回显 base64 或凭据。
- 审看母版可能在 review 子目录，根制作单和旧 final 不能自动代表当前修订。选定制作单、构建记录、源审查和发布清单逐项绑定，复制后比较真实字节。
- 完整动态、完整听感、医学复核和上传独立记录。后台抽帧、技术解码、音轨电平和 ASR 都不能代替完整听感或医生复核。
- 多个疾病共用镜头工厂时，重复感首先来自构图、景别和进入节奏，而不是旁白。给每个主题建立独立系列视觉语法，可以先消除“同一套镜头换标题”的下限问题；相机语法不能冒充导演级重做，物件拿取、翻面、夹住、推入、折叠和收纳的因果仍需逐镜设计。
- 批量修改源码前，备份不能留在 `src`：TypeScript 构建会把任何新文件计入源码清单，导致 render 以“源码文件列表已变”阻断。备份统一放 `work/series-grammar-backups/`，推广工具替换完整属性而非正则截断前缀，批处理每集先 build 再 render。

## 2026-10-13 · 系列级镜头工厂是架构错误，不是可选项

工作台曾用 `six_shots.ts` / `hypertension_shots.ts` / `story_shots.ts` 三个系列工厂渲染 76 集，
并为 89 集只写了 11 份导演稿（每系列一份，连 `intent` 都逐字相同）。批改工厂看起来省事，实际把
89 集压成 11 集的导演：同一空间、同一进入节奏、同一构图，药理学差异进不了画面。

教训与已落地的修复：

1. **只有动画原语和纸件资产可以跨集共享**，导演不行。判断方法：两集的镜头代码若逐字相同（哪怕只差一个
   topic 字符串），就是错的。`scripts/check_episode_independence.py` 现在按内容哈希把这件事变成架构门。
2. **纸景不再用实景照片。** `kitchen` 是实景木地板、`clinic` 是医院外景插画，与纸拼贴主体属于两种媒介，
   画面会读成照片上贴了几张纸。新增 `kit/rooms.ts` 的 `paperRoom()`，把诊室、厨房、卧室、实验台、
   病房画成纸景房间；剩余图片背景由 `kit/staging.ts` 的 `paperPlate()` 拉进纸的媒介。
3. **食物也必须是纸片。** 照片食物切图（陶瓷盘、番茄高光）是拼贴的最后一处破绽，新增
   `kit/tableware.ts` 的 `paperPlate/paperFood`，份量关系由导演给，不再按外框统一缩放。
4. **批量只用于排期与验收，不用于共享实现。** `optimize_current_episodes.py` 只做 build/render/package。
5. 迁移状态与步骤见 `work/episode-migration-status.md`；规则见 `docs/34_逐集独立导演与系列资产分层SOP.md`。

## 2026-10-18 · 五小时级全季优化复盘

本轮长任务覆盖 89 集、483 个镜头，最初动作审计出现 1,036 条定位项。旧自动补写后清零不能证明它们只是缺字段，也不能证明画面修好；2026-10-18 源码复查已更正该入口为只读声明导出，保留真实未审范围。初稿先把患者理解变化演成事情/清楚关系，再做道具状态图、一段深做与整集 animatic；详见 docs/42_paper-collage-mv制作方法适配.md。

长任务的稳定做法是：单一 writer；每集独立导演与独立回执；批量只负责排期、构建、预览、渲染和绑定；断点按最近完整文件阶段恢复。按实际依赖对受影响单集重跑 retime、build/preview、mix 或 render/package；只改方法文档不重渲染。实际媒体改动后回读 `out/current.json`、当前 MP4、mix lineage 和 publish SHA。批量 89/89 成功只能证明工程链路完整，不能替代逐集反向读图、连续动态、段首听辨和医学终审。

初稿质量前移为“患者任务 → 独立故事/视觉处理稿 → 真实代表镜头 → 动作证据 → 整集 animatic → 透明素材准入 → JS 实现 → 连续预览 → 逐集 Review → Meta Review”。库和 kit 只提供稳定下限；复用原语、纸件和声音资产，不复用整套导演。长旁白必须由真实视觉事件或有职责的阅读停留承接，不能用慢推、随机抖动、色带或追加标签填空。

声音仍沿正文/配音输入 → 源 take → 拼接轨 → 归一化轨 → mix → 最终 MP4 逐段核对；段首少字、错读、语气漂移和旧轨引用分别定位。修复后按真实新时长 retime、build、mix、render、package，不能为维持旧时长截声或变速。用户目录只保留唯一最新版，过程回执与可恢复历史放在工作目录之外的对应位置。

## 2026-10-18 · 质量债重分类

质量债处理要区分定位项和已确认故障：素材覆盖先区分 manifest 的声明、源码可达的实际栅格引用与纯程序绘制；未完成运行时帧追踪时，不把挂载候选称作实际使用。`audit_motion.py` 的阶段缺口、长停留、重复事件、方向和承接输出为 `review_locators`。`scripts/reclassify_quality_debt.py` 默认把所有定位保持 `unresolved`；只有逐项审查记录绑定当前集、当前 Score SHA、源码/素材 SHA 和可回读证据后，才可归为 `reviewed_not_defect` 或 `confirmed_defect`。素材报告把原件来源可回读、当前镜头复核和医学复核分开；这些是证据分层，不是成片通过。`check_animation_assets.py` 还会检查 review JSON 内嵌的 contact-sheet/帧路径，失效路径降级为证据待补，不得继承旧的 passed。只有真实帧、源码、语义或医学审查确认后才回到导演/实现修复，不能用改状态字段或批量计数清零。



原件审核按实际调用范围做：纯程序镜头不因没有 PNG 欠素材审核；预加载候选不算当前镜头素材错误。AI 可依据当前原件、医学来源和真实帧判断通用物件/粗略结构是否可用，具体病理、侧别、操作和临床结论另审。不要把模型能完成的基础判断一概留给用户。

本轮真实缺陷包括：两行标题被同一自动夹紧区域挤叠、文字与纸件不共用原点、为够道具把手臂拉长、纸件渐现时穿过人物、暂停用药同时开盖、观察圈与结构切换错位、物件退场包络不完整。分别改本集显式文字区域、物件连接点与姿态、实体轨迹和状态时序；修改后查看新编码帧与邻镜，复用未变旁白。

本轮逐项动作审片已将 573 个定位项绑定到当前集、Score/source SHA 和逐集证据并归为 `reviewed_not_defect`；123 个属于 15 集正在返修或等待最终新候选的定位，继续保持 `unresolved`，没有把早期 663/33 启发式结论当作批准。最终队列见工作区 `work/review/paper-collage-20261018/quality-debt-reclassified-final.json`。
