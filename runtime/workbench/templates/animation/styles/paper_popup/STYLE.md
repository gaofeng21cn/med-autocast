# 纸立体书

纸立体书的物件有纸页、底部折轴、固定纸脚、折痕和前后层。展开不是一张图随便缩放；基点要接住地面，前层遮挡和投影说明立起过程。

颜色来自纸面与纸片，光线统一，折痕和固定件有物理位置。允许展开一个微型世界，但不要把纸屋当成新的无意义背景卡片；屋内需要可见事件。

底部轴带动弹起，页角翻动或折页带出新空间；动作终点保留阅读。Canvas 可以作 2.5D 投影，当前 hingeRise 不是真实折纸力学，也不提供任意 3D 轨道视角。

镜头尊重已实现视角：Canvas 可轻推、平移与分层视差；需要真实绕行、背面或复杂投影时才选择已具备的 Three.js 后端，不能以登记名称冒充运行支持。

声音可以是纸折、轻触纸脚和开页声，静止终点用音乐或静默承接。页轴事件和声音共用 score。

失败模式：底部漂浮、纸脚滑动、弹起只按图片中心拉伸、阴影不随高度、把 Canvas 缩放说成真实 3D。先检查基点、极值与邻镜，再判断是否需要换后端。
