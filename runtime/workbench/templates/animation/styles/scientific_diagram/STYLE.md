# 科学图示

图示的视觉语法是审定对象、稳定定位、层级与局部解释。可拆开、剖开、放大和比较，但结构、命名、方向与因果来自证据，不是从动作效果推断医学。通用样例不含医学解剖，不能拿它证明医学资格。

用清晰结构色与一致的对比体系；高饱和色只标关键对象或变化。参考影像与示意结构分层，文字只命名必要对象。精确比例与说明由具体解释任务决定，不自动加防御性标签。

先建立整体现有关系，再切出局部，最终返回整体或行动建议。位移、解剖层分离、遮挡变化和比较是动作；循环粒子只在确有传播/流动含义且不被误认作真实模拟时出现。

连接线只服务精确局部与放大窗的对应；线的起止必须在真实对象上。相机与放大窗协作，不同时挪动所有层。字幕、命名与重要变化避免争夺同一空间。

声音宜克制，可留静默给认知处理，不自动套警报或心跳。同期旁白先后与揭示关系一致。

失败模式：动画很复杂但关系错、展示未审解剖、粒子冒充病理机制、连线穿错对象、标签过多。工程通过、路径确定性和样例能运行均不能替代医学与解释 Review。
