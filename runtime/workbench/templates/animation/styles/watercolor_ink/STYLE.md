# 水彩与墨

媒介不变量是纸纤维中的透明颜料、逐笔叠色、积色边界和少量干刷留白。墨线确定可识别结构，水彩负责体积、情绪或揭示；边界需足够清晰，不把柔和扩散变成解剖歧义。

色彩采用颜料叠加逻辑。几层低透明度笔触形成深色，不做一次整图淡入或全屏模糊滤镜。落笔、染色和干刷可以分别采用可复现 mask；水彩模块是视觉近似，不宣称物理流体模拟。

动作顺着笔势与干湿变化：先墨后色、局部浸润、第二笔叠上与最后提笔。笔触有不同长度和宽度，边缘纹理固定在物件空间。不是每一镜都必须画完整过程；已建立的插画可与新笔触并置。

镜头让观众看见被描绘的对象和关系，不追逐每一滴颜料；柔和推近可突出一段局部墨线，关键命名仍要稳定可读。环境允许留白，焦点不要被纸纹淹没。

声音可选湿刷、干纸摩擦与轻柔木质/空气音；并非每笔都需要声音。避免恐怖式滴水、心跳或突然兴奋的情绪。

失败模式：整图淡入叫“水彩”、只有滤镜没有笔触、主体低对比、叠色压黑文字、扩散越过医学结构边界。先用真实风格帧审笔触，再看正常速度中的可识别性。
